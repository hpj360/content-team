# 拆解案例：吴承恩《西游记》（公版）

> 类型：章回体神魔小说 ｜ 核心可迁移：**章回体单元历险**、**群像分工**、**背景设定即爽点**。
> 本文件只做结构分析，不含原文全文。**中国古典章回体爆款范式**。

## 一、骨架（一行式）

```
取经任务（总纲）→ 师徒集结 → 八十一难（单元历险）→ 抵达（任务达成）
```

- 主线是**一个明确任务**（取经），沿途**单元历险**（一难一回），可独立成篇。
- 这是"**任务型单元剧**"的原型：总纲给方向，单元给爽点。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 明确总纲 | 取经（不可动摇的目标） | 长线连载的"目标锚" |
| 师徒群像 | 四种性格分工（战力/吐槽/稳重/沉默） | **群像分工**（每个角色一种功能） |
| 单元历险 | 一难一回，自闭环 | 网文/短剧的单元化生产 |
| 妖怪分层 | 小妖→坐骑→大妖（背景） | 反派分层 + "背景揭秘"爽点 |
| 背景即爽点 | 妖怪的来历（谁的坐骑） | 揭背景 = 反转（身份钩） |
| 任务达成 | 抵达西天 | 终局兑现（不可注水） |

## 三、节拍条（单元模板）

```
拍1 遇难：妖怪拦路（危机）
拍2 交手：悟空受挫（能力受限）
拍3 求援：搬救兵/查来历（信息）
拍4 揭秘：妖怪背景（身份反转）
拍5 收服：解决 + 余味
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 遇难 | 02 危机钩 | 拦路危机 |
| 拍3 求援 | 11 信息钩 | 查来历 |
| 拍4 揭秘 | 05 身份钩 | 背景反转 |

## 五、可迁移结论（4 条）

1. **任务型单元剧**：总纲给方向（取经），单元给爽点（一难）——长线连载的可持续结构。
2. **群像分工**：每个角色承担唯一功能（战力/吐槽/稳重），避免角色冗余。
3. **反派分层 + 背景揭秘**：妖怪按"背景"分层，揭背景即反转（身份钩），可持续制造爽点。
4. **目标锚防注水**：明确终局（取经达成）约束节奏，避免无限续命。
