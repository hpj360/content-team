# 拆解案例：莫泊桑《我的叔叔于勒》（公版）

> 类型：短篇 ｜ 核心可迁移：**期待落差**、**阶层势利**、**以"认出"为转折**。
> 本文件只做结构分析，不含原文全文。适用：`novel-writing`（都市/现实）、`script-writing`。

## 一、骨架（一行式）

```
全家期待富豪叔叔归来（改善阶层） → 旅行中偶然认出落魄的于勒 → 全家躲避、装作不认识
```

- 张力来自**期待的建构**与**现实的瞬间戳破**。
- 转折不是事件，而是**一次"认出"**——认知即转折。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 期待建构 | 用日常细节堆出对富豪的期待 | 期待越具体，落差越痛 |
| 期待来源 | 一封旧信（可反复引用的物证） | 用物证承载"希望" |
| 认出 | 关键转折靠一个具体识别符 | 识别符 = 转折触发器 |
| 躲避 | 人物的反应暴露阶层势利 | 用"行动"写道德，不用评论 |
| 冷收 | 不评判，只呈现 | 把判断交给读者 |

## 三、节拍条

```
拍1 期待：全家反复念叨叔叔（旧信为证）
拍2 机会：旅行（阶级跃升的幻想）
拍3 认出：甲板上的卖牡蛎者（识别符）
拍4 躲避：父母装作不认识（行动暴露势利）
拍5 冷收：钱数着过日子（无声的讽刺）
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 期待 | 04 期待钩 | 期待富豪归来 |
| 拍3 认出 | 03 反转钩 | 期待崩塌 |
| 拍5 冷收 | 无（冷收） | 讽刺不点破 |

## 五、可迁移结论（3 条）

1. **期待落差公式**：先让读者与角色共同建构期待（具体到细节），再用一个识别符戳破——落差即冲击。
2. **识别符触发转折**：用可画的识别符（旧衣、口音、手上的疤）作为"认出"的开关（与分镜锚点同源）。
3. **行动写道德**：不评论势利，只写"他们躲开了"——判断留给读者（对应禁旁白式心理描写）。
