# 拆解案例：鲁迅《药》（公版）

> 类型：短篇 ｜ 核心可迁移：**双线并置**、**象征蒙太奇**、**看客群像**。
> 本文件只做结构分析，不含原文全文。适用：`novel-writing`（现实/象征）、`directing`（象征调度）。

## 一、骨架（一行式）

```
线A：华家为救子买"人血馒头" → 线B：革命者被处决 → 两线在"坟场"交汇 → 双坟并置
```

- 两条线**各自独立推进，在结尾空间交汇**（同一坟场，两座坟）。
- 主题不靠陈述，靠**并置产生的意义**（药/血/坟的象征）。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 双线并置 | 两条因果不相干的线 | 让"无关联"的两线在结尾交汇产生讽刺 |
| 象征物 | 馒头/血/花环/坟 | 用可指认的物承载主题 |
| 看客群像 | 围观者的冷漠 | 用群体反应替代道德评论 |
| 空间交汇 | 坟场（两线相撞） | 用一个空间完成结构收束 |
| 花环（细节） | 一丝微光，不点破 | 冷收中留一线希望 |

## 三、节拍条

```
拍1 线A：买药（救子）
拍2 线B：行刑（革命者）
拍3 线A：服药无效
拍4 交汇：坟场（两座坟并置）
拍5 收束：花环（冷收留白）
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 买药 | 04 期待钩 | 期待药有效 |
| 拍3 无效 | 03 反转钩 | 期待落空 |
| 拍4 交汇 | 10 情感钩 | 结构性的悲悯 |

## 五、可迁移结论（3 条）

1. **双线并置**：让两条互不相干的线在**结尾同一空间**交汇，意义由并置自动产生（无需解说）。
2. **象征蒙太奇**：馒头/血/坟——象征物可指认、可拍摄（适配导演的象征调度与风格包）。
3. **冷收留一线**：结尾的"花环"给一丝微光而不点破——比彻底绝望更耐读。
