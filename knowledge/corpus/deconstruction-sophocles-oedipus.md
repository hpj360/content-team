# 拆解案例：索福克勒斯《俄狄浦斯王》（公版）

> 类型：古典悲剧 ｜ 核心可迁移：**命运反讽**、**调查即自证**、**认罪即毁灭**。
> 本文件只做结构分析，不含原文全文。适用：`novel-writing`（悬疑）、`showrunning`（多线）。

## 一、骨架（一行式）

```
为解瘟疫而追查凶手 → 层层线索指向自己 → 真相揭晓 → 自惩（刺目/流放）
```

- 主角是**调查者**，也是**被调查的对象**——每一次调查都在逼近自己的毁灭。
- 张力来自**观众（或读者）已知的宿命**与角色不自知的追问之间的落差。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 谜面 | 瘟疫（外部危机驱动调查） | 用公共危机开启调查 |
| 调查链 | 证人/神谕逐层指向真相 | 线索链（对应剧本杀机制） |
| 反讽 | 主角的每个努力都加速厄运 | 让主角的努力本身成为阻碍 |
| 认罪 | 真相即自我定罪 | 反转不靠外力，靠主角自证 |
| 自惩 | 刺目（象征）+ 流放 | 结局动作具象化主题 |

## 三、节拍条

```
拍1 危机：瘟疫，求神谕
拍2 调查一：追查凶手（誓言严惩）
拍3 调查二：证人逐步指向"外乡人"
拍4 调查三：唯一幸存者揭示真相
拍5 反讽顶点：主角发现凶手是自己
拍6 自惩：刺目、流放（以动作收束）
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 危机 | 02 危机钩 | 公共危机 |
| 拍3 证人 | 07 秘密钩 | 线索指向未知 |
| 拍5 自证 | 03 反转钩 | 认知彻底重估 |
| 拍6 收束 | 12 代价钩 | 以自惩完成代价 |

## 五、可迁移结论（3 条）

1. **调查即自证**：让主角的调查**指向自己**——最强的悬疑结构（主角越努力越危险）。
2. **努力即阻碍**：主角的行动力反过来推进厄运，比"外力阻挠"高级（避免被动主角）。
3. **结局用象征动作**：刺目（拒绝面对真相）比任何总结句有力——对应本项目"外化为可拍摄动作"。
