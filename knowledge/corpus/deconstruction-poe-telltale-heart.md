# 拆解案例：爱伦·坡《泄密的心》（公版）

> 类型：哥特恐怖短篇 ｜ 核心可迁移：**不可靠叙述者**、**感官放大**、**自白即崩溃**。
> 本文件只做结构分析，不含原文全文。适用：`novel-writing`（恐怖/悬疑）、`directing`（恐怖风格）。

## 一、骨架（一行式）

```
叙述者自白（否认疯狂） → 谋划杀人 → 藏尸 → 幻听心跳 → 自首
```

- 全程**第一人称自白**，叙述者反复声称冷静，但语言本身暴露疯狂（不可靠叙述）。
- 恐怖不来自鬼怪，来自**叙述者自己的感官失控**。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 不可靠叙述 | 声称正常 vs 行为疯狂 | 让叙述者自我辩护，读者自行判断 |
| 重复动机 | "他的眼睛"（单一执念） | 用一个具体感官对象承载全部恐惧 |
| 感官放大 | 心跳声越来越响 | 声音作为恐怖载体（低成本高效） |
| 藏尸炫耀 | 处置"完美"（自得） | 得意即伏笔，得意越满崩塌越狠 |
| 自白崩溃 | 幻听压垮伪装 → 自首 | 结局由内在崩溃驱动，非外力 |

## 三、节拍条

```
拍1 自白：否认疯狂（不可靠信号）
拍2 执念：那双眼睛（重复动机）
拍3 谋划：七天观察（冷静的残酷）
拍4 行凶：感官细节放大
拍5 藏尸：炫耀"完美"
拍6 崩溃：心跳幻听 → 自首
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 自白 | 07 秘密钩 | 读者疑其不可靠 |
| 拍4 行凶 | 02 危机钩 | 紧张顶点 |
| 拍6 崩溃 | 03 反转钩 | 自曝 |

## 五、可迁移结论（3 条）

1. **不可靠叙述者**：让叙述者自证正常，读者从矛盾中读出真相（悬疑的高级形态）。
2. **声音即恐怖**：心跳/脚步/滴水——听觉比视觉更省成本且更不安（对应恐怖风格包的"留白与声音"）。
3. **得意即伏笔**：让角色在"成功"处充分自得，为崩塌蓄满落差。
