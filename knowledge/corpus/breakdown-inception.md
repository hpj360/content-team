## 二、规则卡 10 条（机制可复述+违规有代价；金句化程度=可破圈程度）

| 规则卡 | 机制（≤1 句） | 反噬条件 |
|---|---|---|
| R1 镇静分层与共享梦仪 | 药效深度决定可下几层与醒来次序 | 下得过深则中间层全部失守、无人叫醒 |
| R2 想法即病毒与可追溯植入 | 被植入的念头会自我生长并可被溯源 | 植入痕迹可被执念方反向追查 |
| R3 梦被打断即醒 | 中断刺激使本层梦者即刻返上一层 | 关键节点误入中断刺激=任务报废 |
| R4 死亡在各层去向不同 | 浅层死亡=醒来，过深=坠入边缘 | 深层误判"死亡=解脱"会反把队伍送进边缘 |
| R5 时间倍增的体感 | 层深每加一级，主观时间被拉长一级 | 计划按现实时长制定则深层数月化 |
| R6 Kicks 协议 | 坠落/重力冲击按层级次序逐层电击回传 | 多层同时kick须严格排队，错序即分岔 |
| R7 图腾判定真伪 | 只有本人知晓其物理性情的私物承担真伪判定 | 图腾被他人触碰即失去判定资格 |
| R8 投影人物会反扑 | 层内人影是共享者潜意识的防御机制 | 目标人物投影把私事带进任务层 |
| R9 梦主一人的世界 | 每层场景由梦主生成、他人仅共享出入 | 梦主情绪失控=全层物理失稳 |
| R10 潜意识边缘的时滞 | 边缘体感时间近乎无限、易失辨识 | 在边缘滞留越久越难与"真"对账 |

## 四、多线并行的读者理解表（观众如何"补追"落后一层：认知负载管理）

| 层深跳变 | 观众此刻的状态 | 复读锚（公开讨论口径：台词/画面回收作提示） | 负载管理 |
|---|---|---|---|
| 现实 → 一层 | 规则刚听完，段位未练 | 演示戏先"玩一次"规则再做任务 | 每层入场先给练习场戏 |
| 一层 → 二层 | 开始跟不上深层进度 | 上一层的半句台词在新层被复用作回声 | 落后信息不重复整句，只回收半句 |
| 二层 → 三层 | 需同时记三层各自的表 | 同一配乐在不同层以强弱差出现 | 双柱各自可见：时表+空间 |
| 三层 → 边缘 | 多数观众字幕级专注 | 重力事件与坠点镜头直接给答案 | 收束动作"演出"而不解释 |
| 回落期 | 需要把排队次序对齐 | 唤醒次序与坠落次序成镜像 | 给一张"逐层点名"的收束镜头 |

## 七、可迁移技法 6 条（BI-T1…BI-T6）

1. **BI-T1 多轨并行变体**：单集 8 拍模板的三线版升级为按"层深差"并行的四线版，各线节拍自持、合点唯一。
   落点 `skills/script-writing/references/beat-sheets.md`（单集 8 拍 P 系列并行版）。
2. **BI-T2 规则表先行**：开拍前先给"层级规则总表"，每层规则一次表清、条数与层深同增同减。
   落点 `skills/novel-writing/references/worldbuilding-guide.md`（世界观层级表置顶）。
3. **BI-T3 倒计时双柱**：时间轴（倍增表/总闸）与状态轴（kicks 队列/死亡去向）双校验，任一轴崩另一轴顶。
   落点 `src/hermes/content_team/creative/gates.py`（剧情 error 内核+节奏门禁的"双柱口径"）。
4. **BI-T4 概念台词**：一条规则配一句概念台词，台词即文档；短引用遵守 L2 纪律（≤2 句）。
   落点：知识库热梗资产 `knowledge/corpus/hot-quotes-memes.md`（"概念台词"条目的沉淀位）。
5. **BI-T5 悬念帧收尾**：留一个可作互文争议的定格帧收束，并保证戏内主题在帧前已自全。
   落点 `skills/script-writing/references/short-drama-playbook.md`（短剧结尾卡点/留白槽位）。
6. **BI-T6 错序对账**：信息以"后果帧→原因回填"错序摆放后逐格对账，节点×后果成表防断头。
   落点 `knowledge/corpus/paradigm-vertical-interactive.md`（分支回收对账口径）。
