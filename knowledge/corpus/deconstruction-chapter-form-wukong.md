# 拆解案例：章回体动作叙事范式（参考《黑神话：悟空》）

> **版权声明**：本文件为**方法论级结构分析**，不复制原作任何文本、台词、剧情细节或美术资产。
> 所分析的是"章回体制动作叙事"这一**公开讨论的范式**，《黑神话：悟空》作为该范式的当代代表。
> 适用：`novel-writing`（玄幻/西游题材）、`showrunning`（多卷/多章节奏）。

**《黑神话》四件套分工**：本篇=原著章回体结构范式；影神图档案工程见 `breakdown-blackmyth-yingshentu.md`；成品章节节拍见 `breakdown-black-myth-wukong.md`；游戏叙事系统方法见 `paradigm-game-narrative.md`。三篇不重复同一机制。

## 一、骨架（范式级）

```
章回体多卷结构：每卷一个独立小世界（地理+规则+悲剧内核）
  卷内：探索 → 遭遇 → 首领 → 卷终真相
  卷间：散落的"档案"文本逐步拼出主线全貌 → 多结局
```

- 主线不靠连续过场灌输，而靠**世界内散落的档案（图鉴/志怪笔记）**让玩家自行拼合。
- 每卷自成闭环（起承转合），同时服务主线拼图。

## 二、结构要素与可迁移点

| 要素 | 功能 | 可迁移到网文/短剧 |
|---|---|---|
| 章回标题 | 用对仗/典故标题预告本卷基调 | 卷首用"标题即剧透一半"的写法制造期待 |
| 卷内独立世界 | 降低连续叙事负担 | 一卷一地图（换地图即换情绪） |
| 首领＝主题化身 | 每个 BOSS 承载一种执念/悲剧 | 对手即主题：打赢他＝回应主题 |
| 档案式世界观 | 信息分散在可收集物中 | 伏笔分散在"信/志/物"里，让读者拼图 |
| 多结局 | 选择累积影响终局 | 长篇用"选择债"制造重读价值 |

## 三、可迁移叙事技法（4 条）

1. **档案式世界观**：把设定拆成**可收集碎片**（信件/碑文/图鉴），散布在章节里。
   - 对应本项目：伏笔登记进 `StoryState.foreshadowing`，`keyword` 逐章埋设，
     由 `gate_foreshadowing_lifecycle`（L004/L005）校验埋设/回收。
2. **对手即主题**：每个阶段对手不是"更强的数值"，而是主角某一种可能的结局
   （若他走另一条路会变成谁）。适用于玄幻/复仇题材的"镜像对手"。
3. **卷终真相**：每卷结尾揭露一个**重新定义前文**的信息（对应 03 反转钩），
   让读者回头重估已读内容。
4. **标题预告**：章回标题承载基调与暗示（如 `hook-library.md` 的期待钩变体），
   不要写成中性摘要。

## 四、对短剧/网文的落地模板

```
第X卷（第N1–N2章）　卷名：〈三字对仗标题〉
- 地图：新场景 + 新规则（一句话）
- 冲突：本卷对手（＝主题化身）
- 档案：3 条可收集伏笔（进 foreshadowing，标注 planned_resolution）
- 卷终：一条重定义前文的真相（反转钩）
- 卷尾钩：指向下一地图的升级钩（13 式之"升级钩"）
```
