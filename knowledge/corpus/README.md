# 语料库（Corpus）

> 真实作品的**结构化拆解**，作为 `novel-writing` / `script-writing` 的可迁移素材。
> 用于喂给拆文工作流（`case-breakdown.md`）与钩子库，**不复制原文**，只做结构分析。

## 目录

| 文件 | 作品 | 类型 | 可迁移点 |
|---|---|---|---|
| `deconstruction-chekhov-chameleon.md` | 契诃夫《变色龙》（公版） | 短篇 | 单一场景内的人物立场翻转、对话驱动 |
| `deconstruction-luxun-kongyiji.md` | 鲁迅《孔乙己》（公版） | 短篇 | 旁观者视角、细节复沓、悲剧留白 |
| `failure-corpus.md` | 综合 | 失败案例 | 常见失败模式的症状→机制→修复 |

## 版权声明

- 所选作品均属**公有领域**（作者逝世逾版权保护期）。
- 本库仅收录**结构分析、节拍标注与少量必要短语引用**，不收录原文全文。
- 新增案例优先选择公版作品；如需分析在版权期作品，只做**方法论级**分析与原创改写示例。

## 使用方式

1. 对照 `skills/novel-writing/references/case-breakdown.md` 的五步拆解法阅读；
2. 把可迁移结论回填到选题/模板（`GET /api/templates`）；
3. 拆解中的钩子式编号对应 `hook-library.md` 的 13 式。
