## 二、叙事结构范式（8 项机制）

| 机制 | 说明 | 可迁移 |
|---|---|---|
| 预制件强设定 | 制度/流程/文学句法被整体搬上舞台并字面执行 | 单集开场 15s 抛规则（对应 comedy-sketch 高概念前提） |
| 三拍装载 | 同一规则升级三次、每次改变代价维度 | 素描升级三拍+对账位（对应 gates 节奏波谱） |
| 认真人×失控怪人 | 一个对荒诞规则字面较真的人固有喜剧势能 | 站位卡"掌控者×破局者"的隔级用法（variety-show） |
| 元自反 | 作品谈论它所属的形式 | 单元集"收束即开门"的镜像变体 |
| 存量 IP 压力测试 | 借公版 IP 做任务重压（合法引用与遥远的资深记忆） | wu-journey-west 任务型单元剧范式 |
| 制度性差错累积 | 谐音/流程小错被计分、被复用呈现 | 硬门叠加的喜剧变体（防只崩不归拢） |
| 尾部情绪化 | 完归于真心调一收（笑中带泪） | comedy-sketch 情绪收尾；写作台细则 "卡点前 4s 情绪落" |
| 时效议题搭钩 | 把当下平台/社会议题挂进结构（时效提示：议题梗重退场） | platform-playbooks 段落钩子的议题前置版 |

## 二·补、知名作品逐案四段拆解（方法论级，公开报道/评论口径；每案情节细节 ≤2 句）

### 案 1《互联网体检》（2021）——制度具象化鼻祖

- **设定卡**：一场普通体检，每一步都被"平台会员制流程"接管（公开报道口径：护士插播广告、
  抽血要充会员、检查结果付费观看）。
- **结构骨架**：起手规则（体检=会员流程）→ 三拍升级（流程每一环各自再造一次付费门槛，
  代价从时间→尊严→性命位次递增）→ 不反转、以" exhaustion 成真新闻"收束。
- **台词技法**：客服话术的公益/商业双腔切换；重复报幕音承担规则刷新（"会员"复现即笑点价格牌）。
- **热梗与复用**：会员制词全域通用化→ 抽血充会员类"制度性荒词"句式可迁移；
  复用点：S-T1 预制件制度具象化 + platform-playbooks 议题前置。

### 案 2《少爷和我》（2022）——句式错位 CP

- **设定卡**：按霸总文句法字面生活的"少爷"忠仆 × 被守护得体现狼狈的普通人"刘波"。
- **结构骨架**：句法即世界观（单句违规=世界崩坏）→ 三拍升级（守护从公务到家务到越界情感）→
  尾部让位给"真情瞬间的破绽"（CP 反差产生情绪收尾）。
- **台词技法**：霸权句"这是通知，不是商量"承担世界观声明（L1 短引，公开流传口径）；
  "逆鳞"词升级＝权力句式的显错法。
- **热梗与复用**："少爷文学"被观众批量仿写；复用点：S-T8 句式骨架输出 + dialogue-examples 错位句。

### 案 3《小品的世界》（2024）——元喜剧自反

- **设定卡**：小品世界里的角色发现世界按小品规律运转（公开报道口径：吕严/何欢/邓帅，
  致敬春晚小品谱系；话题 #世界是一个巨大的小品#）。
- **结构骨架**：日常→发现规则（音效/笑点抢答/角色突然台词腔）→ 三拍升级（连物理规则都被小品化）→
  以"拒绝笑点的自由"收束（安全出口的自反点题）。
- **台词技法**：公共记忆索引合法化世界规则（"装修离不开黄大锤"，公开报道口径）；
  台词韵律自身即包袱（节奏先于语义）。
- **热梗与复用**：作品名升格为世界观级话题词；复用点：S-T4 元自反 + wu-journey-west 任务锚变体。

### 案 4《八十一难》（2024）——存量 IP 压力测试

- **设定卡**：把"八十一难"的任务当量重压交给一组小人物反复实测（公开评论口径：
  第一赛段最高分作品之一）。
- **结构骨架**：任务锚（凑满八十一难）→ 三拍升级（每难-than-难一代差性荒谬）→
  尾部把"被迫的内卷"翻译成真诚抱怨（情绪出口）。
- **台词技法**：数字计分（"第 X 难"复现）承担拍子显示；
  公版 IP 引用合法化一切荒谬（引用纪律：仅作任务壳，不引用原文情节）。
- **热梗与复用**："内卷文学"化的任务计数；复用点：S-T5 存量 IP 压力测试 + 章回体拆解的任务锚。

### 案 5《大侠别动手》（2024）——极简结构口碑

- **设定卡**：话痨派靠拖住行动派把江湖小事拖出更大的江湖后果（公开评论口径：
  结构极简却令人深省）。
- **结构骨架**：三拍极端简化（拖→被拖→反被拖）→ 反转来自"动手派最后也没动手"的自反;
  **台词技法**：话痨的"预告式废话"在动手瞬间前完成威胁计时（对应昆汀"闲谈即炸弹"的舞台同源）。
- **热梗与复用**："迟到的大侠"式公共叙事；复用点：S-T2 三拍装载 + paradigm-variety-show 翻盘点位置。

## 三、表演与舞台语言（演播工况口径）

- **无剪辑纪律**：素描在舞台上一次成型，节奏靠表演音乐节奏而非剪辑——
  每一拍必须自带"重置拍"（停顿/转身/道具归位），给观众回位。
- **道具外化焦虑**：计数器/价签/盖章把抽象规则物化成可被反复展示的喜剧对象。
- **服装=辨识度资产**：一句"人设行头"（歪领、标注句/制服混搭）跨作品复用。
- **音效点位**：宣告音/失败音分类即 情绪标点（对应 sound-and-edit-craft 分层登记）。

## 六、可迁移技法（8 条，S-T1…S-T8）

1. **S-T1 预制件制度具象化**→ `deconstruction-comedy-sketch.md` 高概念前提 + platform-playbooks 议题前置。
2. **S-T2 三拍装载对账**→ `creative/gates.py` 节奏波谱（替换 beat 频次表每拍须变维度）。
3. **S-T3 认真人站位**→ `skills/storyboarding/references/vertical-shot-grammar.md` 单人情绪位 + `paradigm-variety-show` 站位卡第四人。
4. **S-T4 元自反样本**→ 作品内布局引用自身形式（short-drama-example-waimai 的 8 拍表可自指提醒）。
5. **S-T5 存量 IP 压力测试**→ `deconstruction-wu-journey-west.md` 任务锚 + 版权纪律（公版引用不复制原文）。
6. **S-T6 差错累积计分**→ `StoryState.foreshadowing` 登记口径的差错变体（差错复现 ≥2 即成梗位）。
7. **S-T7 尾部情绪落**→ `beat-sheets.md` 单集 8 拍 P6 代价/P8 出口（卡点前 4s 留情绪帧）。
8. **S-T8 句式骨架输出**→ `dialogue-examples.md` "可造句"句法打包（观众二创即免费续命）。
