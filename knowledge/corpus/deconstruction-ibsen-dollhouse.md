# 拆解案例：易卜生《玩偶之家》（公版）

> 类型：三幕话剧 ｜ 核心可迁移：**三幕突转**、**秘密倒计时**、**以声收尾**。
> 本文件只做结构分析，不含原文全文。适配短剧/长剧的"家庭伦理"题材。

## 一、骨架（一行式）

```
家庭表面美满 → 旧秘密被抓住把柄 → 丈夫只保自己不保妻 → 觉醒出走（关门声收场）
```

- 张力来自**秘密的暴露倒计时**与**关系的体面崩塌**。
- 高潮不是外部灾难，而是**主角对关系本质的认知反转**。

## 二、三幕与突转

| 幕 | 功能 | 关键动作 |
|---|---|---|
| 第一幕 | 建置假象 | 交代体面生活，埋下秘密（借款） |
| 第二幕 | 施压收紧 | 债主利用秘密施压，主角独自承担 |
| 第三幕 | 突转与觉醒 | 秘密公开；丈夫只顾自保；主角认清关系本质后出走 |

- **突转点**：丈夫读完信后第一反应是"我怎么办"，而非"你怎么样"。
- 觉醒由**一个反问**推动，不需要长篇独白。

## 三、细节与收尾技法

- **门响**：结尾不写主角的心理感受，用一个**可听见的动作（关门）**收场，
  成为全剧最有力的标点，也是后世无数作品的模仿对象。
- **对比道具**：信件/借据作为"秘密"的可视化载体，随剧情转移控制权。
- **可迁移**：终局用**一个具体声音/动作**代替情绪总结（对应本项目"外化为可拍摄动作"
  与 S005 禁旁白式心理描写）。

## 四、钩子式映射（对照 13 式）

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 一幕末 | 07 秘密钩 | 借据秘密被债主掌握 |
| 二幕末 | 02 危机钩 | 秘密即将公开 |
| 三幕中 | 03 反转钩 | 丈夫自保，关系本质被揭穿 |
| 三幕末 | 无（以声收尾） | 关门声＝终局标点 |

## 五、可迁移结论（3 条）

1. **家庭伦理三幕模板**：假象 → 秘密被拿捏 → 认清关系本质 → 以具体动作收场。
2. **觉醒靠一个反问**：不要独白，用一句反问 + 一个动作完成人物弧线
   （可写入 `StoryState.characters` 的"心理/目标"维度变化）。
3. **声音收尾技法**：终章用门响/脚步/挂断声等**可听动作**替代总结句，
   适配短剧最后 5 秒的强收束。
