# 题材案例对照集（按题材横向对比）

> 把 `knowledge/corpus/` 的案例**按题材归类横向对照**，便于"同题材找多个参照"。
> 每个题材给出：可用案例 / 共同结构 / 差异化技法 / 推荐组合。

## 一、悬疑/推理

| 案例 | 提供什么 |
|---|---|
| 《俄狄浦斯王》 | 调查即自证、命运反讽 |
| 《泄密的心》 | 不可靠叙述、感官放大 |
| 剧本杀高分机制 | 视角分割、线索链、信息公平 |
| 《罗生门》 | 多视角同一事件 |

**共同结构**：谜面 → 线索分层 → 误导 → 反转重估。
**差异化**：俄狄浦斯重"结构性反讽"，坡重"心理不可靠"，剧本杀重"机制公平"，罗生门重"真相不可知"。
**推荐组合**：线索链用剧本杀范式 + 反转用俄狄浦斯式重估 + 叙述层用坡式不可靠。

## 二、都市/现实

| 案例 | 提供什么 |
|---|---|
| 《项链》 | 欲望—代价、时间跳跃、结尾反转 |
| 《变色龙》 | 单场景立场翻转、对话驱动 |
| 《孔乙己》 | 旁观者视角、识别符复沓 |

**共同结构**：小人物处境 → 处境恶化/翻转 → 冷收。
**差异化**：莫泊桑重"欲望自招"，契诃夫重"信息驱动翻转"，鲁迅重"旁观者折射"。
**推荐组合**：短剧单集用变色龙式立场翻转 + 长线用孔乙己式旁观视角。

## 三、爱情/情感

| 案例 | 提供什么 |
|---|---|
| 《麦琪的礼物》 | 双向牺牲、镜像结构、先失望再升华 |
| 《玩偶之家》 | 关系本质揭穿、以声收尾 |

**共同结构**：关系建立 → 事件施压 → 认知/情感反转 → 具体动作收束。
**差异化**：欧·亨利重"对称牺牲"，易卜生重"觉醒与出走"。
**推荐组合**：单集高潮用双向牺牲模板；关系终局用"关门声"式具体动作。

## 四、恐怖

| 案例 | 提供什么 |
|---|---|
| 《泄密的心》 | 声音恐怖、得意即伏笔、不可靠叙述 |

**补充范式**：恐怖风格包（高光比 + 少动 + 留白）见 `style-pack-library.md`。
**结构**：日常秩序 → 异常细节 → 不拍全的威胁 → 直视收束。

## 五、喜剧/综艺

| 案例 | 提供什么 |
|---|---|
| 商业素描范式 | 高概念前提、升级三拍、回调、笑中带泪 |

**结构**：立规则 → 升级×3 → 反转 → 情绪收尾。配套 `comedy-sketch-structure` 模板。

## 六、玄幻/动作

| 案例 | 提供什么 |
|---|---|
| 章回体范式（参考黑神话悟空） | 档案式世界观、对手即主题、多卷结构 |

**结构**：卷内独立小世界 → 卷终真相 → 主线拼图。配套 `genre-xuanhuan-techniques.md`。

## 七、使用方式

1. 选题确定题材 → 从本表取 2–3 个案例；
2. 对照"共同结构"定骨架，用"差异化技法"定特色；
3. 技法要点落 `StoryState`（规则/人物/伏笔），由门禁校验。
