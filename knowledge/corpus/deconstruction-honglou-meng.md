## 一、定位与命题

- 中国叙事文学最完整的"**档案先于剧情**"系统：第五回"太虚幻境"一场即公开登记全书主要
  人物的命运档案（薄命司册页判词+《红楼梦曲》双轨预告，公开通行口径）——结局先入场，
  过程后展开，读者全程"自带答案读戏"。
  这是连载工具尚未出现时的手工版伏笔账本：结局先入库，正文逐条销账。
- 它与常规故事相反：**不是情节炸出结局，而是档案驱动情节**——后面每一段热闹，读者都会
  拿去和第五回那份预登记记录对账——读者的日常行为变成"对账"，悬疑由解码完成。
- 一行命题：**用"预登记的结局"把宿命感做成叙事基础设施**。

## 二、判词系统拆解（8 条机制）

条目公式（第五回薄命司册页+《红楼梦曲》，合并读取口径）：

```
册页条目 = 一画（图谶）+ 一判诗（四行韵语）→ 冷档案（结果层）
曲谱条目 = 一支曲文（咏叹）              → 热档案（情绪/因果层）
两套同源、分轨发行：判词条说"是什么"，曲文说"为什么、有多痛"。
```

1. **判词=隐喻加密的人生摘要**：第五回薄命司册页按"又副册→副册→正册"分层装订人物档案，
   每条=一画（图谶）+一判诗（四行韵语）的双码条目。
   命运如实登记却全盘加密：画中物象代替姓名，谐音暗指结局——读者拿到的是谜面而非谜底，
   是"提前剧透而不减悬念"的原生解法。
   加密还完成二级任务：谜面留白让后续情节无需反复补说明——档案在场即宣言。
2. **判词与《红楼梦曲》双轨预告**：同一批人物的结局由两套系统各登记一遍——册页判词给
   结果（冷档案），《红楼梦曲》补情绪与因果（热咏叹，其《收尾》一支直接预告全局清空）。
   预言冗余度设计：两条公开线索互为校验，单条读不懂，合并仍能闭合成完整命运图。
   现代对应：冷档案=状态卡登记，热档案=章尾情绪收束——两处存的是同一笔伏笔。
3. **真假互文系统**：太虚幻境联句公设"真/假"双变量（见四、金句表条 2）——府中叙事
   始终对着一本双层账书写；风月宝鉴"正照/反照"是变量开关的道具化原型；
   甄贾宝玉=主变量的镜像对拷。
   读者须同时做两份解读作业：表层一份，里层一份，两层互文不互斥。
4. **草蛇灰线、伏脉千里（公开讨论口径）**：一件器物、一句谶语、一次宴间口占、
   一张药方或一份租单，都可作远期事件的登记处，数十回后原样兑现。
   伏笔跨度以"卷"计、登记在公开文本内部——与 season 状态卡的伏笔登记制同构
   （登记→埋设→回收，三态可查）。
   它同时是社群机制：读者凭公开谜面自行开列预答卷，正文每推进一段即"验收"一次。
5. **框架回环**：首回以"无材补天"的弃石总纲起头；末回在"白茫茫大地"的图景中兑现收尾，
   而该图景早在第五回末曲即已预告——第一回就发布了全书自身的结局预告，开卷与收尾对称成环。
   完结感由框架承担而非情节自证：框架先宣布"此地终将清空"，读者以告别心态读全过程。
6. **空间=关系地形**：大观园分房即性格外化：竹宅对一人、素净雪洞对一人、富丽群芳居中
   收拢——空间分配就是人物档案的可读版。
   一次游园/入园仪式即群像站位图：角色不出场，人格已被房子先说出。
   现代对应：分镜脚本里的"领地分配"——谁的舞台谁站位，场景色板即人物色板。
7. **诗风识人**：限题限韵的赛诗会=同题比稿：同一题目之下，作诗的口气差异即人物简历，
   不看署名也能对号入座（诗社、联句、题对额皆同一机制的变体）。
   群像"口气差异化"的极限实现：声口即身份，文体即脸。
   同题比稿是可移植的群像测试：把所有角色放进同一道题，声口差异一览无余。
8. **账本叙事**：乌进孝交租单（第五十三回）等实务段落用明细流水写大厦将倾——
   租项逐年缩水、旧例难以对支的账目，比抒情更冷。
   economy 线索自成叙事线："从账目读气数"是数字叙事的文学史源头；
   本文仅机制级登记，不照录账目原文。

## 六、可迁移技法（6 条，HL-T1…HL-T6）

1. **HL-T1 判词=章首伏笔登记卡** → StoryState.foreshadowing（planted_at/登记—埋设—回收
   口径）：每卷首公开一张"谜面卡"，数十集后履约；台账自动预警未回收伏笔——
   防烂尾的档案化方案。
2. **HL-T2 空间=性格** → `writing_desk` 场景表 / `shot-patterns` 站位：把人物档案字段
   投射为场景布置（色调/器物/密度），"分房"即站位卡——群像关系不用台词也能读。
3. **HL-T3 诗风识人** → `character-bible` 台词签名：限题限韵同稿竞技，靠声口差异完成
   群像——"台词签名"字段的古典源头（无署名也能对号）。
4. **HL-T4 账本叙事** → `paradigm-urban-business.md`（互引）：用账目/流水写利害与盛衰，
   数据段落即关系武器化的段落——商业文的数字对账与此处的租单同源同向。
5. **HL-T5 真假双城** → `paradigm-vertical-interactive.md`（互引）：太虚幻境/甄贾宝玉=
   变量双层的文学原型——里外两层真相、同一情节双账本，互动叙事的开关机制古已有之。
6. **HL-T6 框架回环** → `deconstruction-chapter-form-wukong.md`（互引）：章回体首尾对称法
   在红楼的收拢——第五回判词与末曲对开大回环，完结感由框架而非情节兑现。
