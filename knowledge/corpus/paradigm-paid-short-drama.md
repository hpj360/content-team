## 二、叙事结构范式（8 项机制）

| 机制 | 说明 | 可迁移 |
|---|---|---|
| 免费前 3 集转化窗 | 前集免费蓄积流量，卡点落在付费墙前，付费决策被设计为"一次选择即代价" | 单集 8 拍的 P7 悬置恰放收银台前 |
| 单集钩链卡点 | 集集钩子链环环相扣，卡点取钩子峰值：信息刚抛出、将揭未揭 | `beat-sheets.md` 单集 8 拍卡点自检 |
| 投流素材＝正片高潮切片 | 投放素材直接取正片信息密度最高的 3–5 秒：写作阶段就要预埋"可切片高潮" | 写作台逐集登记"切片位" |
| 数据口径的平台敏感性 | 红果 2025-04 起热度统计周期缩短至 7 天并取消热力值上限（平台口径影响数据口径） | 战报数据必须注明统计周期口径 |
| 厂牌人设复利 | 听花岛（温情现实主义、团队 5 年从业含长剧背景、豆瓣 8.1 背书，公开报道口径）；马厩制片厂（广告导演创始人、"细糠"镜头语言、氛围感顶流） | 交付物附厂牌风格卡与镜头语言要求 |
| 保本率与爆款概率的成本结构 | 九州文化公开自述：1600+ 部、月上线 30–50 部、约 70% 保本、30% 扑街风险——以量摊销不确定性 | 量产线的季级排播与保本线设计 |
| 精品化 2.0 | 以镜头语言与细节铺陈替代强冲突三件套，"卷流量"转向"抓内容"（公开报道口径） | storyboard 镜头密度与氛围铺陈对标 |
| 监管纠偏＝题材合规护栏 | 2025-09-25 广电总局公开表态对"雷人剧情""霸总人设"纠偏（公开报道口径） | gates 提交前跑题材红线清单 |

2025-06 红果短剧 App 月活 2.12 亿、超优酷（QuestMobile，公开报道口径）：平台体量决定该范式的工程级优先级。

机制选用规则：叙事侧至少落实"转化窗＋钩链卡点＋厂牌人设"三项；投放与分账工程（第三章）为**必修而非加分项**——付费微短剧的剧本合约须预埋切片位与数据口径约定，否则无法结算回收。

## 三、变现与投放工程（非叙事，但必须拆）

- **投流素材三件套（公开报道口径归纳）**：
  1. **正片高光 3–5s 切片**：取全片信息密度最高处直接当广告；
  2. **前后抓取**：素材首尾设计与正片入口跳转链路的衔接（把注意力抓进正片）；
  3. **字幕大字报**：竖屏无字幕不成立，字幕即素材文案本身。
- **分账与保本模型表（公开报道口径：红果自制剧分账）**

| 项 | 公开口径 | 工程含义 |
|---|---|---|
| 单月规模 | 8 月自制剧分账单月破 5000 万 | 分账池对内容方是规模化现金流 |
| 单部剧本分账 | 有案例超 30 万 | 剧本独立计价、可议价 |
| 品类激励 | 最高 75 万 | 品类选择＝收益上限变量 |
| 成本结构 | 九州约 70% 保本、30% 扑街风险（公开自述口径） | 保本线设计先于爆款设计 |

- **"素材量≠播放"反例**：《盛夏芬德拉》投流素材量仅为《家里家外》的 34.7%（公开报道口径），播放增速反而最快破 30 亿——素材是放大器不是引擎，本体的钩链密度与转化窗设计才决定转化效率。
- **投放与内容的工程分工（方法论）**：
  - 内容侧负责"可切片高潮位"的预埋（写作阶段锁定每集切片点）；
  - 投放侧负责素材吞吐与前后抓取链路（可大规模工业化，但不弥补内容缺口）；
  - 数据侧负责战报口径自检：统一注明统计周期与平台口径，跨平台不可直接对齐。

## 六、可迁移技法（8 条，R-T1…R-T8）

1. **R-T1 两分钟内核计转化** → `paradigm-vertical-interactive` 的两分钟内核，前 3 集＝3×内核纪律，付费墙前必须留完整内核回路。
2. **R-T2 P7 悬置即收银位** → 单集 8 拍 P7（悬置/呼吸拍）恰放付费墙与卡点前：呼吸拍不强解钩子，答案押下一集。
3. **R-T3 卡点峰值自检** → `skills/script-writing/references/beat-sheets.md` 单集 8 拍卡点检查（P7 钩子式与相邻集不重复）。
4. **R-T4 翻盘点＝改判预埋** → `paradigm-variety-show` 翻盘点机制迁移为"付费墙前的低点改判"，切片高潮位取全场最低谷。
5. **R-T5 评测迭代制** → `src/hermes/content_team/creative/quality_eval.py` 固定钩位×变体离线评测：对"切片位/卡点文案"做变体 A/B。
6. **R-T6 平台规则对齐** → `skills/showrunning/references/platform-playbooks.md` 红果/抖音条目：格式×节奏×变现×审核，战报注明统计周期口径。
7. **R-T7 名场面外化** → `knowledge/corpus/hot-quotes-memes.md` 第五节：音乐外化物/氛围名场面独立出圈，声音签名绑定作品情绪。
8. **R-T8 题材合规护栏** → `src/hermes/content_team/creative/gates.py` 提交前跑"雷人剧情/刻板人设"红线清单，监管口径持续复审。
