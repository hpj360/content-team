## 一、骨架（范式级）

```
双向心动（读者全知） → 单侧误解（人物半知） → 三层误会递进 → 戳破时机 → 代价兑现 → 体面和解
```

- 核心张力不是"爱不爱"，而是**读者知道、人物不知道**：双向心动对读者是明牌，
  对人物是暗牌，这层信息差就是误会引擎的燃料。
- 好误会的本质是"说破的代价比沉默高一档"：每进一层，讲清的成本都更大，误会才滚得动。

## 二、三层误会递进（核心机制）

| 层级 | 类型 | 典型形态 | 可迁移 |
|---|---|---|---|
| 第一层 | 信息差 | 看错场面、听到半句话、道具被错认 | 一句话可解，却恰好无人说破 |
| 第二层 | 身份差 | 隐藏的身份或关系被误读，误会开始改变相处方式 | 误会"转正"为关系设定，再难撤回 |
| 第三层 | 立场差 | 误会外化为利益对立，两人各持对的理由 | 冲突从"误会"升级为"选择题" |

- 三层必须**换引擎**：第一层靠没说，第二层靠身份，第三层靠立场；同一层重复加码会耗尽耐心。
- 每层误会都要**双伤**：只单边吃亏就成了苦情戏，双方都被误伤才有双向奔赴的重量。
- 递进的方向是**从可说破走向不敢说破**：越往后，误会的缺口越靠近人物的软处，
  于是一个本可以两句对话解开的结，最终变成一段必须从头重来的关系。

## 三、可迁移技法（5 条）

1. **读者全知半步定律**：让读者比人物早半步知道真相（或早半步知道误会），
   误会期间的每一次"差点说破"都是免费钩子。
2. **说破阻断器**：在关键节点放一个合乎人物逻辑的打断（来电、第三者一句话、自身的退缩），
   阻断必须源于人物性格，不许靠强行降智续命。
3. **戳破时机定律**：在感情最深、代价最大时戳破，误会才有回报；早戳不疼，晚戳注水。
4. **代价要落地**：戳破后必须有真实损失（时间/机会/关系），和解的价值由兑现的代价称出。
5. **体面化解红线**：误会必须可由人物自己的行动体面化解（坦白、补救、双向让步），
   禁止靠第三方一锤定音或突发意外收场。

## 四、误会引擎模板（可直接填）

```
前提卡：双向心动为明牌 + 一个天生自带的误会装置
第1层（信息差）：前 2 章 埋误会 → 每章一次"差点说破"
第2层（身份差）：第 3–5 章 误会转正为相处设定 → 升温与互伤并行
第3层（立场差）：第 6–8 章 误会外化为对立 → 双方各持对的理由
戳破点：第 8–9 章 感情最深处摊牌 → 代价兑现一次真实损失
和解段：第 9–10 章 双向坦白 + 由误会衍生的补救行动 → 体面收束
```
