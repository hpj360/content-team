# 短剧单集结构示例：外卖员逆袭（原创）

> 类型：竖屏短剧 ｜ **原创示例**（非公版作品），用于演示 `short-drama-genres.md`
> 的"复仇打脸"题材与 `beat-sheets.md` 的单集 8 拍如何落地。

## 一、单集目标

- **本集功能**：受辱集（欠），建立缺口与反派层级，结尾抛强钩子。
- **题材标签**：复仇打脸 / 都市。
- **集尾钩子式**：05 身份钩（对照 `hook-library.md`）。

## 二、8 拍落地（90s）

```
P1 冷开场(0-3s)   洗碗池里漂浮的工牌，水面上映出"李默"
P2 兑现(3-15s)    上集钩：主管把外包合同拍在他脸上
P3 施压(15-35s)   主管当众宣布：外包工不配用员工餐厅
P4 回击(35-55s)   李默打开手机——昨晚拍的"高档食材被倒进泔水桶"视频，只播了 3 秒
P5 反转(55-70s)   人群中有人认出：泔水桶上贴着"董事专用"
P6 代价(70-78s)   主管抢过手机砸在地上，屏幕碎——但视频已自动上传云端
P7 悬置(78-85s)   主管手机响（画外）："什么？总部要调监控？"
P8 出口(85-90s)   碎屏亮起，弹出消息：「明早九点，总部见」
```

## 三、结构要点

- **压→爆配比**：本集以"压"为主（P1–P4 只给 3 秒回击），符合"铺垫集"定位。
- **卡点**：放在 P7 的钩子峰值（信息刚抛出、真相将揭未揭）。
- **信息即剧情**：P5 的转折不靠新事件，靠**一个新信息**（桶上的标签）——
  与契诃夫《变色龙》"信息驱动翻转"同源。
- **外化**：P6 用"抢手机"这个动作表现压力，不写"他很慌张"（对应 S005）。

## 四、下一集衔接（悬念清单）

| 悬念 | 回收计划 |
|---|---|
| 总部为何调监控？ | 第 3 集揭：主角身份被 HR 系统误录 |
| 云端视频会不会被删？ | 第 2 集冲突：主管找人删数据失败 |
| "董事专用"桶的主人是谁？ | 第 3 集埋、第 6 集回收（进 `StoryState.foreshadowing`） |

## 五、可迁移结论

1. **铺垫集公式**：冷开场承接 + 两次施压 + 3 秒回击 + 信息反转 + 强钩子。
2. **信息驱动反转**：优先用"发现新信息"而非"发生新事件"做反转，成本更低、更可复用。
3. **悬念进状态卡**：每条未回收悬念登记 `planned_resolution`，由
   `gate_foreshadowing_lifecycle`（L004/L005）在回收章校验。
