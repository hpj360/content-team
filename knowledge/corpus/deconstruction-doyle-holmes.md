# 拆解案例：柯南·道尔《福尔摩斯探案》（公版）

> 类型：侦探短篇集 ｜ 核心可迁移：**单元剧系列化**、**主角魅力即 IP**、**可复用推理模板**。
> 本文件只做结构分析，不含原文全文。**系列化单元剧的爆款原型**。

## 一、骨架（一行式）

```
委托上门（异常）→ 现场勘察（观察）→ 推理链 → 揭示（复盘式解释）
```

- 每个故事**自闭环**（可任意顺序阅读），但主角魅力跨篇累积 → **IP 化**。
- 系列爆款的关键不是情节，而是**主角 + 稳定的结构模板**。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 固定主角组合 | 天才侦探 + 普通人视角（记录者） | 双人组合 = 观众代入锚 |
| 单元闭环 | 每篇独立案件 | 短剧/系列每集可独立看 |
| 稳定模板 | 委托→勘察→推理→揭示 | **可复用骨架**（工业化生产） |
| 观察即线索 | 细节（袖口/泥土）指向真相 | 线索公平（见悬疑技法库） |
| 复盘式揭示 | 结尾由主角讲解推理 | 观众"原来如此"的满足感 |

## 三、节拍条（单篇模板）

```
拍1 委托：异常事件上门（钩子）
拍2 勘察：现场细节（信息钩）
拍3 调查：排除/验证（误导）
拍4 推理：链条闭合
拍5 揭示：复盘 + 真相（反转钩）
拍6 收束：余味（人物/主题）
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 委托 | 07 秘密钩 | 异常待解 |
| 拍2 勘察 | 11 信息钩 | 细节线索 |
| 拍5 揭示 | 03 反转钩 | 真相揭示 |

## 五、可迁移结论（4 条）

1. **单元剧工业化**：固定结构模板 + 可变案件 → 可稳定量产（适配短剧/系列短视频）。
2. **双人组合代入**：天才 + 普通视角（"我"）→ 观众借普通人提问、借天才获得解答。
3. **主角即 IP**：跨篇累积的是**人物魅力与关系**，情节可换——系列化的本质。
4. **复盘式满足**：结尾让主角"讲清楚"（公平推理）→ 观众获得智性满足，而非被糊弄。
