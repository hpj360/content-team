# 拆解案例：高分剧本杀的结构机制（范式级）

> **版权声明**：本文件为**方法论级结构分析**，不复制任何商业剧本杀的剧本、角色本、线索卡或台词。
> 所分析的是剧本杀（Murder Mystery / 还原类桌游）的**通用高分机制**。
> 适用：`script-writing`、`showrunning`（多视角/多线叙事）、`novel-writing`（悬疑）。

## 一、骨架（范式级）

```
个人角色本(私视角) → 公共线索 → 时间线碰撞 → 还原真相 → 反转/二次反转 → 结局分支
```

- 核心乐趣不是"找出凶手"，而是**信息不对称下的拼图**：每人只知一角。
- 高分剧本的关键在于**信息分配的公平与反转的伏笔密度**。

## 二、高分机制清单

| 机制 | 说明 | 可迁移 |
|---|---|---|
| 视角分割 | 每个角色掌握不同关键信息 | 双线/多线叙事（各线只给一半） |
| 时间线碰撞 | 同一时段不同人的说法互相矛盾 | 悬疑小说的"证人矛盾" |
| 线索链 | 线索 A 指向 B，B 解锁 C | 伏笔链（进 `foreshadowing`） |
| 反转即重估 | 一个信息让前文全部重读 | 03 反转钩的结构化用法 |
| 机制服务故事 | 规则（投票/搜证/信任）不是为复杂而复杂 | 短剧"设定即规则" |
| 情感还原 | 真相揭晓时落到人物动机的同情 | 情感钩 + 主题收束 |

## 三、高质量判据（可用于自检）

1. **信息公平**：所有结论所需线索都在公开信息中（不靠"新证据空降"）。
2. **动机自洽**：每个角色的行为在其信息集下都合理（不能用"他其实知道"硬圆）。
3. **反转有伏笔**：每个反转在前期至少埋 1 个可回溯的细节。
4. **角色无废牌**：每个角色都持有唯一信息或承担唯一功能。
5. **机制贴合主题**：投票/阵营等机制与故事主题相关（如"信任"主题配信任机制）。

## 四、可迁移到短剧/悬疑的结构模板

```
角色（3–6）：每人 1 条私线 + 1 条公开身份
线索（5–8）：公开线索 60%，私线线索 40%，链式指向
时间线：一张公共表 + 每角色一份不可见的"版本"
转折：主反转 1 个（有 ≥2 处伏笔）+ 二次反转 1 个（可选）
结局：还原 → 情感落点（同情/唏嘘），不做廉价全员恶人
```

**落地要点**：把每条私线信息与线索链登记为 `StoryState.foreshadowing`
（`planted_at` ↔ `planned_resolution` 章号区间），由门禁 L004/L005 保证"埋了必回收"。
