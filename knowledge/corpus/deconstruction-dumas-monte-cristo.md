# 拆解案例：大仲马《基督山伯爵》（公版）

> 类型：长篇复仇小说 ｜ 核心可迁移：**复仇爽文范式**、**身份/马甲**、**长线延迟满足**。
> 本文件只做结构分析，不含原文全文。**公认的复仇爽文鼻祖**，对网文/短剧影响深远。

## 一、骨架（一行式）

```
蒙冤入狱 → 狱中得道（知识+财富）→ 化身神秘伯爵归来 → 逐个复仇 → 真相与宽恕
```

- 这是**复仇类爽文的原型**：受辱（欠）→ 蛰伏（蓄力）→ 归来（身份反差）→ 逐个清算（还）。
- 核心爽点结构：**先极端失去，再极端富有**，落差即张力。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 极端蒙冤 | 把主角打到最低 | 短剧第 1 集的"受辱到底" |
| 狱中得道 | 蛰伏期获取能力+资源 | "金手指"的经典写法（非天降） |
| 多重身份 | 化身不同马甲接近仇人 | **马甲文**鼻祖（逐个揭露） |
| 逐个清算 | 仇人分层、逐个击破 | 反派四级递进 + 打脸链 |
| 延迟满足 | 复仇拉长到全书 | 长线爽感的节奏控制 |
| 宽恕收束 | 终局留道德余味 | 避免"爽到底"的廉价感 |

## 三、节拍条（压缩）

```
拍1 受辱：蒙冤入狱（欠）
拍2 蛰伏：狱中得道（蓄力）
拍3 归来：神秘身份登场（反差）
拍4–N 清算：逐个打脸（还，分层递进）
拍N+1 反转：仇人关系网真相
拍N+2 收束：复仇的代价与宽恕
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 蒙冤 | 02 危机钩 | 极端危机 |
| 拍3 归来 | 05 身份钩 | 马甲登场 |
| 拍4 清算 | 06 冲突钩 | 逐个宣战 |
| 拍N+2 收束 | 12 代价钩 | 复仇代价 |

## 五、可迁移结论（4 条）

1. **复仇爽文公式**：极端失去 → 蛰伏得道 → 身份反差 → 逐个清算；落差越大，爽感越强。
2. **马甲的分层揭露**：多重身份逐个揭开（对应网文"马甲文"），每个马甲服务一次打脸。
3. **金手指非天降**：狱中得道 = 有代价、有过程的获得（比"系统降临"更有说服力）。
4. **复仇要留余味**：终局给宽恕/代价，避免"纯爽"导致的道德空洞（提升作品层级）。
