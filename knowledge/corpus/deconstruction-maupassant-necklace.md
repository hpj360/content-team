# 拆解案例：莫泊桑《项链》（公版）

> 类型：短篇 ｜ 核心可迁移：**欲望—代价**、**假象维持**、**结尾反转**。
> 本文件只做结构分析，不含原文全文。

## 一、骨架（一行式）

```
向往上流 → 借来华服首饰赴宴 → 丢失项链 → 十年偿还 → 揭示项链是假的
```

- 驱动是**一个虚荣的欲望**与**一次意外**，代价被拉长到十年。
- 反转不改变事实（债已还），但**重新定义全部代价的意义**。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 欲望起点 | 对上流的向往（用具体场景写，不用概括） | 短剧"想要却得不到"的开局 |
| 假象道具 | 借来的项链＝体面的假象 | 用一件具体物承载阶层焦虑 |
| 意外 | 丢失＝假象崩塌的导火索 | 意外必须由欲望自身招致（自食其果） |
| 长期代价 | 十年劳作（时间跨度） | 长篇/多集用"时间跳跃"表现代价 |
| 反转 | 项链是假的（代价本可避免） | 反转重估而非推翻 |

## 三、节拍条

```
拍1 欲望：向往（具体化）
拍2 机会：收到请柬 → 借项链
拍3 高峰：宴会上短暂的风光
拍4 意外：项链丢失
拍5 代价：十年偿还（压缩叙述）
拍6 反转：真相揭晓 → 冷收
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍2 借链 | 04 期待钩 | 期待"风光" |
| 拍4 丢失 | 02 危机钩 | 即时危机 |
| 拍6 反转 | 03 反转钩 | 认知被重估 |

## 五、可迁移结论（3 条）

1. **代价由欲望自招**：意外不是天降，而是欲望的必然副作用（避免"倒霉"感）。
2. **时间跳跃表现代价**：用一句"十年过去了"＋状态对比，压缩漫长代价（多集连载可作节奏调节）。
3. **反转=重估**：最好的反转不是加新信息推翻，而是让**已知代价获得新含义**（冷收）。
