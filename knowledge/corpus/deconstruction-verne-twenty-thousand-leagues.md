# 拆解案例：儒勒·凡尔纳《海底两万里》（公版）

> 类型：科幻冒险长篇 ｜ 核心可迁移：**奇观+悬念**、**知识型爽感**、**囚徒视角的探索结构**。
> 本文件只做结构分析，不含原文全文。**类型文学的早期畅销范式**。

## 一、骨架（一行式）

```
海上异常（怪物传闻）→ 被"怪物"俘获 → 随潜艇环游海底（奇观序列）→ 逃离/谜团未解
```

- 驱动是**对未知的探索**（奇观），而非冲突升级；悬念来自"船长是谁、为何如此"。
- 主角是**被囚禁的观察者**——探索的自由与人身的不自由形成张力。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 异常传闻 | 开局钩子（怪物之谜） | 用"都市传说"开局 |
| 俘获 | 主角进入奇观世界 | 强制进入新世界（比"自愿"更有张力） |
| 奇观序列 | 逐个海底景观（可独立成篇） | 单元式奇观（适合视觉化/分镜） |
| 神秘船长 | 悬念核心（动机未解） | 让"谜"挂在人物而非事件上 |
| 知识穿插 | 科学解释 + 冒险 | **知识型爽感**（长见识即满足） |
| 开放结局 | 谜团未解、主角逃离 | 留白续作空间 |

## 三、节拍条（压缩）

```
拍1 传闻：海上怪物（悬念）
拍2 俘获：进入潜艇（新世界）
拍3–N 奇观：逐站探索（单元）
拍N+1 揭秘：船长的执念（人物悬念）
拍N+2 逃离：开放收束（谜未解）
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 传闻 | 07 秘密钩 | 怪物之谜 |
| 拍2 俘获 | 02 危机钩 | 被囚 |
| 拍N+1 揭秘 | 05 身份钩 | 船长身份/执念 |

## 五、可迁移结论（4 条）

1. **奇观+悬念双引擎**：每站奇观（视觉爽点）+ 船长之谜（持续悬念）——探索类叙事的标准配置。
2. **强制进入新世界**：被俘/事故比"主角主动选择"更有张力（对应二幕转折的被动变体）。
3. **知识型爽感**：把硬知识写成"冒险中的解释"（不是教科书），读者"长见识"即满足。
4. **谜挂在人物上**：让持续悬念绑定一个神秘人物（而非单一事件），悬念可贯穿全书。
