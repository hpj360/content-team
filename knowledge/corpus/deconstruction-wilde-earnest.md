# 拆解案例：王尔德《不可儿戏》（公版）

> 类型：喜剧 ｜ 核心可迁移：**误会引擎**、**机锋对白**、**荒诞前提的自洽**。
> 本文件只做结构分析，不含原文全文。适用：`script-writing`（喜剧）、`showrunning`。

本篇"误会引擎"=**单一谎言装置型**；分层信息差版本（三层递进）见 `paradigm-modern-romance.md`，两者名称同源、机制不可互替。

## 一、骨架（一行式）

```
假身份（Earnest 双关） → 两组误会交织 → 身份揭穿危机 → 荒诞反转（身份竟是真的）
```

- 喜剧引擎是**一个可复用的谎言**（虚构的兄弟），它不断制造新误会。
- 每场戏靠**机锋对白**维持张力，而非情节密度。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 荒诞前提 | 一个自洽的谎言设定 | 前提要能"自洽推演"（对应素描的高概念） |
| 误会引擎 | 同一谎言反复制造新麻烦 | 用一个装置驱动多场冲突 |
| 机锋对白 | 人物用聪明话互相拆台 | 台词即动作（反驳/反讽/定义权争夺） |
| 揭穿危机 | 谎言即将破产 | 中段压力峰值 |
| 荒诞反转 | 揭穿时发现谎言竟成真 | 反转=重估而非推翻 |

## 三、节拍条

```
拍1 立谎：虚构身份（自洽前提）
拍2 误会一：两人共用同一假名
拍3 误会二：身份被查（压力升级）
拍4 危机：谎言将破
拍5 反转：假身份竟是真的（荒诞收束）
```

## 五、可迁移结论（3 条）

1. **一个装置驱动多场**：好喜剧不需要多情节，只需**一个自洽的谎言/误会装置**反复榨取笑点。
2. **机锋=动作**：对白是"争夺定义权"的博弈（谁定义谁就占上风），不是段子。
3. **荒诞成真式反转**：揭穿时让谎言反而成真——比"惩罚说谎者"更高明的喜剧收束。
