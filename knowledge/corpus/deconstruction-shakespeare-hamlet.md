# 拆解案例：莎士比亚《哈姆雷特》（公版）

> 类型：悲剧 ｜ 核心可迁移：**复仇延宕**、**戏中戏**、**内心独白外化**。
> 本文件只做结构分析，不含原文全文。适用：`script-writing`、`showrunning`。

## 一、骨架（一行式）

```
亡魂揭露谋杀 → 复仇者求证与延宕 → 戏中戏验证 → 误杀与反噬 → 终局同归于尽
```

- 主角的核心不是"复仇"，而是**"要不要复仇"的延宕**——行动力被怀疑瘫痪。
- 张力来自**已知真相却迟迟不动**与**对手的反制**双线挤压。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 亡魂（信息源） | 给出真相，但要求验证 | 关键信息需"待验证"（防单点真相） |
| 延宕 | 主角不断自问、试探 | 用"验证"延后高潮，蓄压 |
| 戏中戏 | 用"表演"验证真相 | 元叙事：用剧中剧做推理实验 |
| 误杀 | 行动失误招致反噬 | 主角的一次错误决定改变局势 |
| 终局 | 毒剑毒酒同归于尽 | 代价具象化（物：毒） |

## 三、节拍条

```
拍1 揭露：亡魂告知谋杀（要求复仇）
拍2 求证：装疯试探（延宕开始）
拍3 验证：戏中戏观察对手反应
拍4 失误：误杀（招致流放与反噬）
拍5 归来：对手设局（毒剑毒酒）
拍6 终局：同归于尽，真相与权力交接
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 揭露 | 07 秘密钩 | 谋杀真相 |
| 拍2 装疯 | 04 期待钩 | 期待复仇 |
| 拍3 戏中戏 | 03 反转钩 | 验证引发的认知变化 |
| 拍6 终局 | 12 代价钩 | 全员代价 |

## 五、可迁移结论（3 条）

1. **延宕即蓄压**：让主角"必须行动却无法行动"，比直接复仇更有张力（适用于长剧前中期）。
2. **戏中戏/元验证**：用"表演/模拟"验证真相，是把"内心推理"外化的高级手法（可拍摄）。
3. **代价具象化**：终局用毒剑毒酒这类**可指认的物**承载"复仇的代价"，避免抽象说教。
