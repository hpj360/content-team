## 三、群像管理：出场即高光、标签化、退场清算（7 项机制）

| 机制 | 说明 | 可迁移 |
|---|---|---|
| 出场即高光 | 人物登场自带标志事件（温酒斩华雄、三顾茅庐、千里走单骑）：首秀即人格定装，无需铺垫期 | character-bible 登场首事件字段 |
| 记忆点标签 | 羽扇＝诸葛、赤兔＝吕布/关羽、青龙刀＝关羽：道具人格化，标签先于台词完成辨识 | continuity-anchor-examples 道具资产登记 |
| 死亡即退场清算 | 名将之死是叙事杠杆：关羽死→吴蜀开战；张飞死→伐吴加速；诸葛死→全书收束感前置 | event-conflict-arc 退场清算节点 |
| 群像差额记账 | 谋士武将批量轮换，只给"当前牌桌上的关键人物"高光预算，其余按名单一笔带过 | beat-sheets 镜头预算表 |
| 对手戏定价 | 高光靠对手抬价：三英战吕布、诸葛 vs 周瑜——强者对撞才产生名场面 | event-conflict-arc 对手强度表 |
| 绰号与称号 | "卧龙/凤雏"式称号＝能力预告：称号先于登场完成预期管理，登场兑现即高光 | hot-quotes-memes 称号截转口径 |
| 降将再登场 | 换线人物再登场自带旧账（新功旧债一起算），忠诚度成为可叙事资产 | character-bible 效忠结算字段 |

- **短引用示例（≤2 句）**："既生瑜，何生亮！"（通行本回目口径 hedge）＝退场清算的"结案陈词"：
  一句台词完成人物弧的最终定装，也把对手戏的价格当场结清。

## 四、视角：说书人全知＋局部限知双轨（含价值观筛选器）

- **全知轨**：战场全局、双方帐内、人物动机皆可直陈——全知负责宏观账本、势力消长与"天下大势"播报。
- **限知轨**：具体计策的底牌对读者与中计方同步隐藏（苦肉计、连环计的表演层），悬念靠限知段落维持。
- **双轨配比**：宏观全知＋微观限知，与 hitchcock"桌下炸弹"的知情分配同源：读者知道结构，不知道底牌。
- **尊刘抑曹＝价值观筛选器**：同一事件按立场分配篇幅与情感权重——曹方败绩渲染、刘方哀兵笔法、吴方缓冲叙事。
  倾斜是内容取舍的总闸而非局部修辞：它决定谁得到高光、谁死于一句带过。
- **双向记账例外**：倾斜并非剥夺对手存在感，曹操仍获"雄才"级笔墨；筛选的是权重分配，不是真相单边化。
- **限知的双刃**：底牌对读者与角色同时隐藏是悬念态；对读者公开、只对中计方隐藏是"已知反用"态，两态要显式选择。
- **说书人评点口**："毕竟……且听下回分解"式收束：评点口＝节奏口，承担回末钩子与读者契约。
- **复用点**：全知叙事做"有限底牌"→ story-state-and-continuity 设"读者可知/角色可知"双列；评点口→ chapter-continuity 收束钩子字段。

## 五、谋略＝体系的"实力轴"：计策分级与能力外化

| 计策分级 | 机制口径 | 复用点 |
|---|---|---|
| 零级·情报差 | 一切计策的底层是信息不对称（细作/降将/书信）：信息本身是弹药 | 情报线独立记账（story-state-and-continuity 信息差列） |
| 一级·诈败/示弱 | 把伪装做成流程（诈降、空营、诈败诱敌）：胜负先在信息层结算，再在战场层兑现 | 谈判/商战桥段的"表演层"设计 |
| 二级·火攻 | 需环境条件的复合计（风向、地形、内应）：条件齐备才可引爆，缺一件则计不成 | 攻防战的"条件装置"前置表 |
| 三级·反间/离间 | 攻击敌方信任结构（蒋干中计）：成本最低、杠杆最大，一次离间换一员大将 | 组织线冲突的低成本引爆器 |
| 四级·连环计 | 多计成链（连环＋苦肉＋火攻）：一环失效全链报废，风险与层级同步放大 | 终局级阴谋的工程化写法 |

- **谋士＝能力外化角色**：军师把"决策智力"从主君身上拆出单独成角（郭嘉/周瑜/诸葛/司马），
  使战力可对话、可辩驳、可直播推理过程——读者看到的不是结果，而是推理现场。
- **计策对称性**：每一计都预告被识破的可能（识破/将计就计是同级武器），智力对决才有来回。
- **失败也有产出**：计策失败往往交付新信息（暴露内应/暴露底线），失败是下一计的成本核算。
- **复用点**：能力外化为搭档角色 → character-bible 增"能力代演"字段；计策分级 → event-conflict-arc 的冲突强度标尺。

## 六、数值刻度：兵力/城池/粮草（公开口径）

- **粗刻度公开口径**：兵力（"八十三万"对"五万"级）、城池数、粮草存量是势力硬实力的公开读数，说书人直接播报。
- **读数仪式**：大战前必报双方兵力粮草——读数是开战仪式的一部分，给读者"强弱牌面"的正式对表。
- **数值≠胜负**：刻度只是牌面，"以少胜多"必须走条件装置（火攻、内应、地形、对方决策失误）；缺条件则数值成立。
- **刻度的落差功能**：先公开大牌面再给翻盘，落差即张力；守住方用"粮尽援绝"倒计时把防守写成时钟。
- **虚报也是计**：号称与实数之间的水分可写成心理战——虚报兵力是零级情报差的武器化用法。
- **粗刻度的代价**：数字是文学夸张口径而非统计口径，只承担"量级感"，不承担精确推演——精确即穿帮。
- **复用点**：story-state-and-continuity 势力状态表设"公开口径数值＋隐藏条件"双列；数值只用于量级对比与读数仪式。

## 八、可迁移技法（6 条，SG-T1…SG-T6）

1. **SG-T1 势力线主干**→ `character-bible.md` 群像按阵营建档：人物档案挂势力线，标注"当前所属/过往所属/效忠结算"；
   人物换线即触发效忠、信息、功名的三重重算（关羽模式的现代移植）。
2. **SG-T2 合流装置**→ `event-conflict-arc.md` 多线汇合事件设计：会盟/大战/联姻类枢纽先列前置条件表，
   汇合后逐线结算战果与债务，避免"合而不结"；各线视角下的"同一场仗"要分别记账。
3. **SG-T3 章回交棒**→ `chapter-continuity.md` 双线切换纪律：一回一收一放，回末悬念移交下一条线；
   章节模板保留"承接口"字段（话说/且说/且听下回分解的功能位）。
4. **SG-T4 首秀高光＋道具标签**→ `beat-sheets.md` 登场节拍：关键人物首场戏必须配标志事件，
   并在 `continuity-anchor-examples.md` 登记一件人格化道具（羽扇/赤兔/青龙刀级辨识资产）。
5. **SG-T5 底牌双轨**→ `story-state-and-continuity.md` 信息层级字段：读者可知/角色可知双列；宏观走全知、底牌走限知；
   立场权重（价值观筛选器）写成可配置字段，逐卷复查是否漂移。
6. **SG-T6 势力刻度表**→ `worldbuilding-guide.md` 势力层实测表：公开口径数值＋隐藏条件列；
   "以少胜多"必须先过条件表，无条件的翻盘视为刻度失效。

## 九、自检（8 条）

1. 多线主干是"势力/阵营"还是"个人"？人物一退场线就断，说明还停在传记式群像，
   需要把账本升到势力层：先立三条线，再往线里装人。
2. 每个关键人物登场是否自带高光事件？没有高光的登场应按配角预算压缩，
   或推迟到有标志事件时再登场——登场时机本身是预算分配。
3. 记忆点是否有"道具/绰号"级标签？只靠台词辨识的人物在群像里活不过三回，
   先补一件人格化道具再谈戏份。
4. 死亡是否做了退场清算（战果归属、债务移交、走向改变）？死而无声＝杠杆浪费，
   名场面白给：清算清单要逐项过。
5. 全知与限知是否分层使用？宏观用全知、底牌用限知，
   且配比在全书中保持稳定，不逐章随机漂移。
6. 视角倾斜是否自觉且设总闸？允许尊刘抑曹式立场权重，
   但必须写成字段逐卷复查——倾斜是设计，不是事故。
7. 计策是否分级、是否给前置条件？无条件的翻盘＝数值刻度与智力轴双双失效，
   读者契约随之破裂：翻盘先过条件表。
8. 数值刻度是否守住"公开口径＋量级感"？内部精确数值泄底会同时毁掉落差感与悬念，
   量级感一旦换成账目感，翻盘就从奇迹降格为算账。
