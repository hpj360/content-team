# 拆解案例：中文商业素描喜剧结构（参考"喜人奇妙夜"式素描）

> **版权声明**：本文件为**方法论级结构分析**，不复制任何节目、剧本、台词或表演细节。
> 所分析的是当代中文商业素描（Sketch Comedy）的**通用结构范式**，
> "喜人奇妙夜"作为该范式的代表平台。适用：`script-writing`、`showrunning`。

赛制工程与逐案拆解见 `paradigm-sketch-competition.md`；本篇只保留结构范式，不重复赛制与逐案。

## 一、骨架（范式级）

```
强设定(高概念前提) → 关系建立 → 冲突升级(3 级) → 反转/摊牌 → 情绪收尾
```

- **强设定先行**：开场 15 秒内给出一个"反常识但自洽"的前提（如一个荒诞规则、
  一个错位身份）。观众先接受规则，笑点才成立。
- **笑点＝设定的必然推论**：好笑不来自段子，而来自"这个设定下必然发生的荒谬"。

## 二、结构要素与可迁移点

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 高概念前提 | 一句话可复述的荒诞规则 | 短剧单集开场：3 秒抛规则 |
| 怪人×直人 | 一个认真执行荒诞规则的人 + 一个正常反应的人 | 双人冲突结构 |
| 升级三拍 | 同一笑点结构重复三次、每次加码 | 对应"压→爆"递进 |
| 回调(Callback) | 前面埋的细节在最后回收 | 与伏笔机制同源 |
| 情绪收尾 | 笑后落到一个真诚的瞬间（笑中带泪） | 短剧集尾钩的"情绪钩"变体 |

## 三、可迁移技法（4 条）

1. **高概念一句话定律**：如果一个前提不能用一句话说清，它撑不起一段戏。
   - 落点：写单集前先写"设定卡"（对应 `Script.logline` 与 `beat-sheets.md` 的目标）。
2. **升级而非堆量**：不是"多塞几个笑话"，而是**同一结构的三次加码**
   （不变化＝不好笑；变化＝笑点递进）。对应分镜/节拍的"三拍递进"。
3. **角色认真对待荒诞**：喜剧的调度要"太正经"——用正剧的严谨演荒诞的事
   （与 `style-pack-library.md` 的"喜剧节奏包"一致：平光 + 短镜 + 音效强调）。
4. **回调即伏笔**：把开场的一个小细节在结尾原样回收（`hook-library` 的"复沓"变体），
   是低成本高回报的结构糖。

## 四、素描结构模板（可直接填）

```
设定卡：一句话前提 + 荒诞规则 + 为何自洽
人物：怪人（恪守规则） / 直人（正常反应）
拍1 建立规则（15s）
拍2 升级一（规则生效，小荒谬）
拍3 升级二（加码，关系受压）
拍4 升级三（顶点，临近崩坏）
拍5 反转/摊牌（规则被戳破或反噬）
拍6 情绪收尾（一个真诚瞬间）
```

## 五、局限（诚实声明）

- 本文件只迁移**结构范式**，不涉及任何节目的具体剧本、人物与台词。
- 素描喜剧的通用原理（game/升级/callback）源自公共的即兴喜剧理论，可自由使用。
