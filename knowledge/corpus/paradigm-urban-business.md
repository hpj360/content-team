## 一、骨架（范式级）

```
立项（公共目标） → 资源落差 → 职场攻防三段 → 双雄对峙 → 规则内反杀 → 结局重排牌桌
```

- 起点永远是**立项**：一个对上级先讲得通、对业务可验收的目标。
  没有立项的逆袭是情绪斗气，有立项的逆袭才是商战。
- 反杀的全部合法性来自"规则内"：反派越界时主角依然守规，胜利才立得住。

## 二、职场攻防三段与要素表

| 段位 | 功能 | 典型攻防 | 可迁移 |
|---|---|---|---|
| 立项段 | 主角接下"承诺与风险并存"的目标 | 争取授权、拉赞助方、定验收口径 | 开场 3 集内给目标 + 明面阻力 |
| 资源差段 | 暴露主角与对手的资源落差（人脉/预算/信息） | 借调、周旋、拆借 | 用"借"写强：主角的资源全是借来的 |
| 攻防推进段 | 多回合交手，一次小胜一次小败 | 大会汇报、报价博弈、挖角反挖 | 回合制：每回合有明确输家和代价 |

- **双雄对峙**：对手必须强而自洽（他也守另一套规则），双雄才是探照灯——
  照出主角与方法论各自相信的组织逻辑。
- **玻璃房子里的暴力**：商战没有拳脚，"暴力"的替代物是
  数据（报表闪断）、审计（资金链核验）、舆论（声明与撤稿）——
  写商战戏要为每次打击选定一种"替代武器"与它的防线。

## 三、可迁移技法（5 条）

1. **资源差可视化**：开局给主角一张明牌劣势清单，逆袭=逐条收回清单上的筹码。
2. **回合制攻防**：一个大项目切成 3–5 个回合，每回合给出输赢与损耗，杜绝"一路顺风"。
3. **玻璃房子三武器轮换**：数据、审计、舆论轮番上阵，同一种武器连用两级即失效。
4. **规则内反杀钩**：主角的胜负手是他入职第一天就知道的条文/流程/合规定义，
   让伏笔自然长在"职业细节"里而不是外挂。
5. **牌桌重排收尾**：结局不让反派"下场领盒饭"，而是重排席位（升迁/调岗/另起炉灶），
   胜利感来自格局改变而非惩罚快意。

## 四、逆袭结构模板（可直接填）

```
立项卡：目标 + 验收口径 + 明面失败的下限
劣势清单：资金/人脉/信息 三缺其二（可借不可抢）
回合1：小败或惨胜（暴露资源差，学会规则）
回合2：借势翻回（第一武器：数据/审计其一）
双雄摊牌：对手亮出他的道理，主角被打到动摇一次
回合3：规则内反杀（第二、三武器合击，伏笔回收）
收尾：牌桌重排 + 主角方法被组织吸收
```
