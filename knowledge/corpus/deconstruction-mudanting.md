## 一、作品档案

- **体制**：明传奇五十五出（通行本口径）——惊梦/离魂为"人间段"，冥判/还魂为"超自然段"，两段互为镜像。
- **一行命题**：情至论的爱情动员结构——为爱死而复生的"**预设终点**"驱动全剧：生死不是障碍，而是抵达程序。
- **世界观公理**：「情不知所起，一往而深。」（题词，L2 短引，通行文本口径）——公理句给全剧立法，
  情大于生死、大于礼制，一切结构由此推演。

### 骨架（一行式）

```
公理立法（情大于生死）→ 梦中相会（既成事实前置）→ 离魂（人间段收束）
→ 冥判（流程放行）→ 还魂拾画（物证对账）→ 伦理审查（是人是鬼）→ 礼制收场（双段合环）
```

- 结构的关键不是"相爱难不难"，而是**"爱先于一切许可成立"**：阻力只是补发手续的排队。
- 全剧推进靠**一张凭据闭环**：梦中人 → 写真小像 → 拾画认像，三段一个物证同心圆。

## 二、叙事结构范式（机制 → 可迁移）

| 机制 | 原作做法（公开通行口径） | 可迁移 |
|---|---|---|
| 生死双段结构 | 惊梦→离魂为人间段；冥判→还魂为超自然段；两段各半、共用同一笔情绪债 | 三幕的"超自然段"变体：不可调和的矛盾交给物理之外的规则 |
| 梦作为合法叙事空间 | 梦中相会先行，把爱情做成既成事实，再回头补许可 | "既成事实再补许可"：改变阻力戏剧性的写法（见 MT-T2） |
| 自画像＝物证叙事 | 写真→拾画，情缘凭据以画像对账 | 物证对账：把核心情感证据做成可保管/可错认/可回收的物 |
| 家长反对＝社会性反派 | 无大恶人；守礼制本身就是阻力，反对者尽职而无恶意 | 配置阻力而非配置反派：规则即代价（见 MT-T4） |
| 冥判/还魂＝荒诞对位 | 阴间用官僚系统走婚姻流程，公文腔处理生死大事 | 用"本该严肃的流程"处理"不可能的请求"，荒诞是情绪释放阀 |
| 拒认风险（还魂后"是人是鬼"） | 复活后的伦理审查桥段：情既成立，仍须向世俗规则交验"可被接受"（公开通行口径） | 超自然代价披露位：奇迹必须追加一道"是否可被世俗接受"的审查关 |
| 园林空间＝情绪地形 | 游园的亭台花木即情绪地理——繁花与断井颓垣同框，繁华替荒芜作证 | 空间语法：让一句情绪配一块地形，台词始终有投影地点 |

### 节拍条（五十五出的等效主线拍）

```
拍1 题词公理：情不知所起，一往而深（世界观先立法）
拍2 规训成形：闺中守礼制，情无处安放（阻力的源头）
拍3 合法前置：游园惊梦，梦中相会将爱情做成既成事实
拍4 写真离魂：自画小像留证，玉殒香消（人间段收束）
拍5 冥判放行：阴间以公文流程审定"情不逾矩"
拍6 拾画对账：柳生拾画认像，物证闭环（超自然段启动）
拍7 是人是鬼：还魂后的伦理审查，拒认风险顶点
拍8 家长收场：礼制最终承认既成事实，双段合环
```

## 五、可迁移技法（6 条，MT-T1…MT-T6）

1. **MT-T1 生死双段** → `skills/script-writing/references/beat-sheets.md` 三幕 15 拍的"超自然段"变体：
   人间段用现实规则走完，超自然段换一套规则重走同一笔情绪债；两段镜像必须呼应**同一句公理**。
2. **MT-T2 梦＝既成事实** → `paradigm-modern-romance.md` 误会引擎的"合法前置"变体：
   阻力迟到时主角已先斩后奏，戏剧性来自"补许可"的过程，而非"争许可"的拉锯。
3. **MT-T3 物证对账（写真→拾画）** → `skills/storyboarding/references/continuity-anchor-examples.md`：
   把核心情缘凭据登记为可逐字复用的识别符（画像/信物），前后对账禁止同义改写。
4. **MT-T4 无大恶人阻力配置** → `skills/novel-writing/references/worldbuilding-guide.md`"规则即代价"：
   反派可以缺席，阻力必须可指认（礼制/流程/门第），反对者写成"尽职的守规矩人"。
5. **MT-T5 园林情绪地形** → `skills/storyboarding/references/vertical-shot-grammar.md` 空间语法：
   竖屏每场戏给一块情绪地形（高台/曲廊/断井），镜头站位随情感能级走，场景即态度。
6. **MT-T6 金句档案** → `hot-quotes-memes.md` 四段口径（梗名→出处→机制→复用点）：
   公理句、环境句分别造册；跨介质沿用名（游园惊梦式）单列"外化铭牌"条目。

### 写前自检判据（超自然言情必备三问）

1. 爱情是否**先于许可而成立**（合法前置），阻力只是补手续而非终审？
2. 情缘是否配有**一张可对账的物证**（像/物/信），分三步流转（自留→错认→回收）？
3. 超自然是否被一道**世俗审查关**验收（是人是鬼），奇迹不豁免代价？
