# 拆解案例：契诃夫《变色龙》（公版）

> 类型：短篇讽刺 ｜ 篇幅：极短 ｜ 核心可迁移：**单一场景内的立场翻转**与**对话驱动**。
> 本文件只做结构分析，不含原文全文。

## 一、骨架（一行式）

```
主题展示(狗咬人) → 三次立场翻转(随"狗主人是谁"变化) → 回到原点(收场)
```

- 全篇几乎只有**一个场景**、**一组人物**、**一次事件的反复解读**。
- 没有换地图、没有升级——张力全部来自**同一事实在不同信息下的重新评价**。

## 二、人物配置

| 角色 | 功能 | 可迁移点 |
|---|---|---|
| 警官 | 立场随权力信号翻转的主体 | "立场"本身就是笑点与讽刺的载体 |
| 随从 | 递话/放大/迎合 | 用配角把主角的摇摆**外化**为对话 |
| 围观人群 | 压力与见证 | 群体反应替代旁白说明 |

**可迁移**：主角不必"变强"，**让他的立场随环境变化**，同样制造强戏剧性。

## 三、节拍条（结构标注）

```
拍1  事件抛出：狗咬人 → 冲突建立
拍2  初次裁决（低姿态）→ 听说犬主"普通人家"
拍3  翻转1：听说犬主是将军家 → 立即改口
拍4  翻转2：被告知犬主不是将军家 → 再改口
拍5  翻转3：又被纠正为将军家 → 再改口
拍6  收束：以一句"概叹环境"的旁白式冷收
```

- 每一拍的驱动力都是**新信息**，而非事件本身。
- 翻转次数 = 讽刺强度；**信息是唯一的剧情发动机**。

## 四、台词与手法

- **对话即动作**：警官从不"陈述心理"，他的心理全在**改口的措辞**里（对狗/对人的称呼一变，立场就变）。
- **复沓**：相似的对话结构重复出现，靠**微小变化**（称谓、形容词）传递立场位移——这正是 `hook-library.md` 中钩子之外的另一类"重复中的变化"技法。
- **结尾留白**：不收束道德训诫，用一个具体动作/自然现象收尾，把判断权交给读者。

## 五、钩子式映射（对照 13 式）

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 事件 | 02 危机钩 | 狗咬人＝即时冲突 |
| 拍3/4/5 | 03 反转钩 | 立场反复翻转（连环反转） |
| 拍6 收束 | 无（冷收） | 讽刺类常用"冷收"替代钩子 |

## 六、可迁移结论（3 条）

1. **单场景强张力配方**：一个固定事件 + 一条"随信息变化"的立场线 + 3 次立场翻转
   → 适合 30–90s 短剧单集与短篇。
2. **对话承担全部剧情**：删除所有心理描写，让"改口的措辞"成为唯一的信息通道
   （对应门禁 S005：禁止旁白式心理描写）。
3. **讽刺型结尾用冷收**：用一个客观细节收尾，不写"道理"
   → 可作为短剧"高级感"结局模板。
