## 一、骨架（范式级）

```
两分钟内核 → 分支节点 → 选择即代价 → 变量记账 → 结局判定 → 单集钩子与分支回收对账
```

- 竖屏互动的第一约束是时长：一段交互体验以两分钟为内核节拍，
  每个两分钟内必须完成"诱惑选择→付出代价→下一钩子"一轮。
- 选项的意义不在"自由"，而在**选择即付出代价**：每个选项都要拿走玩家一点什么
  （尊严/盟友/时间/信息），免费选项没有戏剧价值。

## 二、核心机制表

| 机制 | 说明 | 可迁移 |
|---|---|---|
| 分支节点密度 | 每 2–3 个两分钟内核设 1 次选择，全片 5–8 个 | 长篇里的章节决策点 |
| 选项三件套 | 每题 2–3 选项，各有代价与甜头 | 关卡分支的对称设计 |
| 变量记账 | 选择写入隐藏变量（信任/金钱/声望），结局按变量阈值判定 | 数值化的伏笔 |
| 结局判定 | 主结局 2–3 个 + 彩蛋结局 1 个，判定规则对玩家可推断 | 多结局的信息公平 |
| 单集钩子 | 每集末尾停在"选择前夜"，不把选择消化完 | 单集末卡点 |
| 分支回收对账 | 每条走过的分支必须被后续剧情承认（台词/后果/关系变化） | 核分支不回收=流失 |

## 三、可迁移技法（5 条）

1. **两分钟内核**：每个内核包含一次微悬念与一次微满足；选择点永远放内核边界上。
2. **选择即人设**：用选项写人物——极端处境下的三个选项就是三种人格，
   玩家选择的过程即角色塑造过程。
3. **变量显影**：账本变量在关键节点"显影"（听到一句因你先前选择而不同的台词），
   显影反馈的密度决定口碑。
4. **判定可推断**：结局判定依据要在前期以可见的道具/台词给出（如计数板、遗嘱条款），
   禁止终局新规则空降。
5. **分支回收对账表**：上线前做一张"节点×后果"对账表，任何走通的分支若在两个内核内
   无任何承认信号，判定为断头分支，二选一：删节点或补后果。

## 四、分支结构模板（可直接填）

```
内核（2min）：诱惑选择 → 代价即时兑现 → 下一个钩子
节点 N：5–8 个选择点，每题 2–3 选项、选项自带代价
变量卡：信任值/资金值/秘密数（阈值触发结局）
结局：主 A / 主 B / 彩蛋 C（判定规则提前可见）
对账：节点→承认信号（台词/后果/关系）逐格填写，空格即断头
```

- 不复制任何互动剧或竖屏剧的选项文案、结局设计或美术资产；本文件只迁移结构与机制。
- 红线：**分支必须回收对账**——选择若有路径不产生任何被承认的后果，视为虚假选项；
