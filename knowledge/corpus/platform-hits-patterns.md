# 平台爆款拆解样例（范式级）

> **版权声明**：本文件拆解的是**公开讨论的爆款结构共性**（范式），**不复制**任何具体作品、
> 视频、帖子、剧本或台词。示例为**原创骨架**，仅用于演示结构，非真实作品。
> 与 `platform-playbooks.md`（规则）、`platform-structure-templates.md`（骨架）配套。

## 一、番茄小说 · 爆款共性

- **共性结构**：废材/低位开局 → 金手指（3 章内）→ 第一个打脸（5–8 章）→ 卷级越阶。
- **共性钩子**：身份钩 + 打脸钩（章章有钩，前三章定生死）。
- **翻车点**：开篇背景铺陈；连续 3 章无情绪推进；断更。
- **原创示例骨架**：`外卖员被当众羞辱 → 误接总裁手机 → 七天协议 → 庆功宴揭身份`。

## 二、起点中文网 · 爆款共性

- **共性结构**：设定亮点（独特性）→ 冲突引入 → 小爽点 → 大副本（10–20 章）。
- **共性钩子**：设定钩（世界观独特性）+ 期待钩（副本预告）。
- **翻车点**：设定与逻辑漏洞；太监/烂尾。
- **原创示例骨架**：`记忆可交易的世界 → 主角低价买入他人记忆 → 发现记忆里藏着凶案`。

## 三、红果短剧 · 爆款共性

- **共性结构**：3/30/60 公式（抓眼/冲突/反转）+ 强钩子收尾 + 卡点在钩子峰值。
- **共性钩子**：身份钩（隐藏身份）+ 危机钩（当众受辱）。
- **翻车点**：反转位置漂移；结尾无钩子；卡点放错位置。
- **原创示例骨架**：`食堂风波 → 视频反转 → 云端备份 → "总部见"`。

## 四、抖音 · 爆款共性

- **共性结构**：0–3s 钩子 → 3–20s 冲突/信息 → 20–40s 转折 → 末 5s 行动号召。
- **共性钩子**：悬念钩（前 3 秒）+ 反差（预期违背）。
- **翻车点**：前 3 秒平淡；标题党货不对板；无字幕。
- **原创示例骨架**：`"这单我不送了" → 顾客开门的瞬间 → 镜头扫过墙上锦旗`。

## 五、小红书 · 爆款共性

- **共性结构**：封面痛点 → 前 2 行承诺 → 分段干货 → 标签。
- **共性钩子**：承诺钩（看了能获得什么）+ 数字钩（3 个方法/5 个坑）。
- **翻车点**：封面无信息量；站外引流；功效宣称。
- **原创示例骨架**：`"月薪 5k 也能存下钱" → 3 个反常识习惯 → 记账截图`。

## 六、微信公众号 · 爆款共性

- **共性结构**：标题信息量+悬念 → 前 300 字冲突开场 → 分段 + 加粗 → 行动号召。
- **共性钩子**：悬念钩（标题）+ 故事钩（开头）。
- **翻车点**：开头"随着……的发展"；纯标题党；无配图。
- **原创示例骨架**：`《我把公司告了》→ 开庭前一晚 → 三段事实 → "如果是你，会怎么选"`。

## 七、视频号 · 爆款共性

- **共性结构**：价值点前置（值得转发的理由）→ 主体 → 转发引导。
- **共性钩子**：情感钩 + 实用钩（可转给朋友）。
- **翻车点**：只求完播不求转发；过度精致失真实感。
- **原创示例骨架**：`"我父亲这辈子只学会一件事" → 一件小事 → "转给爸妈看看"`。

## 八、B站 · 爆款共性

- **共性结构**：前 15s 内容承诺 → 2–3 个信息高点 → 三连引导。
- **共性钩子**：承诺钩 + 信息钩（"我花了 30 天实测"）。
- **翻车点**：中段流失（无信息高点）；标题无信息量。
- **原创示例骨架**：`"30 天只吃食堂，身体发生了什么" → 三阶段数据 → "下期测什么"`。

## 九、知乎 · 爆款共性

- **共性结构**：结论/反常识判断开场 → 分层论证（含来源）→ 收束。
- **共性钩子**：反常识钩 + 专业钩（认证/数据）。
- **翻车点**：无来源；结论先行但论证空；过长无分层。
- **原创示例骨架**：`"其实大多数人不适合买基金" → 三类人群数据 → 建议`。

## 十、快手 · 爆款共性

- **共性结构**：前 3 秒接地气钩子 → 口播直给 → 关注/互动引导。
- **共性钩子**：共鸣钩（"老铁们是不是也这样"）。
- **翻车点**：过度精致失亲切；铺垫过长。
- **原创示例骨架**：`"这活我干了二十年" → 手上的老茧 → "关注我，看怎么省一半力气"`。

## 十一、微博 · 爆款共性

- **共性结构**：首句即观点 → 1–3 图 → @话题。
- **共性钩子**：观点钩（立场鲜明）+ 情绪钩。
- **翻车点**：长篇论述；无话题；情绪模糊。
- **原创示例骨架**：`"这届年轻人不是躺平，是算清楚了账" → 一张对比图 → #话题#`。

## 十二、跨平台共性（提炼）

1. **前 3 秒/前 500 字/前 2 行** 必须给钩子——所有平台的共同生死线。
2. **结构服务平台节奏**：完播（抖音）、转发（视频号）、三连（B站）、收藏（知乎/小红书）。
3. **翻车点高度重合**：铺垫过长、钩子缺失、货不对板、审核踩线。
4. **可复用母版**：一份内容（如剧本）→ 按各平台骨架改写（`platform-structure-templates.md`）→ 导出适配（`creative/exporters.py`）。
