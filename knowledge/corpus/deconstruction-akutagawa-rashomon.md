# 拆解案例：芥川龙之介《罗生门》式多视角结构（公版）

> 类型：短篇/多视角 ｜ 核心可迁移：**同一事件多版本**、**真相不可知**、**叙述者自利**。
> 本文件只做结构分析，不含原文全文。适用：`script-writing`（悬疑/短剧）、`showrunning`（多线）。

## 一、骨架（一行式）

```
一个事件 → 三个（或更多）自利版本 → 每版都自证合理 → 不给出唯一真相
```

- 结构的关键不是"谁在说谎"，而是**每个人的版本都在为自己的利益与体面服务**。
- 读者获得的是"真相的不可得"，而非解谜的快感——这是与剧本杀"有唯一解"的最大差异。

## 二、结构要素

| 要素 | 功能 | 可迁移 |
|---|---|---|
| 单一事件 | 所有人围绕同一事实 | 用一件"不可复现"的事件作锚 |
| 多版本 | 每版自利、部分真实 | 每个叙述者给"对自己有利的细节" |
| 视角标记 | 通过称呼/立场区分版本 | 分镜/文字用明确视角标识 |
| 留白 | 不裁决谁真 | 结尾用旁观者的茫然收束 |
| 环境压力 | 生存/体面逼迫 | 让"说谎"有正当动机 |

## 三、节拍条

```
拍1 事件：发生一桩不可复现的冲突
拍2 版本A：当事人自述（美化自己）
拍3 版本B：对手自述（与之矛盾）
拍4 版本C：旁观者转述（第三种说法）
拍5 收束：无人能证实 → 旁观者的茫然（留白）
```

## 四、钩子式映射

| 位置 | 钩子式 | 说明 |
|---|---|---|
| 拍1 事件 | 07 秘密钩 | 真相待解 |
| 拍2/3 矛盾 | 03 反转钩 | 每版推翻前版 |
| 拍5 收束 | 无（留白） | 不确定收尾 |

## 五、可迁移结论（3 条）

1. **多视角自利原则**：每个版本的"谎"都要**对自己有利**——否则只是随机矛盾，无说服力。
2. **真相不可知**：适合短剧"高级感"结局或系列钩子；与"唯一解"的剧本杀形成互补（可按题材选用）。
3. **不可复现事件**：选一件**无法再验证**的事件（死亡/雨夜/无第三方）作为多视角的锚，保证结构成立。
