# 创作方法论总纲（Creative Methodology Overview）

> 作用：知识库的**顶层综述**与阅读路线图。本文不引入新的原创结论，
> 而是把五个创作技能、语料拆解、模板与门禁共有的**结构公因数**沉淀出来，
> 回答"写一部作品，我到底依赖哪几门手艺、按什么顺序用哪些资产"。
> 适用：`novel-writing` · `script-writing` · `storyboarding` · `directing` · `showrunning` 全体。

## 一、通用叙事骨架：施压——递进——回收

翻遍语料库（`knowledge/corpus/`，21+ 案例覆盖公版经典与原创范式），各题材反复出现同一组骨相：

```
钩子(信息/处境反差) → 施压(冲突逐级加码) → 代价(角色真实损失) → 回收(伏笔/反转) → 留白或下级钩子
```

| 案例范式 | 骨架上的关键一环 |
|---|---|
| 《变色龙》 | 施压源＝权力信号；同一事件三次重估，每次加码 |
| 《麦琪的礼物》 | 代价与回收镜像：双方各自付出最珍视之物，结尾反转完成回收 |
| 《哈姆雷特》 | 施压被刻意延宕：已知的真相反成压力源，代价具象化 |
| 《不可儿戏》 | 回收机制＝误会引擎：一个自洽谎言被逐场兑现 |
| 《基督山伯爵》 | 长线施压→分层清算：蛰伏后逐个兑现，延迟满足即爽感 |
| 外卖员逆袭（原创示例） | 单集 8 拍：每拍都是一次微型"施压→回击"，卡点即钩子 |
| 章回体多卷（悟空范式） | 回收的单位从"场"放大到"卷"：卷内独立、卷间主线 |

**可迁移结论**：换题材不换骨架，换的是施压媒介（权力/误会/复仇/任务/规则）、代价具象物与回收节奏单位。

## 二、五大手艺支柱

### 1. 信息管理：悬念、伏笔与线索链

- 核心命题：**观众的爽感来自"信息差被按计划消除"**，不是"藏得深"。
- 悬念（现在在场的问题）、伏笔（未来回收的种子）、误导（故意给错方向）三者要分账管理，
  状态卡 `StoryState.foreshadowing` 逐条登记 `planted_at / planned_resolution`。
- 门禁承接：`creative/gates.py` 的 L001–L005（伏笔生命周期与章号区间）把"忘回收"变成可判定的错误。
- 语料对照：《罗生门》式多视角（误导契约的极限）、剧本杀线索链（公开/私线 6:4 信息公平）。

### 2. 人物四维与弧线

- 核心命题：人物＝**目标 × 弱点 × 缺陷根源 × 成长弧**，外在形象只负责"可画可演"的识别符。
- 冲突不缺反派的戏（如《樱桃园》）照样成立——施压由时代与选择承担；
  但必须有"幽灵的代价"（未被处理的过去），否则弧线不闭合。
- 验证方式：写作前填人物档案（识别符/红线/四维状态），写作后与一致性锚点对账。

### 3. 台词与动作写人物

- 核心命题：**台词是情绪外化，动作是道德外化**。观众从"选择做了什么"读人，不从"说了什么"读人。
- 语料对照：《我的叔叔于勒》用躲避行动完成道德暴露；商业素描用"怪人认真执行荒诞规则"替代台词 funny。
- 修复路径：台词 8 症状逐条改造（AI 腔、释义腔、重复问候腔……），落地在 `deai.py` 出口门与修订器词表。

### 4. 节奏与切点

- 核心命题：节奏不是"快慢"，是**切点分布**——信息切、情绪切、动势切各有功能。
- 单集层：3/30/60 公式 + 8 拍模板；分镜层：每镜 2–5s、段 ≤15s，镜头时长反映从事信息密度；
  系列层：跨集施压梯度（压、小爽、压、爽）防止情绪通胀。
- 验证方式：gates 的镜时长/总时长断言 + 分镜失败案例手册（SB1–SB8）对账。

### 5. 风格保真与一致性

- 核心命题：**风格是可测量的约束，不是氛围**。镜头长度、机位库、光比、色彩、口头禅全部可参数化。
- 落地：导演风格包（参数 YAML）→ 文风指纹（句长/段落节奏 bigram）→ 去 AI 味出口门 →
  连续性锚点（canonical description 逐字复用）。
- 红线：生成/修订不得抹平作者声线；diff 可见，人改回可回灌指纹。

## 三、写作工作流：写前→写中→写后

| 阶段 | 动作 | 资产入口 |
|---|---|---|
| 写前 | 选题评审 + 知识/语料检索 | `make_knowledge_planner` 自动注入 `corpus_refs` / `knowledge_refs` |
| 写前 | 设定与人物 | 世界观五层表 · 人物档案 · 题材手册（玄幻/科幻/悬疑等技法库） |
| 写中 | 节拍表 → 草稿 → 钩子自检 | 单集 8 拍模板 · 黄金三章模板 · hook-library 13 式 |
| 写后 | 门禁（结构/合规/一致性/节奏/手艺） | gates 30 断言 · 独立审查器 · 分维度评分 |
| 写后 | 语义评议（不门禁） | LLM judge 五模板打分 + 跨 provider 去同源 |
| 写后 | 修订闭环 | 规则修订器（max_rounds）→ LLM 修订后端 → 不收敛交回人工 |
| 交付 | 导出与发布 | 分章 TXT / EPUB3 / 短剧剧本 / 公众号 MD + 平台发布桥 |

## 四、题材 × 平台适配

- 题材决定**读者期待与雷区**（题材技法库：玄幻的战力守恒、科幻的三律自洽、悬疑的线索链比例），
  平台决定**篇幅、节奏、审核与变现口径**（`showrunning/references/platform-playbooks.md` 11 平台）。
- 判断顺序永远是：先题材定情绪配比与爽点周期，再平台定物理形态（字数/时长/竖屏如否），
  最后才谈风格包。反序会导致"平台皮的题材错"。
- 规则时效：平台参数以 `data/platform_rules.json` 版本化，写稿前查新鲜度（`content_freshness.py`）。

## 五、失败模式的元模式

跨技能的失败反复呈现四种元模式（各技能失败手册是其题材化实例）：

1. **堆量不升级**：同一冲突原样重复，靠加场景充字数。修复：La 三拍递进检查（每拍必须改变某要素）。
2. **一致性漂移**：人物识别符/时间线/光色被逐场改写。修复：锚点逐字对账 + 状态卡跨表校验。
3. **信息不公平**：结论依赖观众绝不可能获得的信息（悬疑侧最致命）。修复：线索链 6:4 公开/私线比例审计。
4. **风格抹平**：生成文本退化为"技能文档的平均值"。修复：文风指纹注入 + 出口门阻断 AI 腔。
