# 章节体量标准 V2（全作统一）

> 旧标准下的第一章约 2800–3100 字、序章约 1000–1200 字，信息密度够但"读一章不像读一章"。上架后单章是要独立卖钩子的单位，体量必须到位。本标准即刻生效，并回溯适用于全部已交付章节。

## 一、字数标准
| 章节 | 字数 |
|---|---|
| 序章 | 2000–2500 |
| 正文常规章 | **4500–5500** |
| 黄金三章（前 3 章） | 5000–6000 |
| 大底牌章／终章 | 可至 7000 |
| 单章下限 | 4000（不足即视为交付未完成） |

## 二、每章结构配额（5000 字标准章）
| 段 | 字数 | 功能 |
|---|---|---|
| 冷开场钩 | ≤400 | 时间／地点／第一个反常，直接入戏，不铺垫 |
| 主场景 A | 1400–1700 | 本章主事件的展开（勘查／副本／审讯／处刑） |
| 主场景 B（多视点或空间切换） | 1200–1500 | 第二现场或群像节拍 |
| 微观配额（身体记号＋物证细节＋一句关系债） | 300–400 | 每章必含，从人物档案直取 |
| 章尾双钩 | 400–500 | 主钩＋次钩（钩型登记，两钩不得同型） |

## 三、扩写三律
1. **三增原则**：增物证级细节、增信息对白、增情绪节拍——一切扩写内容必须属于以上三类；
2. **禁水清单**：不增风景描写替代事件、不增回忆复述原文、不增"他想着想着"式的心理替代动作、不加新人物不给戏；
3. **密度红线**：每 800 字必须出现一次"反常／代价／反转／钩子"四选一，读不到就砍。

## 四、卷与全书的量级影响
- 卷一 18 章 × 平均 5000 字 ≈ **9 万字／卷**；
- 全书按 5 卷 × 18 章规划，总约 **45–50 万字**（完本体量，长篇规格）；
- 日更节奏（业余）：每章 5000 字、每周 2–3 章，卷一写作周期约 7–9 周——卷一细纲不变，只是每章变厚；
- 漫剧／短剧换算：5000 字／章 ≈ 2–3 集／章，切片口径不变。
