# 章节体量标准 V3（回退版 · 以 V1 初稿为基准）

> 标准：**在原稿基础上增厚约 1/3**。原稿（第一版正文实稿）每章 2800–3100 字 → 新标准 **3600–3900 字**；序章 1000–1200 → **1500 字左右**；大底牌章不设上限。
> 由此推算：卷一 18 章 × 3700 字 ≈ **6.7–7 万字／卷**，全书约 38–40 万字（完本）。

## 一、每章结构配额（3600 字标准章）
| 段 | 字数 |
|---|---|
| 冷开场钩 | ≤300 |
| 主场景 A | 1300–1400 |
| 主场景 B（视点/空间切换） | 1100–1300 |
| 微观配额（身体记号＋物证细节＋一句关系债） | 200–300 |
| 章尾双钩 | 300–400 |

## 二、扩写三律（不变）
1. 三增原则：增物证级细节 / 增信息对白 / 增情绪节拍；
2. 禁水清单：不增风景，不增回忆复述，不增"他想着想着"，不凭空加人物；
3. 密度红线：每 800 字至少一次"反常／代价／反转／钩子"四选一。
