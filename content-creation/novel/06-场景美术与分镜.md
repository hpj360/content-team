# 场景美术与分镜样张（双作）

> 用途：直接供分镜剧本（storyboarding/script-writing 下游）与 AI 漫剧出图使用。场景档案给"可画三要素"（要画出的特征、要避免的坑、爆点镜头位），分镜样张为样张级（镜号／景别／画面／字幕／声音／时长）。
> 美术基调双作分工：**勘察组＝冷色系公文美学（灰蓝＋警戒带橙）**；**一星单＝暖色系生活美学（土黄暖光＋手机蓝黑）**。

# 三、跨作美术红线（AI 出图规范速查）
1. **人物五格**：勘察组全员避免露出"全脸笑容"（制度感）；一星单全员避免"军装感"设定。
2. **色域**：勘察组每幅只允许一个暖点（警戒带橙）；一星单每幅只允许一个冷点（手机蓝）。
3. **文字质感**：勘察组的公文/结案报告必须用印刷体方块字；一星单邮件必须手写体（工单 UI 弹窗允许系统字）。
4. **不出现**：流血、瑞解膨胀类怪兽；一星单副本无实时怪物画面（怪物线只在语音/背影出现——见 04 号"不留物理全怪"）。
5. **两百米守则**：同一主角跨图，识别符（识别符五格表）至少两个索点出现：链不认脸也认位。
