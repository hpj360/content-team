# 《吞兽维修师》人物圣经与主角团（V1 · 资产沉淀）

> 规范：性格写行为证据；每人 2 个物理记忆点（可入漫剧设定集）；每对关系埋一句"没说出口的话"；每角色一句"角色引擎"。

---

## 一、主角：陆岩

- **身份**：21 岁（穿越前 28 岁，汽修工），废料场维修站学徒。
- **一句话**："一个只会修东西的人，被扔进了一个只会换东西的世界。"

### 多维卡
| 项 | 内容 |
|---|---|
| 外貌 | 瘦，手指粗糙有老茧，左手小指少一截；总穿一件洗得发白的工装夹克 |
| 语言指纹 | 爱报数字（"这核还剩 11% 寿命"）；口头禅"能修。"；反驳时只说三个字："拆开看。" |
| 行为证据 | 见到坏东西手会痒；说话时无意识摸裤兜里的扳手；修东西前先擦手（习惯） |
| 欲望 | 攒够钱，开一间自己的修理铺 |
| 恐惧 | "修不好的东西"——前世他父亲的机器出事，他没修好 |
| 缺陷 | 不信任官方与专家；对"活的东西"过度共情 |
| 金句 | "没有修不好的东西，只有不肯拆到底的人。" |

### 记忆点（2 个，可拍）
1. **旧扳手**：穿越时唯一带过来的东西，手柄上刻着一行小字——"**陆岩修理铺，修一切**"（他自己的店，倒闭了）。他从不用它修机甲，只在想家的时候摸一摸。
2. **左手小指**：少一截。前世被压断的，穿越后这具身体也有同样的伤——他第一次发现时，在废料场坐了一整夜。

### 角色弧线
"修东西" → "修人" → "修城" → "修这个时代"。
起点：只想活着、开个铺子；
中点：为了修好 000，第一次承认"有些东西值得拿命去修"；
终点：他修的不再是机器，是七十年前那笔没人愿意认的账。

### 与 000 号机的关系
- 000 会说话，只有他听得见（神经频率匹配）；
- 000 叫他"修理匠"（不是"驾驶员"）；
- 000 的记忆碎片里，有女主父亲失踪那天的画面——**这是一个"人"和一台"机器"互相修的过程**。

## 二、女主：苏晚（鉴定师）

- **身份**：24 岁，壁垒城机甲鉴定科最年轻的 A 级鉴定师；鉴定世家出身。
- **一句话**："她这辈子判过一千两百台机甲的死刑，唯独 000 号机，她判错了。"

### 多维卡
| 项 | 内容 |
|---|---|
| 外貌 | 干净利落，白大褂＋军靴；左耳戴一只老式耳麦（父亲的遗物） |
| 语言指纹 | 说话像写报告："合格。""待定。""报废。"；从不使用"可能"这个词 |
| 行为证据 | 随身带一台老式核检仪；评价一切用"三分法"；紧张时会反复擦镜片 |
| 欲望 | 查清父亲失踪的真相 |
| 恐惧 | 父亲留下的最后一条记录——"000 号机，不可修复"——是错的 |
| 缺陷 | 只相信数据，不相信直觉；对"不确定"极度不安 |
| 金句 | "数据不会骗人。……除非数据是假的。" |

### 记忆点
1. **核检仪**：父亲留下的老式检测仪，屏幕有裂纹，她修过三次，修不好——**她第一次求陆岩修东西，就是修它**。
2. **父亲的最后一条记录**：她随身带着的纸条，写着"000 号机，不可修复"，字迹潦草，像是匆忙写的。

### 角色弧线
判 000 死刑 → 与陆岩一起修 → 发现父亲的记录被篡改 → 直面父亲失踪的真相。
情感线核心：她与陆岩互为谜底——**她父亲的失踪与 000 有关，而 000 只对陆岩说话。**

## 三、主角团（维修站四人＋一台机甲）

### 1. 老周（周铁山），78 岁，维修站老板
- 前军方维修兵，右手七根机械义指（"修人也是修"）。
- 性格：嘴臭、贪财、护短；"只换不修"的实用主义者——因为修的成本比换高。
- 秘密：他参与过七十年前 000 号机的封存；每年 7 月 7 日独自喝酒（首潮纪念日）。**（V2 补：他每年去废料场看 000 一次，不修，只看——"修好了，就得有人开它。开它的人，会死。"见 43 号）**
- 记忆点：①机械义指总在无意识敲桌子（算账的习惯）②柜台下压着一张老照片，照片上的人穿着初代机甲的驾驶服。
- 金句："**修什么修？换！——但你真要修，别死在我店里。**"
- 角色引擎：他嘴上说"只换不修"，是因为他修过一次，没修好——**那一次，死的是他徒弟**。

### 2. 豆子（17 岁），学徒
- 嘴碎、手巧、胆小、崇拜陆岩。
- 记忆点：①永远戴着护目镜（焊东西被烫过，眼睛怕光）②口袋里全是零件，走路叮当响。
- 功能：喜剧担当＋技术流助手＋被绑架（推动剧情）。
- 金句："岩哥，这个……拆了还能装回去吗？"
- 角色弧线：从"换件工"到"真维修师"。

### 3. 铁柱（34 岁），退役军人
- 前壁垒军机甲兵，右腿义肢，因伤退役；欠老周一条命。
- 性格：沉默寡言，战斗担当；只在喝酒后说话。
- 秘密：他在回潮（第二次首潮）中见过 000 号机出动——军方记录里没有这一笔。
- 记忆点：①右腿义肢的关节声（走路有节奏）②胸前挂一枚旧军牌，名字磨掉了。
- 金句："**那台机器，我见过。它当年，不是这个样子。**"

### 4. 000 号机（"零号"），活体机甲
- 七十年前的初代机，最后一台活体机甲；会饿、会进化、会说话（只对陆岩）。
- 性格：像一头饿极了的野兽，又像一个记性太好的老人；说话短，常用命令句。
- 记忆点：①胸口那道"嘴"（吞噬口）②驾驶舱里那行字——"建议进食"。
- 金句："**饿。**"／"**你修我，我记你。**"

## 四、反派

### 1. 冯判（鉴定科长，45 岁）
- 官僚，判定一切为"报废"；口头禅："按规程办。"
- 与苏晚：她的上司，也是她父亲的老同事——**他知道当年的事，但不说**。
- 金句："**报废不是终点，是流程的开始。**"

### 2. 叶氏（机甲贵族）
- 垄断定制机甲生意；最怕活体机甲复活（会毁掉他们的市场）。
- 金句："**机器就该是机器。会饿的东西，不配叫机甲。**"

### 3. 金牙（猎兽公司老板）
- 资本化身，把异兽和猎队都当耗材。
- 金句："**兽核有价，人命也有价。就是不知道哪个更便宜。**"

### 4. 深巢之母（卷三后）
- 地底的存在；异兽逃难的源头。
- 不是"恶"，是"更古老的东西"。

| 关系 | 性质 | 没说出口的话（爆点引信） |
|---|---|---|
| 陆岩×苏晚 | 从对立到搭档 | 她： "你不是第一个想修 000 的人。" 他： "但我是第一个修好的。" |

| 000×苏晚 | 隔着一台机器 | 000 的记忆里，有她父亲最后的样子；但她听不见 000 说话 |
| 豆子×陆岩 | 崇拜者 | 豆子："岩哥，我要是修不好，你会不会不要我？" |

## 九、写作应用检查表（每章）
1. 主角每章至少一次"拆开看"式的行动（不是说话）；
2. 每 3 章一次"修复打脸"或"吞噬升级"；
3. 苏晚每卷至少一次"判错"，每次判错都推动关系；
4. 老周的秘密每卷揭一层；
5. 000 的说话每章不超过 5 句（稀缺感）；
6. 每卷末必须有"人机合一"或"新器官"的升级节点。
