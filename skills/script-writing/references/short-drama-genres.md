# 短剧题材库（单集钩子 / 爽点 / 反派）

> `script-writing` 按需加载参考。六大主流短剧题材的"情绪公式"，用于 25 集
> 竖屏短剧的选题与分集设计；每题材给出核心钩、爽点链、反派配置与雷区。

## 速查矩阵

| 题材 | 核心钩子 | 爽点链 | 反派配置 | 主要雷区 |
|---|---|---|---|---|

| 战神归来 | 隐藏强者 | 被轻视→随手化解→集体傻眼 | 敌方势力 | 战力廉价、无代价碾压 |

## 一、复仇打脸（最主流）

- **核心钩**：主角带着隐藏身份/证据归来，目标明确。
- **爽点链**（25 集）：受辱(1) → 小反击(2-4) → 对手升级(5) → 中点反转(6) → 谷底(7) → 反攻(9) → 逐个打脸(11-23) → 终局揭底(24-25)。
- **反派**：四级递进（小人物→中层→势力→幕后 BOSS），每级 4–6 集。
- **雷区**：复仇对象过多导致失焦；打脸节奏平均化（应递进加大）。

## 二、战神归来

- **核心钩**：隐藏的顶级强者被当作废物。
- **爽点链**：被轻视 → 随手化解危机 → 围观震惊 → 更大的敌人出现。
- **注意**：碾压必须有**代价/限制**（如"出手就暴露身份"），否则无张力。
- **雷区**：战力廉价（随手灭一切）；配角智商随剧情降低。

## 三、甜宠

- **核心钩**：契约/同居/重逢等强关系设定快速拉近距离。
- **爽点链**：心动信号（每 2–3 集）→ 保护欲时刻 → 双向确认。
- **反派**：情敌/家长，功能是"制造误会但要快解"。
- **雷区**：误会拖过 3 集；配角沦为工具；主角无独立目标。

## 四、穿越

- **核心钩**：现代认知在古代/异界的"套利"。
- **爽点链**：用现代知识解决古代难题 → 被奉为上宾 → 旧势力打压 → 反制。
- **注意**：知识要用得**有条件**（材料/信任/时机），不能万能。
- **雷区**：现代人开挂无阻力；穿越动机经不起追问。

## 五、悬疑

- **核心钩**：开场即抛谜面（失踪/尸体/异常）。
- **爽点链**：线索(每 3–5 集小反转) → 中点大反转 → 真相。
- **反派**：真凶 + 同谋，线索必须**公平可见**。
- **雷区**：真凶靠新证据空降；为反转而反转。

## 六、家庭伦理

- **核心钩**：亲情误解与"付出被看见"。
- **爽点链**：被误解 → 默默付出 → 真相被撞见 → 和解落泪。
- **反派**：偏心长辈/外人挑拨。
- **雷区**：为虐而虐；婆媳/重男轻女刻板印象堆砌引发反感。

## 单集设计模板（通用）

```
P1 冷开场(0-3s)   承接上集钩 / 抛新异常
P2 兑现(3-15s)    上集钩子落地
P3 施压(15-35s)   对手加码（本集题材对应的压力）
P4 回击(35-55s)   主角反击（部分成功）
P5 反转(55-70s)   本集题材的核心反转
P6 代价(70-78s)   反击副作用
P7 悬置(78-85s)   强钩子（对照 hook-library 13 式）
P8 出口(85-90s)   付费/预告卡点
```
