# 改编方法论（源 → 目标形态）

> `script-writing` 按需加载参考。改编不是"翻译"，而是**为媒介重建结构**：
> 先抓"哪个人物的哪个欲望"，再按目标形态重组。

## 一、核心原则

1. **抓欲望，不抓情节**：原作真正驱动故事的是某个人物的欲望；情节可以换，欲望要留。
2. **换媒介 = 换承载**：文字靠叙述，影视靠视听，短剧靠钩子密度，舞台靠台词调度。
3. **删减优先**：改编的第一动作是**删**（合并角色、砍支线），不是加。

## 二、改编转换矩阵

| 源 → 目标 | 关键动作 | 常见失败 |
|---|---|---|
| 小说 → 电影 | 删支线、外化心理、给视觉锚 | 照搬叙述句（不可拍） |
| 小说 → 短剧 | 压缩为单集钩子链、前 3 集定生死 | 节奏太慢、信息密度不足 |
| 小说 → 漫剧/分镜 | 拆场景为镜头、定动态部分 | 分镜做新决定（越权） |
| 剧本 → 短剧 | 重排钩子、删过渡、加卡点 | 保留长铺垫 |
| 真实事件 → 剧本 | 找"戏剧性人物"、合并当事人 | 平铺直叙、无主角 |
| IP/游戏 → 剧本 | 抓核心设定与招牌桥段、建改编契约 | 世界观倾倒 |
| 长篇 → 系列/多季 | 每季一个完整弧、跨季伏笔标记 | 主线失焦、注水 |

## 三、小说 → 剧本的六步

1. **抓 logline**：一句话主角+欲望+障碍。
2. **合并角色**：把 5 个配角压成 2–3 个（每个承担唯一功能）。
3. **砍支线**：只留服务主线的 B 故事。
4. **外化心理**：把"他很难过"改为可拍动作（见 `dialogue-examples.md`）。
5. **分场**：按"价值转折"切场（见 `screenwriting-craft.md`）。
6. **定钩子**：每场/每集结尾留钩（见 `hook-library.md`）。

## 四、长篇 → 短剧的压缩法

```
原作主干（3–5 个关键转折）
  → 每个转折 = 一集的核心事件
  → 前 3 集：受辱 + 金手指 + 小爽点
  → 每集末强钩子；卡点放钩子峰值
```
- **压缩比参考**：10 万字小说 ≈ 25 集 × 1.5 分钟短剧。
- 自检：能否用一句话说清"这一集删了什么、留了什么、为什么"。

## 五、IP/游戏改编契约

- 建"改编契约"：必须保留的核心设定、招牌桥段、角色红线；可自由发挥的部分。
- 世界观**分片投放**（见 `genre-scifi-techniques.md`），不倾倒。
- 与 `worldbuilding-guide.md` 配合：改编不新增与原点冲突的规则。

## 六、改编自检清单

- [ ] logline 一句话说清（主角+欲望+障碍）
- [ ] 角色已合并，无冗余配角
- [ ] 心理描写已外化为可拍动作
- [ ] 场景按价值转折切分，晚进早出
- [ ] 每场/每集有钩子
- [ ] 有改编契约（保留项/自由项）且无设定冲突
