# 改编方法论（源 → 目标形态）

> `script-writing` 按需加载参考。改编不是"翻译"，而是**为媒介重建结构**：
> 先抓"哪个人物的哪个欲望"，再按目标形态重组。

## 一、核心原则

1. **抓欲望，不抓情节**：原作真正驱动故事的是某个人物的欲望；情节可以换，欲望要留。
2. **换媒介 = 换承载**：文字靠叙述，影视靠视听，短剧靠钩子密度，舞台靠台词调度。
3. **删减优先**：改编的第一动作是**删**（合并角色、砍支线），不是加。

## 二、改编转换矩阵

| 源 → 目标 | 关键动作 | 常见失败 |
|---|---|---|
| 小说 → 电影 | 删支线、外化心理、给视觉锚 | 照搬叙述句（不可拍） |
| 小说 → 短剧 | 压缩为单集钩子链、前 3 集定生死 | 节奏太慢、信息密度不足 |
| 小说 → 漫剧/分镜 | 拆场景为镜头、定动态部分 | 分镜做新决定（越权） |
| 剧本 → 短剧 | 重排钩子、删过渡、加卡点 | 保留长铺垫 |
| 真实事件 → 剧本 | 找"戏剧性人物"、合并当事人 | 平铺直叙、无主角 |
| IP/游戏 → 剧本 | 抓核心设定与招牌桥段、建改编契约 | 世界观倾倒 |
| 长篇 → 系列/多季 | 每季一个完整弧、跨季伏笔标记 | 主线失焦、注水 |

## 三、小说 → 剧本的六步

1. **抓 logline**：一句话主角+欲望+障碍。
2. **合并角色**：把 5 个配角压成 2–3 个（每个承担唯一功能）。
3. **砍支线**：只留服务主线的 B 故事。
4. **外化心理**：把"他很难过"改为可拍动作（见 `dialogue-examples.md`）。
5. **分场**：按"价值转折"切场（见 `screenwriting-craft.md`）。
6. **定钩子**：每场/每集结尾留钩（见 `hook-library.md`）。

## 四、长篇 → 短剧的压缩法

```
原作主干（3–5 个关键转折）
  → 每个转折 = 一集的核心事件
  → 前 3 集：受辱 + 金手指 + 小爽点
  → 每集末强钩子；卡点放钩子峰值
```
- **压缩比参考**：10 万字小说 ≈ 25 集 × 1.5 分钟短剧。
- 自检：能否用一句话说清"这一集删了什么、留了什么、为什么"。

## 五、IP/游戏改编契约

- 建"改编契约"：必须保留的核心设定、招牌桥段、角色红线；可自由发挥的部分。
- 世界观**分片投放**（见 `genre-scifi-techniques.md`），不倾倒。
- 与 `worldbuilding-guide.md` 配合：改编不新增与原点冲突的规则。

## 六、改编自检清单

- [ ] logline 一句话说清（主角+欲望+障碍）
- [ ] 角色已合并，无冗余配角
- [ ] 心理描写已外化为可拍动作
- [ ] 场景按价值转折切分，晚进早出
- [ ] 每场/每集有钩子
- [ ] 有改编契约（保留项/自由项）且无设定冲突

## 附、文学 ↔ 影视转场对照表

> 用途：把章际转场（`novel-writing/references/chapter-continuity.md` 七法）换算成镜头/剪辑语言
> （镜头层分类见 `storyboarding/references/edit-rhythm-and-transition.md`）。改编剧最常"翻译错"
> 的就是转场——文学靠语句，影视靠声画。示例全部自造。

| 文学转场（七法） | 影视等价手法 | 换算要点 | 常见翻译错 |
|---|---|---|---|
| 尾词复现 | 对白衔接切（上句尾词=下句首词） | 保留"词桥"，用 J-cut 提前入声 | 直接硬切丢桥 |
| 物件接力 | 道具匹配切（match cut on prop） | 同一物件跨场景延续（伞/钥匙/照片） | 物件在两场各给一次，没做"同一件" |
| 声音桥 | J/L-cut 声先于画 | 下一场声音提前 1–2s 进入 | 声画同进，桥感消失 |
| 行走过渡 | 跟随镜头越场（on-the-move transition） | 行走方向=叙事方向，途中给新环境一角 | 停下来再切，变成两场 |
| 时间铆钉 | 字幕卡/时钟空镜/日历翻页 | 铆钉只放一处，别字幕+空镜叠加 | 双重标注削弱信任 |
| 回环句 | 首尾呼应镜头（opening image callback） | 同机位/同景别的变奏重现 | 换了机位还宣称呼应 |
| 制式桥 | 惯例化过渡（新闻片头/列车报站/班牌特写） | 制式只服务"时间跳"一种功能 | 用制式桥遮剧情跳（偷懒感） |

**反向（影视→小说）**：交叉蒙太奇→双线章节交替（章尾互挂钩）；洗礼式对位剪辑→同一章内双线段交替
（各段 ≤300 字）；闪回蒙太奇→自由间接引语短闪（≤25 字，一句即止，见 `scene-detail-engineering` 心理四外化）。

自检：每次改编剧转场，问一句"**原句的桥是什么？**"——桥丢了就补一件道具、一个声音或一个词。
