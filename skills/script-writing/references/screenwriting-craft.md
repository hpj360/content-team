## 一、结构：事件—场景—序列—幕

- **事件**：一个变化。没有变化就不是事件；没有事件就不是场景。
- **场景**：价值发生转折的最小单位（正→负 或 负→正）。
- **序列**：若干场景构成一段走向明确的小高潮。
- **幕**：幕末发生不可逆的转折，把故事推入新处境。

三幕骨架：

1. **建置**：现状 + 激励事件（打破平衡）。
2. **对抗**：递进复杂化（每次解法带来更大问题）。
3. **结局**：危机 → 高潮 → 解决，价值回到新的平衡。

节拍参考：开场画面 → 主题呈现 → 铺垫 → 催化剂 → 争论 → 第二幕转折 → B 故事 → 中点 → 坏人逼近 → 一无所有 → 灵魂黑夜 → 第三幕转折 → 结局 → 终场画面。

## 二、人物与冲突

- **三维人物**：生理/社会/心理，缺一不可。
- **对立统一**：主角与对手在目标上对立，在能力上匹配（对手要强）。
- **给对手一把刀**：让对手有正当动机与杀伤力，主角的胜利才有价值。
- **冲突类型**：上升冲突（越来越难，主流）、静态冲突（原地拉扯）、跳跃冲突（突变，慎用）。
- **转折**：人物的变化必须由事件逼出来，不能靠旁白宣布。

## 三、台词

- **台词即动作**：每句台词都在企图改变对方或处境。
- **说 / 不说 / 说不出**：优先写人物"不愿说"和"说不出口"的部分，用行为与停顿承载潜台词。
- **说明性信息是弹药**：把背景信息藏在冲突里抛，不要集中成"解释段"。
- **台词缺陷清单**：过于对称、信息过载、人人一个腔调、把结论说尽、无目的寒暄。
- **性格化词汇**：让不同角色的用词、句长、口头禅可区分。
- **节拍用动名词**：一个节拍 = 一个动作（"撬开真相""掩饰慌张"），先标节拍再写台词。

## 四、场景手艺

- **五步场景分析**：谁想要什么 → 障碍是什么 → 冲突如何升级 → 谁赢/输 → 价值如何翻转。
- **晚进早出**：在冲突已经开始后进场，在转折发生后立刻离场。
- **动作优先于对白**：能用动作演的，不要用台词说。
- **地点即隐喻**：同一场戏换个地点，含义可能完全不同；优先选择能施压的空间。
- **悬念 / 延迟 / 机锋**：先让观众比角色多知道一点（悬念），再延迟偿还（延宕），用智性对白制造机锋。

## 五、格式与打磨

- 规范格式硬规则：场次标题（内/外·地点·时间）、动作段、角色名、台词，逐项统一。
- 草稿阶梯：分步大纲 → 处理稿(treatment) → 剧本 → 修订。
- 修订 pass 顺序：结构 → 场景 → 台词 → 格式与错别字。
- 改编：先抓原作的"哪个人物的哪个欲望"，再重建可拍摄的场景，不要逐句翻译叙述。

## 六、质量门（机器可验证）

- [ ] `logline` 非空且 ≤ 200 字，含主角+欲望+障碍
- [ ] 场景数 ≥ 3，每场都有 `slugline` 与明确 `purpose`
- [ ] 每场满足"价值转折"：进场价值与出场价值不同
- [ ] 每场至少一条动作描述或一句台词，无空场
- [ ] 台词无旁白式心理描写，无"人人一个腔调"
- [ ] `body` 非空，场景顺序与 `scenes` 一致
- [ ] 对手有明确动机与威胁（无对手的场次需说明原因）
