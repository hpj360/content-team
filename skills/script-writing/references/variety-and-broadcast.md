# 综艺台本 / 口播 / 广播剧（非叙事脚本写法）

> `script-writing` 按需加载参考。这三类**不是"讲故事"的剧本**，而是"交付流程/信息/声音"的脚本。
> 与叙事剧本的最大差异：**不靠情节，靠结构与人设感**。

## 一、综艺/栏目台本

**定位**：交付一份"可执行的录制流程"，不是台词全文。

```
【节目】名称　【期数】EP12　【时长】45 min
【本期主题】一句话
【环节表】
  环节一 开场（5 min）
    主持人开场口播：3 句（钩子/本期看点/悬念）
    嘉宾介绍：每人 1 句记忆点
  环节二 核心游戏（20 min）
    规则（可执行、无歧义）：目标 / 步骤 / 胜负判定
    预设冲突点：2 个（制造看点）
    突发应对：3 条（冷场/失控/超时的兜底）
  环节三 收尾（5 min）
    金句提炼 / 下期预告
【剪辑点提示】笑点 / 反应镜头 / 字幕点
```

- 规范：**写流程 + 规则 + 兜底**，台词给"方向"而非逐字。
- 自检：一个没看过节目的人，能否按台本独立执行？

## 二、口播 / 知识脚本

**定位**：一个人对着镜头讲清一件事。

```
钩子(0–3s)    "如果你也遇到过 X……"
承诺(3–8s)    "这条视频讲清 3 件事"
主体          Point1：结论 + 一个例子
              Point2：结论 + 一个例子
              Point3：结论 + 一个例子
收尾(末5s)    行动号召 / 关注引导
```

- 规范：口语化（写出来读一遍，拗口就改）；**每点先给结论**；数字与例子替代形容词。
- 反例：书面语、长句、"综上所述"。
- 自检：去掉画面只看文稿，能否听懂？

## 三、广播剧 / 有声剧脚本

**定位**：没有画面，**声音即画面**。

```
【场景】地点·时间
【音效】环境声（雨/脚步/门响/金属摩擦）
角色A（情绪）：台词。
【音乐】情绪提示（进入/骤停）
【留白】2 秒（呼吸/沉默）
```

- 规范：用**音效与留白**替代视觉描述；旁白与对白分工（旁白交代、对白冲突）。
- 关键技法：
  - **声音蒙太奇**：上场景声音延续到下场景（L-cut），无画面也能转场。
  - **听觉锚点**：给角色一个标志性声音（口癖/脚步声），替代"识别符"。
  - **留白即节奏**：情绪峰值前抽掉音乐 1–2 秒。
- 自检：闭眼听一遍，能否在脑中"看见"场景？

## 四、三类共性自检

- [ ] 结构清晰（流程/要点/场景），可独立执行
- [ ] 无书面语/无旁白式心理描写
- [ ] 每类都用足了其核心承载（综艺=流程看点、口播=结论例子、广播=音效留白）
- [ ] 结尾有明确出口（下期预告/行动号召/情绪收束）

## 五、与本项目集成

- 口播/广播剧可作 `Content`（`content_type=video_script/audio_script`）进入发布管线；
- 广播剧的音效/留白标注对应 `Shot.sound` 与 `sound-and-edit-craft.md` 的声音三层。
