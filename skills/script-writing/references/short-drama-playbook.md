# 短剧剧本手册（蒸馏）

> 面向 `script-writing` 的按需加载参考。蒸馏自公开短剧 skill 的工业化方法与节奏公式，重构为可执行清单，非逐字引用。
>
> 节奏段位与时长以 `beat-sheets.md` 为准，本篇负责 3/30/60 公式与爽点矩阵的表达层。

## 一、黄金节奏公式

单集遵循：**3 秒抓眼 → 30 秒冲突 → 60 秒反转 → 结尾强钩子**。

- 单集时长默认 1–2 分钟（约 300–2500 字，取决于语速）。
- 时长按语速**确定性折算**：`估算时长 ≈ 台词字数 / 语速(字/秒)`，不要凭感觉说"差不多"。
- 每集结尾必须留钩子；无钩子 = 不合格。

## 二、单集结构

| 位置 | 功能 | 要求 |
|---|---|---|
| 0–3 s | 抓眼 | 冲突/悬念/异常画面，前 3 拍（节拍）内兑现 |
| 冷开场 | 兑现钩子 | 不用旁白交代背景 |
| 主体 | 冲突递进 | 每 2–3 拍一次压力升级 |
| 反转 | 认知/局势突变 | 位置在 60 s 附近 |
| 结尾 | 强钩子 | 指向下一集的悬念或宣战 |

## 三、节奏曲线与爽点矩阵

- 铺垫集：建立缺口，爽点密度低，但要埋钩子。
- 释放集：兑现爽点，情绪回报集中。
- 整体曲线：全季呈"小爽—大爽—超爽"递进，避免平铺。
- 爽点类型：打脸、扮猪吃虎、身份揭露、逆袭、护短、复仇、团宠。
- 付费卡点：放在最强钩子处（悬念最高、爽点将出未出）。

## 四、反派四级递进

反面压力逐级升级，避免一次用尽：

1. 小人物骚扰（制造即时摩擦）
2. 中层对手算计（制造持续威胁）
3. 势力/组织打压（制造系统性困境）
4. 幕后大 BOSS（终局对决）

## 五、合规清单

- [ ] 无低俗色情、擦边内容
- [ ] 无违法犯罪的具体教程性描写
- [ ] 无地域/群体歧视、无恶意煽动
- [ ] 无封建迷信的实操引导
- [ ] 涉及行业/机构有合理免责标注（如需要）

## 六、格式与避坑

标准输出（红果式）：

```
【第X集】集名（一句话概括核心冲突）
第1场  内/外  日/夜  具体地点
【运镜】本场主镜头运镜标注（景别+运镜+叙事目的）
人物：角色A（身份/状态）、角色B（身份/状态）
【角色A】
（动作/表情/神态）〔镜头：钩子/打脸/反转/登场处的专属运镜〕
台词。
（音效/旁白/环境音）
```

避坑清单：

- 禁止"不由得、顿时、心中暗道"等 AI 模板化表达
- 禁止大段环境描写与心理活动
- 禁止超过 3 行的连续台词
- 禁止每集结尾没有钩子
- 禁止场次缺少内/外、日/夜标注
- 禁止动作与台词混写在同一行
- 禁止运镜模糊表述（"有氛围感的镜头"），必须用运镜术语

## 七、质量门（机器可验证）

- [ ] 每集有非空 `hook`（结尾钩子）与集名
- [ ] 时长折算有依据（字数 / 语速），非估计值
- [ ] 每集含至少一处反转或认知突变
- [ ] 反派压力符合四级递进，无跳级或重复
- [ ] 合规清单逐项通过
- [ ] 出口项：无 AI 模板化表达、无超 3 行连续台词、无缺标注场次
