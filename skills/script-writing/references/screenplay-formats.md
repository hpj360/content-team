# 剧本形态格式规范（九类）

> `script-writing` 按需加载参考。不同形态的剧本**格式、节奏、交付标准**差异极大。
> 本表给九类形态的规范与最小模板，先定形态再动笔。

## 一、电影/长片（FEATURE）

```
场景号. 内/外景 - 地点 - 时间
动作描述段（现在时，可拍摄）。
            角色名
        台词。
                          （转场提示）
```
- 规范：动作段不写心理；每场标注进出时间；页数≈分钟（1 页 ≈ 1 分钟）。
- 节奏：三幕，幕点在第 25%/50%/75%。

## 二、短剧（SHORT_DRAMA，单集 2–5 min）

```
【第X集】集名
第1场  内/外  日/夜  地点
【运镜】景别+运镜+叙事目的
人物：角色A（身份/状态）
【角色A】
（动作）〔镜头：钩子/打脸处〕
台词。
```
- 规范：3/30/60 公式；单集强钩子；时长按语速折算（4.2 字/秒）。

## 三、微短剧/短视频脚本（MICRO，30–90 s）

```
0–3s   钩子（画面 + 文案）
3–20s  冲突/信息
20–40s 转折
末5s   行动号召
```
- 规范：字幕全程；单句台词 ≤3 行；每镜 2–5 s（与分镜硬门一致）。

## 四、舞台剧（STAGE）

```
【幕/场】地点·时间
（舞台说明：布景/灯光/调度）
角色A：（动作提示）台词。
角色B：台词。
```
- 规范：以**场**为单位；舞台说明写"可执行调度"；台词需"读出来能演"。
- 特点：无剪辑，靠**台词与调度**承载全部节奏；群戏需标注走位。

## 五、综艺/栏目（VARIETY）

```
【环节一】名称（时长）
主持人开场（口播稿）
嘉宾互动（Q&A 预设 + 突发应对）
游戏/任务规则（可执行描述）
剪辑点提示（笑点/反应/字幕）
```
- 规范：**台本而非剧本**——写清流程、规则、可剪辑点；留即兴空间。

## 六、口播/知识脚本（ORAL）

```
钩子(0–3s)   "如果你也遇到过……"
承诺         "这条视频讲清 3 件事"
主体         Point 1 / 2 / 3（每点一句结论 + 一个例子）
收尾         行动号召 / 关注引导
```
- 规范：口语化；每点先给结论；数字与例子替代形容词。

## 七、广播剧/有声剧（AUDIO）

```
【场景】地点·时间
【音效】环境声（雨/脚步/门响）
角色A（情绪）：台词。
【音乐】情绪提示
【留白】2 秒
```
- 规范：**声音即画面**——用音效与留白替代视觉描述；旁白与对白分工明确。

## 八、漫剧/动态漫画（ANIMATION）

```
【分镜N】景别+画面描述
【台词/旁白】
【音效/配乐】
【动态提示】推/摇/局部动效
```
- 规范：介于剧本与分镜之间；标注"可动部分"与"静态部分"。

## 九、广告/品牌短片（AD）

```
0–3s   痛点/悬念
3–15s  产品出场（功能具象化）
15–25s 使用场景（证据）
25–30s 品牌 slogan + 行动号召
```
- 规范：**30 秒讲一件事**；卖点必须"看得见"；结尾品牌落款。

## 形态选择自检

- [ ] 形态已确定，且格式符合本表对应规范
- [ ] 时长/篇幅与形态匹配（见上表）
- [ ] 该形态的核心承载（电影=视听、舞台=台词调度、广播=声音）已用足
- [ ] 交付物可直接被下游使用（分镜/剪辑/配音）
