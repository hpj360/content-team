# 剧本形态格式规范（九类）

> `script-writing` 按需加载参考。不同形态的剧本**格式、节奏、交付标准**差异极大。
> 本表给九类形态的规范与最小模板，先定形态再动笔。

## 一、电影/长片（FEATURE）

```
场景号. 内/外景 - 地点 - 时间
动作描述段（现在时，可拍摄）。
            角色名
        台词。
                          （转场提示）
```
- 规范：动作段不写心理；每场标注进出时间；页数≈分钟（1 页 ≈ 1 分钟）。
- 节奏：三幕，幕点在第 25%/50%/75%。

## 二、短剧（SHORT_DRAMA，单集 2–5 min）

```
【第X集】集名
第1场  内/外  日/夜  地点
【运镜】景别+运镜+叙事目的
人物：角色A（身份/状态）
【角色A】
（动作）〔镜头：钩子/打脸处〕
台词。
```
- 规范：3/30/60 公式；单集强钩子；时长按语速折算（4.2 字/秒）。

## 三、微短剧/短视频脚本（MICRO，30–90 s）

```
0–3s   钩子（画面 + 文案）
3–20s  冲突/信息
20–40s 转折
末5s   行动号召
```
- 规范：字幕全程；单句台词 ≤3 行；每镜 2–5 s（与分镜硬门一致）。

## 四、舞台剧（STAGE）

```
【幕/场】地点·时间
（舞台说明：布景/灯光/调度）
角色A：（动作提示）台词。
角色B：台词。
```
- 规范：以**场**为单位；舞台说明写"可执行调度"；台词需"读出来能演"。
- 特点：无剪辑，靠**台词与调度**承载全部节奏；群戏需标注走位。

## 五、综艺/栏目（VARIETY）

- 写**台本而非剧本**：按环节分段，每段标时长，规则写成可执行描述。
- 必写四件：主持人开场口播、嘉宾互动预设（Q&A + 突发应对）、游戏/任务规则、剪辑点提示（笑点/反应/字幕）。
- 自检：留够即兴空间；每个环节都能单独剪成一条短视频。

完整模板与写法见 `variety-and-broadcast.md`（综艺/口播/广播剧各一节）。

## 六、口播/知识脚本（ORAL）

- 四段式：钩子(0–3 s) → 承诺（"这条讲清 N 件事"）→ 主体（每点一句结论 + 一个例子）→ 收尾行动号召。
- 口语化写作；每点先给结论，用数字与例子替代形容词。
- 自检：闭眼只听音频也能听懂；单段不超过 30 秒。

完整模板与写法见 `variety-and-broadcast.md`（综艺/口播/广播剧各一节）。

## 七、广播剧/有声剧（AUDIO）

- **声音即画面**：用环境音效与留白替代视觉描写；场次标地点·时间。
- 台词标情绪，音效/配乐/留白各自独立成行（留白 2 秒级）；旁白与对白分工明确。
- 自检：闭眼单听，能分辨人物、地点与情绪走向。

完整模板与写法见 `variety-and-broadcast.md`（综艺/口播/广播剧各一节）。

## 八、漫剧/动态漫画（ANIMATION）

```
【分镜N】景别+画面描述
【台词/旁白】
【音效/配乐】
【动态提示】推/摇/局部动效
```
- 规范：介于剧本与分镜之间；标注"可动部分"与"静态部分"。

## 九、广告/品牌短片（AD）

```
0–3s   痛点/悬念
3–15s  产品出场（功能具象化）
15–25s 使用场景（证据）
25–30s 品牌 slogan + 行动号召
```
- 规范：**30 秒讲一件事**；卖点必须"看得见"；结尾品牌落款。

## 十、格式硬规则与交付标准（深度）

### 10.1 美式剧本格式（电影/美剧）

| 元素 | 规则 |
|---|---|
| 页面 | 12pt 等宽（Courier）；左右边距 1"–1.5"；页数≈分钟 |
| 场景标题 | `INT./EXT. 地点 - 时间`（全大写）；场景号在左 |
| 动作段 | 现在时、可拍摄；首次出场角色名**全大写** |
| 台词块 | 角色名居中大写；括注（paren）只写"动作意图"，不写情绪指令 |
| 转场 | 仅必要处用 `CUT TO:` / `FADE OUT.`（现代剧本少用） |
| 修订标记 | 二稿起页眉标 `Revised: <date>`；改动处页边加星号 `*` |

### 10.2 中文剧本格式（国内短剧/电视剧）

| 元素 | 规则 |
|---|---|
| 场次 | `第X场　内/外　日/夜　地点`（一行说清） |
| 人物栏 | 出场人物列表（身份/状态），便于制片统计 |
| 动作 | 独立成行，不与台词混排 |
| 台词 | 角色名独占一行，台词另起 |
| 运镜 | 短剧必标（景别+运镜+叙事目的），长剧可选 |
| 集数/页数 | 首页标注集数、总页数、时长预估 |

### 10.3 修订与交付

- **修订稿阶梯**：分场大纲 → 处理稿(treatment) → 初稿 → 二稿 → 定稿。
- **修订标记**：页眉日期 + 改动页边星号 + 变更说明页（改了哪场、为什么）。
- **交付清单**：剧本正文 + 人物表 + 分场表 + 时长估算 + 格式说明（目标平台/形态）。
- **常见退稿原因**：动作段不可拍、台词说尽潜台词、场次无价值转折、无钩子、格式混乱。

### 10.4 与门禁联动

- 交付前过 `gate_script`：场景数(S004)、心理旁白(S005)、AI 腔(S006)、合规(S007)；
- 时长折算（4.2 字/秒）与目标平台区间比对（见 `platform-playbooks.md`）。

## 形态选择自检
- [ ] 形态已确定，且格式符合本表对应规范
- [ ] 时长/篇幅与形态匹配（见上表）
- [ ] 该形态的核心承载（电影=视听、舞台=台词调度、广播=声音）已用足
- [ ] 交付物可直接被下游使用（分镜/剪辑/配音）
