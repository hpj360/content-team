# 场景写作练习库（八类场景写法）

> `script-writing` 按需加载参考。八类高频场景的**可练习写法**，每类给：目标 / 结构 / 反例 / 改写要点。
> 与 `dialogue-examples.md`（台词）、`screenwriting-craft.md`（理论）配套使用。
>
> **边界**：本篇=八类场景的**写法素材与改写要点**（怎么写得好看）；"这场戏该不该存在"的判定见 `scene-engineering.md`。
> 物理层细节（环境/动作/物件/感官/影响）见 `skills/novel-writing/references/scene-detail-engineering.md`。

## 一、冲突场景（对峙）

- **目标**：让价值在场景内翻转（谁占上风易位）。
- **结构**：施压 → 抵抗 → 加码 → 翻转。
- **反例**：两人各说各话，结尾无变化。
- **改写要点**：给"筹码"具象化（一份文件、一个电话、一个证人）；最后一拍必须有人失去/获得。

## 二、揭示场景（信息炸弹）

- **目标**：抛出一个**重新定义前文**的信息。
- **结构**：平静铺垫 → 细节异常 → 揭示 → 余震（听者反应）。
- **反例**：信息由旁白直接宣布。
- **改写要点**：信息用**物证或他人之口**给出；揭示后必须留一拍反应镜头。

## 三、追逐/动作场景

- **目标**：空间与距离的压迫感。
- **结构**：同框建距 → 障碍升级 → 视觉暂失 → 再同框（距离归零）。
- **反例**：只有速度没有空间关系。
- **改写要点**：每 2–3 拍交代一次**方位**（谁在前、隔多远）；用障碍（门/楼梯/人群）替代纯跑动。

## 四、情感场景（告别/和解）

- **目标**：情绪落差，不靠台词说破。
- **结构**：日常动作 → 未说出口 → 一个具体物/动作承载 → 留白。
- **反例**："我爱你，别走"式直白。
- **改写要点**：把台词换成**选择动作**（收伞、留灯、多买一份早餐）；情绪峰值用一个物件。

## 五、喜剧场景

- **目标**：荒诞前提下的必然推论。
- **结构**：立规则 → 升级×3 → 反转/摊牌 → 回调。
- **反例**：靠角色做鬼脸或段子堆砌。
- **改写要点**：角色**认真对待荒诞**；笑点后留白 0.5 拍。

## 六、悬疑场景（信息差）

- **目标**：让观众比角色多知道一点，或更少。
- **结构**：异常建立 → 线索分层 → 误导 → 局部揭示（留更大谜面）。
- **反例**：线索藏而不给（不公平）。
- **改写要点**：所有线索**公开可见**；误导必须可回溯（观众复盘时承认"我该看到"）。

## 七、建置场景（新世界首现）

- **目标**：15–18 秒交代时代/地域/秩序/主角"抓手"。
- **结构**：远景世界 → 场所 → 场内秩序 → 主角识别符 → 入场。
- **反例**：大段旁白介绍背景。
- **改写要点**：用**秩序细节**替代解说（排队的人群、招牌的文字、光线的方向）。

## 八、过渡场景（换场衔接）

- **目标**：时空转换不生硬，且携带信息。
- **结构**：上场景余韵 → 匹配元素（声/物/动作）→ 下场景进入。
- **反例**：硬切导致"断片"。
- **改写要点**：用 match cut（相似物/相似动作/声音延续）承担转场，并让它顺带交代时间流逝。

## 练习法（每日 15 分钟）

1. 选一类，写 300 字场景（只写动作+台词，禁心理描写）。
2. 自检：**进场价值 ≠ 出场价值**？结尾有钩子？
3. 对照本类"改写要点"改一遍；把改进项记入 `knowledge/corpus/failure-corpus.md` 若属常见错误。
