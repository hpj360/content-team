# 平台爆款结构模板（按平台套用）

> `showrunning` 按需加载参考。与 `platform-playbooks.md`（规则）配套：本文件给**可套用骨架**。
> 用法：定平台 → 套骨架 → 用题材库填内容 → 过发布前检查清单。

## 一、番茄小说（免费流网文）

```
第1章  处境+金手指+钩子（前500字出主角与冲突）
第2章  第一个明确冲突（主角的选择）
第3章  小爽点+更大悬念（黄金三章收口）
第4–N章  压:爆 ≈ 2.5:1，章章钩子，每 10 章一次大爽点
```
- 骨架要点：**开篇 500 字 = 主角 + 处境 + 钩子**；断更伤权重。

## 二、起点中文网（付费订阅）

```
第1章  设定亮点（世界的独特性）
第2章  冲突引入
第3章  小爽点（留住读者）
第4–20章  养读者 + 埋设定（第一个大副本）
```
- 骨架要点：读者吃**设定与逻辑**；前期不急着爆。

## 三、红果短剧（竖屏单集）

```
P1 冷开场(0-3s)  抓眼
P2 兑现(3-15s)   上集钩子
P3 施压(15-35s)  对手加码
P4 回击(35-55s)  部分成功
P5 反转(55-70s)  认知/局势翻转
P6 代价(70-78s)  副作用
P7 悬置(78-85s)  强钩子
P8 出口(85-90s)  卡点
```
- 配套模板：`short-drama-episode-8beat`。

## 四、抖音（短视频）

```
0–3s    钩子（画面+文案给出"为何看下去"）
3–20s   冲突/信息推进
20–40s  转折
末5s    行动号召
```
- 骨架要点：完播率优先；字幕全程；18:00–22:00 发布。

## 五、小红书（图文/短视频）

```
封面    痛点/对比/大字（决定点击）
前2行   承诺（看了能获得什么）
正文    分段 + emoji，300–800 字
标签    3–6 个（大词+长尾）
```
- 骨架要点：搜索流量；避免站外引流。

## 六、微信公众号（图文）

```
标题    信息量 + 一点悬念
开头300字  故事/冲突开场（禁"随着……的发展"）
主体    每段 2–4 行；重点加粗；1 图/300 字
结尾    行动号召 + 在看/分享引导
```

## 七、视频号（短视频）

```
0–5s    价值点（值得转发的理由）
5–60s   实用/情感/知识主体
末5s    转发引导
```
- 骨架要点：社交推荐，**求转发**（区别于抖音求完播）。

## 八、B站（中视频）

```
前15s   本期内容承诺
主体    2–3 个信息高点（防中段流失）
结尾    三连引导
```
- 骨架要点：标题带信息量；分 P/合集利于追更。

## 九、知乎（问答/专栏）

```
开头    结论或反常识判断
论证    分层论证 + 来源标注
收束    回到结论
```
- 骨架要点：2000–5000 字；**引用标注来源**（可信度）。

## 十、快手（短视频）

```
前3s    接地气钩子
主体    口播直给，少铺垫
结尾    关注/互动引导
```
- 骨架要点：真实感优先；直播联动。

## 十一、微博（短图文）

```
首句    即观点
配图    1–3 张
话题    @话题
```
- 骨架要点：≤300 字；情绪鲜明。

## 组合用法

1. 同一内容多平台分发 → 取"母版"（如剧本）→ 按各平台骨架改写（格式适配由 `creative/exporters.py` 承担）；
2. 骨架只管**结构**，内容质量仍由题材库（`genre-*.md`）与语料（`knowledge/corpus/`）保证；
3. 发布前逐项过 `platform-playbooks.md` 的检查清单。
