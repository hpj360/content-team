# 系列与连载规划

> `showrunning` 按需加载参考。与 `episode-rhythm-examples.md`（单季节奏表）互补：
> 本文件解决**多季/长线**的结构问题——伏笔跨季、人设跨季、引擎可持续。

## 一、三层规划结构

```
总纲（系列定位 + 终局）→ 季纲（每季一个完整弧）→ 集纲（钩子/冲突/高潮/悬念）
```

- **总纲**：一句话终局（结局是终点，不是续命）——防止无限注水。
- **季纲**：每季自含"起承转合"，季末给"重定义系列"的真相（对应反转重估）。
- **集纲**：见 `episode-rhythm-examples.md`。

## 二、可持续引擎（防中段疲软）

| 引擎类型 | 说明 | 风险 |
|---|---|---|
| 目标推进型 | 一个明确终局目标，逐季逼近 | 目标达成即结束，需提前铺第二目标 |
| 世界扩张型 | 每季换地图/新势力 | 易失焦，需主线锚 |
| 关系演化型 | 核心关系逐季变化 | 关系耗尽即疲软 |
| 谜团升级型 | 每季揭示更大谜面 | 谜面通胀，需控制层数 |

- **推荐**：主引擎 1 个 + 副引擎 1 个（如"目标推进 + 关系演化"）。
- 自检：第 N 季结束时，能否一句话说清"这一季改变了什么"？

## 三、伏笔跨季管理

- 每条伏笔登记 `planned_resolution`，**跨季伏笔单独标记**（如 `S2-EP03`）。
- 每季末跑一次"未回收清单"，决定：本季回收 / 延至下季（须显式记录）/ 放弃。
- 反例：跨季伏笔无标记 → 后期遗忘（`gate_foreshadowing_lifecycle` L005 会暴露）。

## 四、人设跨季一致性

- 人物"四维状态"逐季记录（能力/心理/关系/目标），季初对照季末。
- 跨季允许的变化必须**有事件依据**（不能"新一季性格变了"）。
- 红线（不可违背）跨季恒定；若确需变更，作为季末大转折显式处理。

## 五、节奏总控

| 位置 | 节奏 |
|---|---|
| 季初 3 集 | 承接上季钩子 + 立本季目标（快） |
| 季中 | 2 个高潮 + 1 次谷底 |
| 季末 2 集 | 兑现 + 抛出重定义真相 + 下季钩 |

- 全季"压:爽"≈5:7；越靠后爽点越大（梯度兑现）。

## 六、自检清单

- [ ] 总纲有明确终局，且终局不靠"续命"维持
- [ ] 主引擎 + 副引擎各一，且季末能一句话概括改变
- [ ] 跨季伏笔显式标记 `planned_resolution`
- [ ] 人物四维状态逐季记录且变化有事件依据
- [ ] 季末有"重定义"真相 + 下季钩子
