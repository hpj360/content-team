# 悬疑/推理专属技法库

> `novel-writing` 按需加载参考。悬疑的唯一公平性准则：**所有推理所需的线索，
> 必须在揭晓前对读者可见**。本库给诡计分类、线索链设计与反转层级。

## 一、诡计分类（六类）

| 类型 | 核心 | 代表作范式（公版） |
|---|---|---|
| 本格解谜 | 读者可参与推理 | 《俄狄浦斯王》的调查即自证 |
| 密室/不可能犯罪 | 排除法推理 | —（范式通用） |
| 叙述性诡计 | 叙述者误导 | 《泄密的心》的不可靠叙述 |
| 社会派 | 动机重于手法 | 现实题材 |
| 多视角/罗生门式 | 同一事件多版本 | 芥川《罗生门》式结构 |
| 时间诡计 | 时间线错位 | 剧本杀的"时间线碰撞" |

## 二、线索链设计（三段式）

```
公开线索（60%）→ 指向 → 隐藏线索（40%）→ 解锁 → 真相
```

- 每条线索登记进 `StoryState.foreshadowing`（`content/planted_at/planned_resolution/keyword`）。
- **公平性自检**：把真相所需线索列一张表，逐条确认"读者在揭晓前能读到"。

## 三、误导（Red Herring）三原则

1. **可回溯**：误导必须真实存在（不是作者临时栽赃），读者复盘时承认"我该注意到"。
2. **有动机**：被误导的角色行为在其信息集下合理。
3. **有限度**：全文误导 ≤ 2 条主线级，过多 = 读者愤怒。

## 四、真凶设定（防"空降"）

- 真凶必须在**前 1/3 出场**（哪怕只是路人）。
- 真凶的动机链必须在揭晓时**可完整回溯**（对应 `dialogue-examples.md` 的"给动机"）。
- 反例：真凶靠"新证据"在最后 10 页空降 → 读者被欺骗。

## 五、反转层级（三层递进）

| 层 | 功能 | 位置 |
|---|---|---|
| 局部反转 | 修正一角认知 | 每 3–5 章 |
| 中点反转 | 重估前文一半 | 全篇中点 |
| 终极反转 | 重估全部（含动机） | 高潮 |

- 每个反转前置 ≥2 处伏笔（`hook-library.md` 的"反转钩"要求）。
- 反转是**重估**而非**推翻**：最好的反转让已知信息获得新含义（《项链》式）。

## 六、悬疑专属钩子

| 场景 | 钩子式 | 示例 |
|---|---|---|
| 发现线索 | 11 信息钩 | 报告补充页只有一行：胃里有安眠药 |
| 证人矛盾 | 07 秘密钩 | 两人描述同一时段，地点却不同 |
| 真凶逼近 | 02 危机钩 | 门锁从外面转动了一下 |
| 身份揭穿 | 03 反转钩 | 监控里，凶手穿的是"我"的鞋 |

## 七、自检清单

- [ ] 诡计类型明确，且与题材匹配
- [ ] 线索链公开:隐藏 ≈ 6:4
- [ ] 公平性表：真相所需线索均对读者可见
- [ ] 误导 ≤2 条主线级，且可回溯
- [ ] 真凶在前 1/3 出场且动机可回溯
- [ ] 三层反转各有 ≥2 处前置伏笔
