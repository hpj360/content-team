# 玄幻/仙侠专属技法库

> `novel-writing` 按需加载参考。玄幻的成败不在设定多宏大，而在**境界体系是否可验证、
> 升级是否有代价、战力是否守恒**。本库给可执行的体系设计与节奏参数。

## 一、境界体系设计（四要素）

| 要素 | 说明 | 反例 |
|---|---|---|
| 层级 | 5–9 级为宜，级名要有辨识度（炼气/筑基/金丹…） | 层级过多（30 级）读者记不住 |
| 前置 | 升级所需条件（功法/资源/机缘/心境） | "突然就突破了" |
| 代价 | 每次突破付出什么（寿元/心魔/资源清空） | 无代价升级 → 无张力 |
| 失效 | 什么情况下境界会退/被压制 | 只升不降 → 危机失真 |

```
境界表（示例）
炼气 → 筑基（前置：筑基丹；代价：三月虚弱）
     → 金丹（前置：心境圆满；代价：渡劫折寿）
     → 元婴（前置：机缘；代价：斩一情）
```

## 二、升级节奏参数

- **小升级**：1–3 章一次（可感知的进步，维持爽感）。
- **大越阶**：15–30 章一次（卷末高潮），必须**前置铺垫 + 代价可见**。
- **瓶颈期**：每次大越阶前设 3–5 章瓶颈（冲突来源），避免"顺风顺水"。
- 自检：任一 10 章窗口内，读者能说出"主角强在哪、弱在哪"。

## 三、战力守恒

- 建立**同级对比锚**：同境界之间互有胜负，不能"主角同级无敌"。
- 越阶战斗必须有**明确理由**（功法克制/环境/奇宝/自损秘法），且**代价后置**。
- 反例：主角随手灭掉高一境对手 → 后续境界全部贬值。

## 四、资源经济（爽点的燃料）

- 天材地宝/灵石/功法构成**稀缺经济**：谁掌握资源，谁有话语权。
- 资源冲突 = 天然剧情引擎（抢夺/交易/宗门任务）。
- 自检：主角的每次大提升，是否对应一次资源获取事件？

## 五、宗门/势力体系

- 至少三层：**同门（内斗）/ 敌宗（外压）/ 上界（天花板）**。
- 每层给一个"规则的荒诞处"（如：宗门大比只看血脉）→ 主角的破局点。
- 与 `worldbuilding-guide.md` 的势力层配套：势力目标互相冲突。

## 六、玄幻专属钩子

| 场景 | 钩子式 | 示例 |
|---|---|---|
| 突破失败 | 02 危机钩 | 丹田传来一声脆响 |
| 秘境开启 | 04 期待钩 | 十万年一开的秘境，明日午时 |
| 身份曝光 | 05 身份钩 | 长老看清他掌心的印记，跪了下去 |
| 越阶挑战 | 06 冲突钩 | "你一个筑基，也配站上这个擂台？" |

## 七、自检清单

- [ ] 境界表含 层级/前置/代价/失效 四要素
- [ ] 大越阶前有 ≥3 章瓶颈铺垫
- [ ] 越阶战斗有明确理由且代价后置
- [ ] 资源经济存在且驱动 ≥1 条主线
- [ ] 势力三层齐备，每层有"荒诞规则"作破局点
- [ ] 战力守恒：同级互有胜负
