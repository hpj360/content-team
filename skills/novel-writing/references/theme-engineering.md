# 主题工程：控制性观念、命题三拍与象征系统

> `novel-writing` 按需加载参考。本文件解决"故事讲完了、但不知道它到底在讲什么"的诊断与设计问题：
> 先把模糊的"想表达点什么"压成一句可被反驳的价值主张，再用三拍把它跑成情节，最后用外化装置让读者
> 在场景里看见它。纯方法论，不含任何版权内容。

## 一、主题不是标签，是"价值主张"

三个层次常被混用，混用就会写出"贴标签"的故事：

| 层 | 回答什么 | 检验方式 |
|---|---|---|
| 题材 | 写什么（职场/悬疑/家庭） | 一句话能归类即可，不承担判断 |
| 母题 | 人类共同问题（复仇、亲情、阶层的代价） | 可以套在无数作品上，仍不指向本部 |
| 主题 | 本部作品对该母题的**具体判断** | 换一个判断，故事就不成立 |

**控制性观念公式**：一个价值判断 + 一个原因从句。

```
[价值判断：X 比 Y 更值得／更危险] ，因为 [原因从句：Z 的代价证明了它]
```

公式只给结构，具体填什么由作者自己定。填不出来，通常不是"还没想好"，而是故事里还没有对应的代价事件。

**判定（两条都要过）**：

1. 能用一句话说清"这部作品相信什么"，且主语是作品，不是某个角色的口号；
2. 这句话**可以被反方有理有据地反驳**——反方拿得出自己的代价证据。

不可反驳的句子是口号（"善良终将胜利"），不是主题；口号没有反命题，第二幕就无从落拍。

## 二、命题三拍（正-反-合）

三幕不是"起承转合"的同义词。在主题层面，它是一条**信念被打碎再重装**的路线：

- **拍一 命题**：主角相信 X，并据此行动。X 必须带来一次真实收益，否则反命题打不中任何东西。
- **拍二 反命题**：世界用代价证明非 X，或证明 X 有界限。对手、规则、亲密关系三处同时施压最有效。
- **拍三 综合**：主角带着已付出的代价重构 X′。X′ 不是 X 的加强版，而是"知道贵、仍然选"的版本。

| 幕 | 命题状态 | 主角对主题的认知 | 代价形态 | 常见病 |
|---|---|---|---|---|
| 拍一 | X 成立且好用 | 我信 X，还没为它付过账 | 预付（时间/关系/小损失） | 信念无收益，反命题打空 |
| 拍二 | X 被证伪或越界 | 我怀疑 X，但还没有替代品 | 实付（伤疤/背叛/不可逆） | 只加痛苦不加认知，拍成苦情戏 |
| 拍三 | X′ 成立但更贵 | 我知道代价，仍然选它 | 已付 + 愿付（主动再付一次） | 顿悟式免费升级 |

**三个常见病与处方**：

1. **无综合**：正-反结束就收尾，读者只收到"世界很残酷"——补一场"带着代价的再选择"。
2. **综合廉价**：最后一场顿悟解决全部矛盾——把 X′ 的成立条件前移到中段埋下，高潮只做兑现。
3. **主题与情节脱钩**：道理全靠台词讲——删掉所有主题台词，若情节仍能推出同一判断，才算合格。

## 三、主题的"外化装置"四类

主题必须长在可描写、可拍摄的东西上，否则只能靠旁白宣告。

### 1. 对手即主题

反派是主题反命题的**活体**，他的道理必须能自洽，才能逼出主角的 X′。

- 给对手一套完整因果：他的手段由他的代价观推出（"我出卖过谁，所以我信什么"）；
- 对手的道理必须**真的赢过一次**，否则反命题只是纸老虎；
- 读者要能理解他，但不必原谅他——理解来自因果，不来自苦衷展览。

### 2. 象征系统三层

| 层 | 设计要求 | 失效信号 |
|---|---|---|
| 道具 | 可被使用、可损坏、可易主；每次出场改变一次归属或状态 | 只在旁白里被解释，从未被角色拿在手里 |
| 空间 | 地形承担性格：门/窗/楼梯/边界决定谁能进、谁被挡 | 只当地名出现，换掉不影响任何一场戏 |
| 仪式 | 同一动作重复三次以上，每次参与者或结果变化一次 | 只在回忆或总结里复述，正文从未完整演过一次 |

三层共用一条判据：**象征物只在场景中出现且被使用过**，才算进入叙事；否则是设定集里的装饰。

### 3. 代价具象化

主题的代价必须长成一个**可看见的东西**：伤疤、账单、空椅子、缺角的牌位。

- 三问筛选：能否被镜头拍到？能否被第三方看见并追问？结局时是否仍留在画面里？
- 形容词不算代价（"他很痛苦"），物件才算（"他把那张缴费单折了四折"）。

### 4. 复沓句/母句

一句在关键时刻变奏重述的句子，三次即可：

| 次序 | 功能 | 变奏规则 |
|---|---|---|
| 第一次 | 初立：角色真诚地说出它 | 字面最完整，语境最轻 |
| 第二次 | 反讽：同一句被错的人、在错的场合说出 | 词不变，指向反转 |
| 第三次 | 兑现：主角用行动把它说完，或说完就付代价 | 可只留半句，留白给结局 |

母句的判定：删掉第一次，第三次是否失效？失效说明它只是金句，不是结构。

## 四、主题自检（12 条，逐条勾选）

- [ ] 1. 能否用一句话说清主题，且这句话可被反方有理有据地反驳
- [ ] 2. 主题句的主语是作品，而不是某个角色的口号
- [ ] 3. 已区分题材、母题与主题，主题指向本部作品的具体判断
- [ ] 4. 反命题是否配得上主角：对手的道理能自洽，且真的赢过一次
- [ ] 5. 综合是否带代价：X′ 的成立以前两幕已付的代价为条件
- [ ] 6. 每个主要角色是否对主题有自己的立场（支持/反对/折中，且互不重复）
- [ ] 7. 象征物是否在场景中出现且被使用过（道具被拿、空间被穿、仪式被演）
- [ ] 8. 代价是否有具象物承载，且该物件在结局仍在场
- [ ] 9. 母句是否完成三次变奏（初立—反讽—兑现）
- [ ] 10. 主题判断能否由事件推出，删掉所有主题台词后仍成立
- [ ] 11. 开篇三章提出的问题，是否就是结局回答的问题
- [ ] 12. 漂移对账表已逐章段填写，无未处理的"漂移"标记

## 五、主题漂移检测（写后）

写完后按四个检测点回读，每点只问一个问题：

| 检测点 | 位置 | 要问的问题 |
|---|---|---|
| 主题承诺 | 开篇 3 章 | 读者能否说出"这本书在赌什么"？ |
| 主题反命题 | 中段 | 世界给出的反证是否指向同一个价值判断？ |
| 主题兑现 | 高潮 | 主角的选择是否只能由 X′ 解释，换任何信念都做不出来？ |
| 主题余味 | 结局 | 最后一屏留下的物件或动作，是否仍在回答同一个问题？ |

**三类漂移信号**：

1. **主题换轨**：结局解决的问题 ≠ 开篇提出的问题（复仇开局，收在原生家庭和解）。
2. **主次倒挂**：配角台词比主角更承担主题，主角沦为事件执行者。
3. **贴标签**：主题只在章末总结句出现，删掉该句后整章不承载任何判断。

**主题一致性对账表**（每章段一行，写完即填）：

| 章段 | 主题话题 | 该段体现（事件/物件/台词） | 是否漂移 |
|---|---|---|---|
|  |  |  | 否 / 是（注明改法） |

## 六、与仓库资产的映射

| 主题工程要素 | 落点 |
|---|---|
| 控制性观念 | `creative/prompts.py` 的 v2 契约变体：写前注入一句话主题契约，与硬性配额同层生效 |
| 命题三拍 | `beat-sheets.md` 三幕拍位：命题/代价/综合各落一拍组，不另设第四幕 |
| 对手即主题 | `paradigm-director-kurosawa.md` 的对手与群像口径、`character-bible.md` 的反派自洽性（正当动机 + 主题承载） |
| 象征三层 | `worldbuilding-guide.md` 的"规则即代价"口径、`continuity-anchor-examples.md` 的锚点复用 |
| 漂移检测 | `creative/gates.py` 预留主题门口径（沿用现有问题码与维度分风格）、`reviewer.py` 的维度分（结构/合规/一致性/节奏/技法） |

落点纪律：主题判定优先做成离线可测的纯函数，不新增模型调用；语义或向量判据只作提示，不作硬门。

## 七、局限声明

- 强类型爽文可采用"弱主题"（情绪承诺替代价值判断），本文件对弱主题仅要求"不漂移"。
- 主题优先级因受众而异：文学向偏高，短剧向以情绪交付为先——不是所有作品都需要高浓度主题。
- 主题不得由旁白宣告；一切主题判断须由事件与代价承担。
