# 人物档案与关系网设计

> `novel-writing` 按需加载参考。人物不是标签集合，而是**目标 × 弱点 × 关系**驱动的行动体。
> 本表给出可填写档案与关系网方法，直接对应 `StoryState.characters` 四维状态。

## 一、人物档案模板（一人一档）

```yaml
姓名: 李默
定位: 主角 / 对手 / 导师 / 镜像
外在: 28岁，外卖骑手，蓝色骑手服袖口磨白，右眉尾一道短疤   # 可画特征，逐字复用
目标: 查清父亲失踪真相
弱点: 遇强则退，习惯性回避冲突
缺陷根源: 童年目击父亲"认输"
成长弧: 从回避 → 直面（三阶段：忍、试、立）
能力: 初期无，中期借势，后期掌控
关系: 老陈（恩）、主管（仇）、妹妹（软肋）
口头禅: "先把这单送完。"
红线: 不伤及无辜（不可违背）
```

## 二、四维状态（每卷更新）

| 维度 | 本卷进入 | 本卷离开 |
|---|---|---|
| 能力 | 无 | 借势可用 |
| 心理 | 回避 | 决意面对 |
| 关系 | 与老陈疏远 | 与老陈结盟 |
| 目标 | 找线索 | 锁定真凶 |

> 跨卷对比进入/离开状态，**防止能力突进与性格突变**（人设漂移）。

## 三、关系网设计（三条线）

1. **主线关系**：主角 ↔ 核心对手（目标对立、能力匹配）。
2. **情感线**：承载主题的 B 故事（师徒/恋人/亲情），给主角"为什么坚持"。
3. **镜像线**：与主角同起点、不同选择的人物 → 主角"另一种结局"（对应
   `deconstruction-chapter-form-wukong.md` 的"对手即主题"）。

```
         [镜像：同起点，选择了复仇 → 毁灭]
                    │
[情感线：妹妹] ── [主角] ── [核心对手：为父报仇的真凶]
                    │
              [导师：老陈，持有前史线索]
```

## 四、对手塑造三要素

- **正当动机**：对手的目标在其信息集下合理（不是"天生坏"）。
- **能力匹配**：能给主角真实压力（对手要强）。
- **主题承载**：对手是主题的另一种答案。

## 五、自检

- [ ] 每个主要角色有：目标 / 弱点 / 缺陷根源 / 成长弧 / 红线
- [ ] 外在描述含 ≥1 个"别人画不走的识别符"
- [ ] 四维状态逐卷记录，无跨卷矛盾
- [ ] 关系网三线齐备（主线/情感/镜像）
- [ ] 对手有正当动机与主题承载

## 六、与本项目集成

- 档案落 `StoryState.characters`（name/ability/psychology/relations/goals + 红线）；
- `gate_story_state` 校验四维完整性（T002–T004）；
- 识别符同步进 `storyboarding/references/continuity-anchor-examples.md` 的锚点包，供分镜逐字复用。
