# 人物档案与关系网设计

> `novel-writing` 按需加载参考。人物不是标签集合，而是**目标 × 弱点 × 关系**驱动的行动体。
> 本表给出可填写档案与关系网方法，直接对应 `StoryState.characters` 四维状态。

## 一、人物档案模板（一人一档）

```yaml
姓名: 李默
定位: 主角 / 对手 / 导师 / 镜像
外在: 28岁，外卖骑手，蓝色骑手服袖口磨白，右眉尾一道短疤   # 可画特征，逐字复用
目标: 查清父亲失踪真相
弱点: 遇强则退，习惯性回避冲突
缺陷根源: 童年目击父亲"认输"
成长弧: 从回避 → 直面（三阶段：忍、试、立）
能力: 初期无，中期借势，后期掌控
关系: 老陈（恩）、主管（仇）、妹妹（软肋）
口头禅: "先把这单送完。"
红线: 不伤及无辜（不可违背）
```

## 二、四维状态（每卷更新）

| 维度 | 本卷进入 | 本卷离开 |
|---|---|---|
| 能力 | 无 | 借势可用 |
| 心理 | 回避 | 决意面对 |
| 关系 | 与老陈疏远 | 与老陈结盟 |
| 目标 | 找线索 | 锁定真凶 |

> 跨卷对比进入/离开状态，**防止能力突进与性格突变**（人设漂移）。

## 三、关系网设计（三条线）

1. **主线关系**：主角 ↔ 核心对手（目标对立、能力匹配）。
2. **情感线**：承载主题的 B 故事（师徒/恋人/亲情），给主角"为什么坚持"。
3. **镜像线**：与主角同起点、不同选择的人物 → 主角"另一种结局"（对应
   `deconstruction-chapter-form-wukong.md` 的"对手即主题"）。

```
         [镜像：同起点，选择了复仇 → 毁灭]
                    │
[情感线：妹妹] ── [主角] ── [核心对手：为父报仇的真凶]
                    │
              [导师：老陈，持有前史线索]
```

## 四、对手塑造三要素

- **正当动机**：对手的目标在其信息集下合理（不是"天生坏"）。
- **能力匹配**：能给主角真实压力（对手要强）。
- **主题承载**：对手是主题的另一种答案。

### 4.1 反派自辩戏（操作步骤）

- **先说一句正确的话**：反派首次登场，先给一句读者会点头的话（"会饿的东西不可控，不可控就是灾难"），读者先认同、再害怕；
- **让他的道理赢一次**：在他占理的场合，主角当场无法反驳（主角输的是道理，不是气势）；
- **补因果源头**：他的手段由他的代价观推出——他失去过什么，所以信这套；
- **给一次"不损己仍作恶"的选择**：证明他不是走投无路，是选择了这条路。

## 五、记忆点武器化与称呼进度条（区分度增强）

### 5.1 记忆点武器化
每个角色的物理记忆点（物件/习惯/身体记号）必须至少一次**进入剧情机制**，不能只当装饰：
- 例：断指 → 数东西永远多数一遍 → 某次窄缝作业反成败笔或优势；
- 例：义指 → 关键时刻当零件用 → 角色的"身体"成为解决问题的工具。

### 5.2 称呼进度条
用"称呼变化"承载关系推进，读者可无意识读到进度：
- 称呼三阶：**官职/代号 → 名字 → 昵称**（亲近），或反向（决裂）；
- 每个改口必须有事件触发（他做了什么，她才改口）；
- 全员称呼表写进人物档案，改口章号登记进状态卡。

### 5.3 机器观/职业观区分法
同职业群像会"糊"，用**每个人对同一事物的不同态度**做区分轴：
- 例（维修题材）：机器是病人（要治）／档案（要判）／商品（要换）／玩具（要拆）／战友（要用）；
- 检验：把一句台词换给另一个人说，若仍成立 → 区分度不够，重写。

## 五、自检

- [ ] 每个主要角色有：目标 / 弱点 / 缺陷根源 / 成长弧 / 红线
- [ ] 外在描述含 ≥1 个"别人画不走的识别符"
- [ ] 四维状态逐卷记录，无跨卷矛盾
- [ ] 关系网三线齐备（主线/情感/镜像）
- [ ] 对手有正当动机与主题承载

- `gate_story_state` 校验四维完整性（T002–T004）；
