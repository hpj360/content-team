# 科幻专属技法库

> `novel-writing` 按需加载参考。科幻的门槛是**设定自洽**：一个漏洞就能让全篇可信度崩塌。
> 本库给"三律自洽"检查、硬软边界与科技树设计。

## 一、设定自洽三律

| 律 | 检查什么 | 反例 |
|---|---|---|
| 物理律 | 技术是否违背已知物理（或**明确声明**为软设定） | 无声太空里爆炸声震耳 |
| 生物律 | 生命/意识/进化是否自洽 | 外星生物随意变形无能量来源 |
| 社会律 | 技术如何改变社会结构（经济/权力/伦理） | 有超光速通讯但社会如古代 |

**原则**：允许"一个奇点假设"（如曲速），但其余必须自洽——**一奇点，全自洽**。

## 二、硬科幻 vs 软科幻的边界

- **硬**：技术是主角（推演后果），需要**可验证的推论链**。
- **软**：技术是背景（服务人物），但**不得自相矛盾**。
- 写作前明确：本作允许几个"不予解释"的假设？（建议 ≤2）

## 三、科技树设计（三阶）

```
基础层：能源/材料/信息（设定世界的物理底座）
应用层：由基础层推导的装备/武器/交通（必须可追溯）
社会层：应用层带来的制度/伦理变化（冲突来源）
```

- 每条应用必须能回溯到基础层（"这个东西为什么能造出来"）。
- **反例**：凭空出现的万能装置 → 悬念与冲突同时消失。

## 四、伦理冲突（科幻的戏剧核心）

- 每个核心技术给一个**伦理困境**：克隆→身份、AI→意识、延长寿命→阶层固化。
- 困境必须**具体到人物选择**，不能停留在讨论。
- 与 `worldbuilding-guide.md` 的规则层配套：规则即代价。

## 五、世界观信息投放（防"设定倾倒"）

- 设定**分片投放**：对话/事故/档案/新闻 逐章释放（对应档案式世界观）。
- 前 3 章只给"读者此刻必需"的 3 条设定。
- 反例：开篇 2000 字讲完世界观 → 读者流失。

## 六、科幻专属钩子

| 场景 | 钩子式 | 示例 |
|---|---|---|
| 异常数据 | 07 秘密钩 | 探测器传回的坐标，是三年前的 |
| 技术失控 | 02 危机钩 | 环城维生系统倒计时 72 小时 |
| 身份揭示 | 05 身份钩 | "你不是人类，你是我写的程序" |
| 规则改写 | 03 反转钩 | 时间在这里是可以被折叠的 |

## 七、自检清单

- [ ] 声明了"奇点假设"数量（≤2）且其余自洽
- [ ] 每条应用可回溯到基础层
- [ ] 每个核心技术配一个伦理困境且落到人物选择
- [ ] 设定分片投放，前 3 章仅 3 条必需设定
- [ ] 物理/生物/社会三律无自相矛盾
