# 场景细节工程

> `novel-writing` 按需加载参考。细节不是形容词堆叠，而是**感官可锚定的具体名词+动词**——服务于压力、转折、情感的物理层显影系统。

## 一、定义：细节的运作机制

**细节 = 感官可锚定的具体名词 + 动词**，而非形容词三连。

- **正例**：烟灰缸里三根烟头，最上面那根还在冒丝烟。（名词 + 状态动词）
- **反例**：房间很乱很脏很压抑。（形容词堆叠，无锚点）

**服务对象三限**：
1. **压力显影**：细节在冲突点前 1 拍入场，给压力找物理载体。
2. **转折标记**：情绪翻转瞬间，细节变化即转折信号。
3. **情感投射**：人物状态通过环境/物件折射（不直述"她很难过"）。

**视角过滤铁律**：只写 POV 角色**当下可感知**的细节——看不到的背后动作、闻不到的另一房间气味、不在场的对话，一律不写。

> 与 `narratology-toolbox.md` 的交叉引用：视角过滤原则源自该文件第一节"视角的信息权限分配"，本篇只负责**物理层细节过滤**，不展开叙述学理论。

## 二、五维细节矩阵

| 维度 | 子维度 | 锚定示例 A | 锚定示例 B |
|---|---|---|---|

| | 光线 | 百叶窗把光切成五道斜条 | 手机屏幕把脸照成惨白 |
| | 质地 | 桌面木刺扎进指腹 | 杯壁凝结的水珠滑到虎口 |

| | 身体语言 | 肩膀朝门的方向偏了半寸 | 手指在桌下攥成拳又松开 |

| | 通感 | 空气黏得像要凝固（触觉→视觉） | 寂静重得压在肩上（听觉→触觉） |
| **影响** | 对人物状态 | 她攥杯子的手指关节发白 | 他说话开始吞字 |

| | 对后续情节 | 那把刀还在桌上（伏笔） | 她记住了那个门牌号（后续动机） |

## 三、密度纪律

**克制原则**：每场景 **3-5 个核心细节**，不是越多越好。细节服务于压力，不是为描写而描写。

**引入时机三拍**：
1. **冲突点前 1 拍**：在压力爆发前，先给细节铺垫（如：对峙前写光线变化）。
2. **转折瞬间**：情绪翻转时，用细节变化标记（如：她转身时杯子落地）。
3. **余波扫描**：高潮后用一个静态细节收尾（如：烟灰缸满了，窗还开着）。

**过密失效信号**：
- 一段内细节超过 5 个 → 读者注意力被稀释
- 细节之间无因果关联 → 变成流水账
- 细节与情绪方向无关 → 读者困惑"为什么写这个"

## 四、视角过滤铁律

**只写 POV 角色当下可感知的细节**：

- ✓ 她看到他攥紧了拳头（她的视线可及）
- ✗ 他心里一阵刺痛（限知视角下，她看不到他的内心）
- ✓ 隔壁传来摔门声（她能听到）
- ✗ 隔壁房间里他把杯子砸在地上（她看不到另一房间的具体动作）

**过滤检查表**：
- [ ] 该细节在 POV 角色的视野/听觉/嗅觉范围内？
- [ ] 没有写出 POV 角色背后的动作？
- [ ] 没有透露 POV 角色不在场的信息？
- [ ] 内心活动只写 POV 角色自己的？

> 与 `narratology-toolbox.md` 的分工：该文件负责视角的理论与类型，本篇只负责**视角对细节选择的过滤规则**。

## 五、前后对照微演示

### 示例 A：对峙场景

**原版（单薄）**：
他走进办公室，看到她坐在椅子上。两人对视了一会儿，气氛很紧张。他说："我们得谈谈。"她没有回答，只是看着他。整个房间安静得可怕，他能感觉到她的愤怒。

**补充后（立体）**：
他推开门，百叶窗把午后的光切成五道斜条，正好落在她脸上。她坐在椅子上，手指在扶手边缘一下一下地敲，桌上烟灰缸里已经有三根烟头。

"我们得谈谈。"

她没接话，视线从他脸上移到窗外，肩膀朝门的方向偏了半寸。空调嗡嗡作响，压缩机突然停了，寂静像凝固的水泥。

**标注**：用了 **环境（光线、声音）+ 动作（微动作、身体语言）+ 物件（状态变化）** 三维。

---

### 示例 B：情感转折

**原版（直述）**：
她接到电话后很难过。她坐在床边哭了很久，感到非常绝望和痛苦。外面的世界似乎与她无关了。

**补充后（投射）**：
她按掉电话，手机滑到腿上。窗外小区喇叭还在循环那首《甜蜜蜜》，小贩吆喝声从三楼飘上来，尖锐、欢快，像在另一个世界。

她低头盯着地板的瓷砖缝，那条裂纹从床脚一直延伸到门口——上个月她搬进来时就想修，后来忘了。现在它像一道黑色的河，把房间劈成两半。

喉咙发紧,呼吸开始黏滞。她咬了下嘴唇内侧，铁锈味在舌尖化开。

**标注**：用了 **环境（声音、空间投射）+ 感官（听觉、视觉、味觉）+ 影响（生理反应、情绪外化）** 三维。

## 六、反模式

| 反模式 | 失效信号 | 示例 |
|---|---|---|
| **形容词三连** | 连续三个以上形容词，无具体名词锚点 | "房间漂亮精致华丽" → 改为"墙上挂着镀金画框，地毯踩下去陷半寸" |
| **环境与情绪错配** | 悲剧配鸟语花香，但无反差意图 | 葬礼当天阳光明媚鸟鸣啾啾（若非刻意用反差制造荒诞感，则失效） |
| **细节无后果** | 描写的枪下文不开火 | 第三章写"桌上放着一把刀"，后文再不提 → 删除或让它产生后果 |
| **全知视角泄露** | 限知叙述者写出不在场信息 | POV 在 A 房间，却写"此时 B 房间里他拿起了电话"（她看不到） |

> 与 `emotion-conflict-externalization.md` 的分工边界：该文件负责**情感四通道（生理/行为/认知/环境）+ 冲突外化**，本篇只做**场景物理层细节**，情感描写部分只留接口（如"喉咙发紧"属于生理通道，细节工程只负责把它写具体，不负责情感通道的系统设计）。

## 八、自检清单

每场景完成后过一遍：

- [ ] 五维至少覆盖 3 维？（环境/动作/物件/感官/影响）
- [ ] 密度 ≤ 5 个核心细节？（不过密）
- [ ] 视角过滤无泄露？（没写 POV 看不到的）
- [ ] 细节有后续呼应或影响？（不是废笔）
- [ ] 感官配比合理？（视觉不超 50%，至少用 2 种感官）
- [ ] 细节服务于压力/转折/情感？（不是为描写而描写）
- [ ] 引入时机在冲突点前 1 拍/转折瞬间/余波？
- [ ] 名词 + 动词为主，形容词 ≤ 2 个/段？

## 九、项目实训公式（R47 蒸馏，与五维矩阵互补）

> 来源：小说项目实战稿《吞兽维修师》的四维细节系统（44 号）。五维矩阵回答"查哪些维度"，
> 本节回答"落笔怎么写"。两者叠加使用。

### 9.1 环境＝参与动作的对手/工具/限制（不是布景）

- 公式：**环境参数（温度/湿度/光/声/气味/尺寸）× 人物状态 × 一个变数（此刻在变的东西）**
- 反例："雨下得很大，天很冷。"（形容词，环境没参与）
- 正例："雨停了，棚顶还在滴水。滴在他拆下来的装甲板上，一滴一个印。"
- 判据：环境是否**挡路/告警/耗损/提供线索**？只当背景板的环境描写一律删。

### 9.2 动作三拍与手感

- **三拍公式：意图 → 受阻 → 变招**（每场至少一次）。
- 大动作拆**起势—受力—余震**；小动作写**手感**（重量/温度/阻力）。
- 例："第一颗螺栓锈死了（受阻）。他换长杆扳手，手臂绷直，扳手'咯'地一滑，虎口蹭掉一层皮（受力+余震）。他没停，换个角度从下往上顶（变招）。"

### 9.3 心理四外化（补充"注意偏移"与"闪回"两个增量）

| 外化 | 写法 | 例 |
|---|---|---|
| 生理 | 心跳/口干/手指发凉 | "他数了三遍螺丝，第三遍才数对。" |
| 注意偏移 | 忽然注意到平时不看的细节 | "他这才看见，墙上的挂钟停在四点。" |
| 行动替代 | 想说的话换成另一个动作 | "他想说'别去'。他把雨衣塞进对方怀里。" |
| 闪回 | **≤25 字，一句即止** | "父亲当年也是这么拧的。" |

### 9.4 影响三账

事件必须改变**至少一张账**，各写一句：**人的账**（关系/信任/亏欠）· **物的账**（零件/损失）· **局的账**（局势/规则/权力）。
例："老周把报价单上的'维修费'划掉，改成'欠一次'（人的账）。"

### 9.5 事件判据与配比

- 事件判据：删掉它后文是否仍成立？成立=交代（删）；不成立=事件。必写三问：**谁的态度变了？谁的账变了？下一步选项变了吗？**
- 配比（每 800–1200 字场景）：动作 35% / 影响 30% / 心理 20% / 环境 15%；
  每 800 字至少一次"反常/代价/反转/钩子"。

### 9.6 四个可套用句式

1. 环境参与式：`X 的时候，Y 正好（环境变数），他（动作应对）。`
2. 动作三拍式：`想（意图）→ 卡住（受阻）→ 换个法子（变招）。`
3. 心理外化式：`他没说 Z。他做了（动作）。`
4. 影响三账式：`事件之后：谁的账变了（一句）；谁的称呼变了（一句）；下一步选项变了（半句）。`

## 十、具体化阶梯：细节如何更具体

> 本节回答一个更前置的问题：**怎样把一个判断改写成细节**。第九节给句式，本节给**颗粒度的升降规则**——细节不是"有没有"，而是"到了第几档"。

### 10.1 问题：抽象判断不是细节

- 「环境很差」是判断，不是画面；「墙角的霉斑长到半人高」才是细节。
- 「一辆车」是类别，读者只能自行补全；「一辆掉漆的白色面包车」才落到具体。
- 细节的敌人有三类：**类别词**（车/房子/东西）、**集合词**（一些/各种/很多）、**副词化情绪**（非常难过/极其压抑/特别紧张）。
- 判据一句话：**这句话能不能被拍成一个镜头？** 拍不出，就还在抽象层。

### 10.2 具体化四档阶梯

同一场景（搬家那天的楼下），逐档升格：

| 档 | 写法 | 示例（原创，同一场景逐档升格） | 用力点 |
|---|---|---|---|
| 档1 | 类别词/抽象判断 | 「一辆车」「环境很差」 | 只给类别，零信息 |
| 档2 | 特征限定 | 「一辆旧车」「屋里很乱」 | 加了形容词，仍不可拍 |
| 档3 | **专名/标识/数字** | 「一辆掉漆的白色面包车，车门上用红漆写着"顺达搬家"」「桌上三只没洗的碗，其中一只磕了口」 | 落到唯一性，可被指认 |
| 档4 | **感官复合**（动/声/触/味） | 「他拉开门，玻璃哐一声，风灌进来，混着纸箱和机油的味道」 | 让读者身体在场 |

- **换算规则：1 个档3/4 细节 > 3 个档1/2 细节。** 档2 堆再多，读者仍不知道那是什么。
- 每场档3/4 细节 **3–5 个封顶**（与第三节密度纪律、P9 口径一致）；超出即炫技。

### 10.3 名词具体化五问

1. **什么材质**：不是「一把刀」，是「刀柄缠着褪色的电工胶布」。
2. **什么状态**：不是「一个杯子」，是「杯口磕掉一块瓷」。
3. **什么标记**：不是「一个包」，是「包带上用马克笔写着"203"」。
4. **谁用过**：不是「一件外套」，是「外套口袋里有张别人家的门禁卡」。
5. **现在怎样**：不是「一扇门」，是「门从里面反锁，钥匙还插在外面」。

### 10.4 动词具体化：把「做」拆成动作链

「做/整/弄/处理/搞」是**动词的类别词**，信息量为零；替换法是写出**动作链**（抓→拧→撬→换角度），读者才看得见手。

- 抽象：「他把门弄开了。」
- 具体：「他抓住门把手往上提，肩膀顶住门板，锁舌"嗒"地缩回去。」
- 抽象：「他把那份材料处理了一下。」
- 具体：「他抽出附件，用红笔划掉第三行，折两折塞进内袋。」

### 10.5 数量与时间具体化

约数是叙述者的懒；**精确数 + 一个理由**，才是人物的处境。

- 「大约半小时」→「两小时三十八分」。理由：「他每十分钟看一次表，三点前必须把钥匙交回去。」
- 「排了很久」→「前面还有 47 个人」。理由：「取号单 A047，电子屏卡在 A019 已经二十分钟。」

| 抽象版 | 具体版 |

| 都市｜地铁太挤了 | 背包带被夹在门缝里 |
| 都市｜房价高得离谱 | 中介把「首付 68 万」圈了两遍 |
| 悬疑｜现场很乱 | 抽屉全拉开，只有病历本不见了 |
| 悬疑｜他死得蹊跷 | 拖鞋摆得整整齐齐，朝床 |

| 职场｜会议很无聊 | 投影仪风扇响，幻灯片停第七页 |
| 灵异｜屋子很阴森 | 墙纸下透出一块更深的方印 |
| 灵异｜她很害怕 | 她数到第三遍才敢回头 |
| 灵异｜楼道很黑 | 声控灯拍到第三下才亮 |
| 灵异｜那东西很冷 | 手电照过去，玻璃结了一层霜 |

### 10.7 具体化 ≠ 堆砌

1. **档4 连发变成炫技**：「玻璃哐一声，风灌进来，纸箱味、机油味、汗味一起涌上，铝梯在墙上刮出白痕，楼下电钻突突突……」一句五个感官，读者只记住"吵"。
2. **每段一个感官复合**：段段声香味触，密度拉满等于没有重点，读者第三段开始跳行。
3. **具体化脱离视角**：POV 在屋里，却写「楼下车门关上时，司机骂了句脏话」——她听不见，细节再准也是错的。

**少即是多**：同一场只留 **1 个最锋利的档4**，其余压回档2。

- 原稿：「门一开，冷风灌进来，铁皮味、机油味、纸箱味混在一起，玻璃哐一声，楼道灯闪了两下，楼下有人按喇叭。」
- 改后：「门一开，玻璃哐一声。风是冷的，带着纸箱味。楼道灯闪了两下。」——只留"玻璃哐一声"一个档4。

### 10.8 自检 5 条

- [ ] 每个核心细节是否到**档3**？（专名/标识/数字，而不只是形容词）
- [ ] 名词是否回答「五问」至少**两问**？（材质/状态/标记/谁用过/现在怎样）
- [ ] 动词是否**可拍摄**？（没有「做/整/弄/处理」这类类别动词）
- [ ] 数量是否有**理由**？（精确数后面跟得上一句"为什么记得住"）
- [ ] 档3/4 是否**不超 5 个**？（超了压回档2 或删）

## 十一、事件与影响：两个薄弱维的补全

> 五维矩阵里的「影响」与 9.5 的事件判据，是实战稿里最易写空的两处：事件写成交代，影响写成形容词。本节补两块——**事件的可写化**（怎样让一件事成为事件）与**影响的外显四通道**（影响怎样被读者看见），末尾给一张可直接填的对账表。

### 11.1 事件的可写化

**事件三要素**：**谁做了什么 + 对谁 + 导致什么后果**。缺「后果」即非事件——回到删除测试：删掉它后文仍成立，它就是交代。

**因果链四问**（落笔前先答完）：

1. **为什么此刻发生**？——时机被什么逼出来（限期/耗尽/撞见）。
2. **谁推动的**？——至少一个具名推手，不写「命运」。
3. **挡住它的力量是什么**？——无阻力的事件只是流水账。
4. **发生后谁的选项变了**？——答不出，事件就没有落地。

**时间颗粒度法则**：按重要性选刻度。过场用「日/周」一笔带过，关键拍用「分/秒」逐格推进。同一事件两种刻度对照：

| 对照 | 粗刻度（过场） | 细刻度（关键拍） |
|---|---|---|
| 一：跑医院 | 那一周他跑了三家医院，结论都一样。 | 十点零七分，护士叫到 37 号，他起身时单子被汗浸软一角。 |
| 二：盘店 | 那天他签完字，第二天就搬走了。 | 笔尖悬在「转让方」上停了三秒，他换了个握法才落笔。 |

**事件类型矩阵**：

| 类型 | 判定 | 原创微例（≤25 字） |
|---|---|---|
| 目标事件 | 追求或失去某物 | 他把最后一张存单推过去，换回一张欠条。 |
| 关系事件 | 结盟或决裂 | 她当着全桌叫他的全名，不再叫哥。 |
| 状态事件 | 受伤或揭穿 | 他摘了帽子，那道疤露在灯下。 |
| 信息事件 | 得知或误信 | 护士念到「三床」，那是他母亲的床号。 |

**可拍摄检验**：事件必须能给出**一张画面**；给不出画面 = 仍是交代。把「他们吵翻了」改成「她把钥匙放在桌上，推到两人中间」——后者才有镜头可拍。

### 11.2 影响的外显四通道

先厘清与 9.4「影响三账」的关系：**三账 = 记账口径（人/物/局：谁的账变了）；四通道 = 呈现口径（读者看得见什么）**。三账回答「变了没有」，四通道回答「怎么让读者看见变了」，是同一件事的记账面与呈现面。

| 通道 | 子类 | 写法 | 原创微例（≤30 字） |
|---|---|---|---|
| **人的反应** | 态度 | 从「愿意」变「敷衍/戒备」 | 他不再替她留门，钥匙串上少了一把。 |
| | 称呼 | 换称谓/改口径 | 她从「老板」改口叫「陈哥」。 |
| | 身体距离 | 靠近或退开的物理距离 | 她把椅子往回挪了半尺，膝盖不再碰他。 |
| **物的状态** | 损坏 | 破/坏/缺件 | 那只杯子磕了口，他还在用。 |
| | 移动 | 换了位置 | 她的相框被挪到了书架最下层。 |
| | 旧了 | 褪色/磨损/过期 | 门上的封条褪成浅黄，字还认得出。 |
| | 多出来 | 凭空多一件东西 | 桌上多了一双筷子，没人动过。 |
| **空间的变化** | 痕迹 | 留下的印子（钉眼/划痕/水渍） | 墙上的钉子眼还在，画的位置空着。 |
| | 空缺 | 少了什么，空间显形 | 藤椅搬走后，客厅长了半米。 |
| | 气味残留 | 人走了，味还在 | 屋里还是膏药味，人走了三天。 |
| **后续选项** | 能做什么 | 新获得的可行动项 | 现在他可以直接推开那扇门。 |
| | 不能再做什么 | 永久失去的可行动项 | 这家店，他再也进不去了。 |

- **规则**：**每个重大事件至少写 2 个通道**；四通道全空 = 事件无影响，判定不合格。

### 11.3 事件—影响对账表（可直接填）

| 事件 | 谁的账变（三账） | 人 / 物 / 空间 / 选项（各一句） | 空通道数 | 判定 |
|---|---|---|---|---|
| （谁做了什么 + 对谁 + 后果） | 人：…／物：…／局：… | 四通道逐条填写 | 0–4 | 合格／不合格 |
| **示例**：老周把最后一套工具卖给徒弟，收了钱，没留收据。 | 人：徒弟欠他一份人情；物：铺子里只剩空挂钩；局：这条街再没人找他修东西。 | 人：徒弟改口叫「师父」，叫完自己愣了下；物：柜台上多了一张没写字的收据；空间：墙上留下十二个挂钩的锈印；选项：他再没有借口在铺子里待一整天。 | 0 | 合格 |

### 11.4 自检 5 条

- [ ] 事件有**后果**？（缺后果，回到删除测试）
- [ ] 因果链四问**答得出**？（此刻/推手/阻力/选项变化）
- [ ] 时间刻度与重要性**匹配**？（过场粗，关键拍细）
- [ ] 重大事件四通道 **≥2**？（全空即无影响）
- [ ] 对账表**无空行**？（每行填满，或明确判为不合格）

## 十二、局限

本方法论**不适用**以下场景类型：

1. **纯对话场景**：两人在空白空间对话，刻意不给环境细节（实验性写法）。
2. **极简风格**：海明威式冰山理论，刻意压缩细节到极致。
3. **意识流为主**：内心独白占 80% 以上，物理细节让位于心理流动（如伍尔夫《达洛维夫人》式）。

> 与 `scene-engineering.md` 的配合：当场景通过"删除测试"（该文件核心方法）确认必须保留后，再用本篇方法填充细节；若场景本身可删，细节再好也是浪费。
