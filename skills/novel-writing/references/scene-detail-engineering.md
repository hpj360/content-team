# 场景细节工程

> `novel-writing` 按需加载参考。细节不是形容词堆叠，而是**感官可锚定的具体名词+动词**——服务于压力、转折、情感的物理层显影系统。

## 一、定义：细节的运作机制

**细节 = 感官可锚定的具体名词 + 动词**，而非形容词三连。

- **正例**：烟灰缸里三根烟头，最上面那根还在冒丝烟。（名词 + 状态动词）
- **反例**：房间很乱很脏很压抑。（形容词堆叠，无锚点）

**服务对象三限**：
1. **压力显影**：细节在冲突点前 1 拍入场，给压力找物理载体。
2. **转折标记**：情绪翻转瞬间，细节变化即转折信号。
3. **情感投射**：人物状态通过环境/物件折射（不直述"她很难过"）。

**视角过滤铁律**：只写 POV 角色**当下可感知**的细节——看不到的背后动作、闻不到的另一房间气味、不在场的对话，一律不写。

> 与 `narratology-toolbox.md` 的交叉引用：视角过滤原则源自该文件第一节"视角的信息权限分配"，本篇只负责**物理层细节过滤**，不展开叙述学理论。

## 二、五维细节矩阵

| 维度 | 子维度 | 锚定示例 A | 锚定示例 B |
|---|---|---|---|
| **环境** | 空间 | 天花板裂缝从门框延伸到窗角 | 桌腿下垫着三折的杂志 |
| | 天气 | 雨水顺窗沿斜打进来半尺 | 风把纸页吹翻三页又压回去 |
| | 声音 | 楼上拖椅子，吱嘎两声停了 | 冰箱压缩机突然启动 |
| | 气味 | 走廊飘来热油呛鼻的焦味 | 衣领残留的烟草混洗衣液味 |
| | 光线 | 百叶窗把光切成五道斜条 | 手机屏幕把脸照成惨白 |
| | 质地 | 桌面木刺扎进指腹 | 杯壁凝结的水珠滑到虎口 |
| **动作** | 微动作 | 拇指在手机壳边缘反复抠 | 咬了下嘴唇内侧 |
| | 身体语言 | 肩膀朝门的方向偏了半寸 | 手指在桌下攥成拳又松开 |
| | 器械交互 | 钥匙插进锁孔转了一半卡住 | 打火机按三次才点着 |
| | 动作链因果 | 杯子倾斜→茶水漫到文件上→她猛地抽纸 | 他伸手→她后退半步→椅背撞到墙 |
| **物件** | 识别符 | 杯沿那道缺口对着她 | 发票在钱包夹层叠成小方块 |
| | 状态变化 | 烟头从一根变成三根 | 门把手从竖直歪到四十五度 |
| | 所有权 | 他的外套还搭在她椅背上 | 桌上两只手机，她的那只亮了 |
| | 象征投射 | 窗外霓虹灯闪三下灭掉 | 时钟秒针卡在 47 秒位置 |
| **感官** | 五感配比 | 视觉 40% / 听觉 25% / 触觉 20% / 嗅味觉 15% | - |
| | 通感 | 空气黏得像要凝固（触觉→视觉） | 寂静重得压在肩上（听觉→触觉） |
| **影响** | 对人物状态 | 她攥杯子的手指关节发白 | 他说话开始吞字 |
| | 对关系 | 两人之间的距离从一米拉到两米 | 她不再看他，视线钉在墙上 |
| | 对空间 | 窗帘被拉上，光线只剩门缝一条 | 门从半掩被推到全开 |
| | 对后续情节 | 那把刀还在桌上（伏笔） | 她记住了那个门牌号（后续动机） |

## 三、密度纪律

**克制原则**：每场景 **3-5 个核心细节**，不是越多越好。细节服务于压力，不是为描写而描写。

**引入时机三拍**：
1. **冲突点前 1 拍**：在压力爆发前，先给细节铺垫（如：对峙前写光线变化）。
2. **转折瞬间**：情绪翻转时，用细节变化标记（如：她转身时杯子落地）。
3. **余波扫描**：高潮后用一个静态细节收尾（如：烟灰缸满了，窗还开着）。

**过密失效信号**：
- 一段内细节超过 5 个 → 读者注意力被稀释
- 细节之间无因果关联 → 变成流水账
- 细节与情绪方向无关 → 读者困惑"为什么写这个"

## 四、视角过滤铁律

**只写 POV 角色当下可感知的细节**：

- ✓ 她看到他攥紧了拳头（她的视线可及）
- ✗ 他心里一阵刺痛（限知视角下，她看不到他的内心）
- ✓ 隔壁传来摔门声（她能听到）
- ✗ 隔壁房间里他把杯子砸在地上（她看不到另一房间的具体动作）

**过滤检查表**：
- [ ] 该细节在 POV 角色的视野/听觉/嗅觉范围内？
- [ ] 没有写出 POV 角色背后的动作？
- [ ] 没有透露 POV 角色不在场的信息？
- [ ] 内心活动只写 POV 角色自己的？

> 与 `narratology-toolbox.md` 的分工：该文件负责视角的理论与类型，本篇只负责**视角对细节选择的过滤规则**。

## 五、前后对照微演示

### 示例 A：对峙场景

**原版（单薄）**：
他走进办公室，看到她坐在椅子上。两人对视了一会儿，气氛很紧张。他说："我们得谈谈。"她没有回答，只是看着他。整个房间安静得可怕，他能感觉到她的愤怒。

**补充后（立体）**：
他推开门，百叶窗把午后的光切成五道斜条，正好落在她脸上。她坐在椅子上，手指在扶手边缘一下一下地敲，桌上烟灰缸里已经有三根烟头。

"我们得谈谈。"

她没接话，视线从他脸上移到窗外，肩膀朝门的方向偏了半寸。空调嗡嗡作响，压缩机突然停了，寂静像凝固的水泥。

**标注**：用了 **环境（光线、声音）+ 动作（微动作、身体语言）+ 物件（状态变化）** 三维。

---

### 示例 B：情感转折

**原版（直述）**：
她接到电话后很难过。她坐在床边哭了很久，感到非常绝望和痛苦。外面的世界似乎与她无关了。

**补充后（投射）**：
她按掉电话，手机滑到腿上。窗外小区喇叭还在循环那首《甜蜜蜜》，小贩吆喝声从三楼飘上来，尖锐、欢快，像在另一个世界。

她低头盯着地板的瓷砖缝，那条裂纹从床脚一直延伸到门口——上个月她搬进来时就想修，后来忘了。现在它像一道黑色的河，把房间劈成两半。

喉咙发紧,呼吸开始黏滞。她咬了下嘴唇内侧，铁锈味在舌尖化开。

**标注**：用了 **环境（声音、空间投射）+ 感官（听觉、视觉、味觉）+ 影响（生理反应、情绪外化）** 三维。

## 六、反模式

| 反模式 | 失效信号 | 示例 |
|---|---|---|
| **形容词三连** | 连续三个以上形容词，无具体名词锚点 | "房间漂亮精致华丽" → 改为"墙上挂着镀金画框，地毯踩下去陷半寸" |
| **环境与情绪错配** | 悲剧配鸟语花香，但无反差意图 | 葬礼当天阳光明媚鸟鸣啾啾（若非刻意用反差制造荒诞感，则失效） |
| **细节无后果** | 描写的枪下文不开火 | 第三章写"桌上放着一把刀"，后文再不提 → 删除或让它产生后果 |
| **全知视角泄露** | 限知叙述者写出不在场信息 | POV 在 A 房间，却写"此时 B 房间里他拿起了电话"（她看不到） |

> 与 `emotion-conflict-externalization.md` 的分工边界：该文件负责**情感四通道（生理/行为/认知/环境）+ 冲突外化**，本篇只做**场景物理层细节**，情感描写部分只留接口（如"喉咙发紧"属于生理通道，细节工程只负责把它写具体，不负责情感通道的系统设计）。

## 八、自检清单

每场景完成后过一遍：

- [ ] 五维至少覆盖 3 维？（环境/动作/物件/感官/影响）
- [ ] 密度 ≤ 5 个核心细节？（不过密）
- [ ] 视角过滤无泄露？（没写 POV 看不到的）
- [ ] 细节有后续呼应或影响？（不是废笔）
- [ ] 感官配比合理？（视觉不超 50%，至少用 2 种感官）
- [ ] 细节服务于压力/转折/情感？（不是为描写而描写）
- [ ] 引入时机在冲突点前 1 拍/转折瞬间/余波？
- [ ] 名词 + 动词为主，形容词 ≤ 2 个/段？

## 九、项目实训公式（R47 蒸馏，与五维矩阵互补）

> 来源：小说项目实战稿《吞兽维修师》的四维细节系统（44 号）。五维矩阵回答"查哪些维度"，
> 本节回答"落笔怎么写"。两者叠加使用。

### 9.1 环境＝参与动作的对手/工具/限制（不是布景）

- 公式：**环境参数（温度/湿度/光/声/气味/尺寸）× 人物状态 × 一个变数（此刻在变的东西）**
- 反例："雨下得很大，天很冷。"（形容词，环境没参与）
- 正例："雨停了，棚顶还在滴水。滴在他拆下来的装甲板上，一滴一个印。"
- 判据：环境是否**挡路/告警/耗损/提供线索**？只当背景板的环境描写一律删。

### 9.2 动作三拍与手感

- **三拍公式：意图 → 受阻 → 变招**（每场至少一次）。
- 大动作拆**起势—受力—余震**；小动作写**手感**（重量/温度/阻力）。
- 例："第一颗螺栓锈死了（受阻）。他换长杆扳手，手臂绷直，扳手'咯'地一滑，虎口蹭掉一层皮（受力+余震）。他没停，换个角度从下往上顶（变招）。"

### 9.3 心理四外化（补充"注意偏移"与"闪回"两个增量）

| 外化 | 写法 | 例 |
|---|---|---|
| 生理 | 心跳/口干/手指发凉 | "他数了三遍螺丝，第三遍才数对。" |
| 注意偏移 | 忽然注意到平时不看的细节 | "他这才看见，墙上的挂钟停在四点。" |
| 行动替代 | 想说的话换成另一个动作 | "他想说'别去'。他把雨衣塞进对方怀里。" |
| 闪回 | **≤25 字，一句即止** | "父亲当年也是这么拧的。" |

### 9.4 影响三账

事件必须改变**至少一张账**，各写一句：**人的账**（关系/信任/亏欠）· **物的账**（零件/损失）· **局的账**（局势/规则/权力）。
例："老周把报价单上的'维修费'划掉，改成'欠一次'（人的账）。"

### 9.5 事件判据与配比

- 事件判据：删掉它后文是否仍成立？成立=交代（删）；不成立=事件。必写三问：**谁的态度变了？谁的账变了？下一步选项变了吗？**
- 配比（每 800–1200 字场景）：动作 35% / 影响 30% / 心理 20% / 环境 15%；
  每 800 字至少一次"反常/代价/反转/钩子"。

### 9.6 四个可套用句式

1. 环境参与式：`X 的时候，Y 正好（环境变数），他（动作应对）。`
2. 动作三拍式：`想（意图）→ 卡住（受阻）→ 换个法子（变招）。`
3. 心理外化式：`他没说 Z。他做了（动作）。`
4. 影响三账式：`事件之后：谁的账变了（一句）；谁的称呼变了（一句）；下一步选项变了（半句）。`

## 十、局限

本方法论**不适用**以下场景类型：

1. **纯对话场景**：两人在空白空间对话，刻意不给环境细节（实验性写法）。
2. **极简风格**：海明威式冰山理论，刻意压缩细节到极致。
3. **意识流为主**：内心独白占 80% 以上，物理细节让位于心理流动（如伍尔夫《达洛维夫人》式）。

> 与 `scene-engineering.md` 的配合：当场景通过"删除测试"（该文件核心方法）确认必须保留后，再用本篇方法填充细节；若场景本身可删，细节再好也是浪费。
