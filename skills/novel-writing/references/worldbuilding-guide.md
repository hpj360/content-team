# 世界观设定指南（可执行版）

> `novel-writing` 按需加载参考。世界观不是"设定百科"，而是**约束剧情与爽点的规则系统**。
> 每一条设定都必须能被剧情"用上"，否则就是废设定。

## 一、五层结构

| 层 | 回答什么 | 落库字段 |
|---|---|---|
| 规则层 | 世界怎么运转（能力/科技/魔法边界） | `StoryState.tracking.global_rules` |
| 势力层 | 谁在争夺什么（组织/阵营/利益） | 人物卡 + 势力表 |
| 地理层 | 舞台与资源分布（换地图的动机） | 卷结构 |
| 经济层 | 钱与资源从哪来、卡住谁 | 冲突燃料 |
| 历史层 | 现在为何是这样（前史钩子） | 伏笔来源 |

## 二、规则层三原则

1. **边界即戏剧**：能力的**代价与限制**比能力本身重要。
   - 反例：主角无所不能 → 无冲突。
   - 正例：一次施法折寿一年 → 每次出手都是抉择。
2. **可预测**：读者能预期规则后果，反转才"公平"。
3. **可升级但不失控**：给能力划**层级表**（如炼气/筑基/金丹），升级要可见、有代价。

```
能力体系表（示例）
L1 感知（代价：疲劳）
L2 操控（代价：寿元）
L3 规则改写（代价：记忆）
—— 每级设定：前置条件 / 代价 / 失效条件
```

## 三、势力层：冲突的发动机

- 至少 3 股势力，目标**互相冲突**且**都不完全正确**（避免脸谱反派）。
- 每势力给：目标 / 手段 / 底线 / 与主角的关系（利用/敌对/暧昧）。
- **可迁移**：势力目标冲突 = 天然的"压—爆"燃料，不必依赖主角受辱开局。

## 四、地理层：换地图的正当性

- 换地图必须由**规则或势力**逼出来（资源耗尽/被追杀/任务指向），不能"作者想换"。
- 每张地图给一个**独有规则**（如：此城禁武）→ 立刻产生新冲突。

## 五、历史层：伏笔的矿脉

- 前史事件 = 伏笔来源。登记进 `StoryState.foreshadowing`：
  `{content, planted_at, planned_resolution, keyword}`。
- 埋设即"可收集档案"（信件/碑文/传说），对应 `deconstruction-chapter-form-wukong.md` 的档案式世界观。

## 六、自检（机器可验证）

- [ ] `global_rules` 非空且包含"代价/限制"表述
- [ ] 势力 ≥ 3 且目标互相冲突
- [ ] 每条设定至少被一处剧情/伏笔引用（无"废设定"）
- [ ] 换地图有明确触发（规则或势力）
- [ ] 能力层级有前置/代价/失效三要素

## 七、与本项目集成

- 规则层写 `StoryState.tracking.global_rules`；势力/人物写 `StoryState.characters`；
- 前史伏笔写 `foreshadowing`，由 `gate_foreshadowing_lifecycle`（L004/L005）校验埋设与回收。
