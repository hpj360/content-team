## 一、导演式推理五原则

1. **镜头是叙事决策**：说不出"观众此刻比一秒前多懂了什么"，这个镜头就删。
2. **走位先于构图**：摄影机位置取决于身体在空间中的动作；走位对了，平拍也能读懂。
3. **关键帧是控制点**：视频模型基本是在重新驱动静帧已决定的一切；修静帧比重跑视频便宜。
4. **连贯性是设计出来的**：身份串、光位、画面方向、年代锁定，写一次后逐字复用。
5. **失败要诊断，不要重摇**：先定位失败机制，再沿成本阶梯用最便宜的修复。

## 二、13 步流水线与 10 种输出模式

13 步：intake → breakdown → beats → lens(可选) → director's book → blocking → shot list → keyframe → adapter → video prompts → sound → edit → QC。

输出模式（按需组合）：

| 模式 | 名称 | 何时用 |
|---|---|---|
| A | 导演分析 | 解读、潜文本、规则 |
| B | 节拍表 | 先立结构 |
| C | 导演书 | 统辖全片的规则集 |
| D | 分镜方案 | 镜头表/拍摄表 |
| E | 关键帧提示词包 | 静帧/首尾帧/人物设定 |
| F | 视频动作提示词包 | 素材已有，需动作提示 |
| G | 连贯性圣经 | 反复出现的人物/场景 |
| H | 声音与对白方案 | 声音设计/音乐/旁白 |
| I | 剪辑与合成方案 | 把生成素材剪成序列 |
| J | QC 与修复 | 出了问题 |

全流程通常 A→B→C→D→E→F→H→I，G 贯穿，J 收尾。

## 三、导演书与走位

- **导演书**：写清统辖全片的"不变量条款"（风格、光比、色板、平均镜头时长、声音策略、负面词）。
- **走位（blocking）**：标注每个镜头的 起 → 动 → 止（动作起止与路径），而不只是"画面里有什么"。
- **覆盖策略（coverage）**：为关键场次规划主镜/反打/插入/过渡，供剪辑选择。
- **调度几何**：深度调度（前中后景）、轴线、屏幕方向、视线匹配在拍前确认。

## 四、风格镜头参数化

选择导演风格 = 一组可机器读取的参数覆盖默认值（示例字段）：

```yaml
风格参数:
  lens_kit_mm: [21, 35, 50]          # 允许的镜头包
  allowed_moves: [handheld, slow_push]
  forbidden_moves: [whip_pan]
  motion_budget: low                  # 每镜运动预算
  key_light_ratio: 8:1
  palette: [neon, teal]               # 色板
  avg_shot_length_s: 2.5
  sound_policy: 环境声主导
  negative_prompt_additions: [steadycam_smooth, daylight]
```

- 风格是"镜头"，不是"外套"：选某风格意味着机制上的取舍，不只是加一个词。
- 每个风格模块都应写出"反例/这不是什么"，点名容易混淆的相邻风格及**机制差异**。

## 五、失败编码与成本阶梯

对生成失败建立**编码手册**（机制 + 按概率排序的成因 + 成本最低的有效修复），例如：

| 编码 | 症状 | 常见机制 | 最省修复 |
|---|---|---|---|
| F1 | 像 PPT，人物几乎不动 | 运动预算/关键帧问题 | 改静帧或重排镜 |
| F2 | 角色漂移 | 身份串未逐字复用 | 补 canonical description |
| F3 | 越轴/空间错乱 | 视频模型不知上一镜机位 | 加过渡镜或改机位 |
| F4 | 卡不到切点 | 提示词无时间戳 | 用 S3/S4 提示词形态 |
| F5 | 光影跳变 | 光位未锁定 | 锁定光位锚点 |

**成本阶梯**：改提示词 < 改关键帧 < 重排镜头 < 重写场次。**三振规则**：同一问题三次失败 → 停下重排，不要继续重摇。

## 六、质量门（机器可验证）

- [ ] `theme` 非空且为一句完整陈述
- [ ] `style` / `tone` / `pacing` 非空；风格参数块字段完整
- [ ] 每个主要角色有 `performance_notes`，且为可执行的外部动作
- [ ] 镜头表每镜含 起-动-止 走位与叙事功能
- [ ] `scene_reviews` 覆盖剧本所有场景，每条有明确 `verdict`
- [ ] 失败项均有编码与成本阶梯修复方案
- [ ] `director_notes` 非空
