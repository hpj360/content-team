# 导演风格参数规范（字段定义与选用）

> `directing` 按需加载参考：`风格参数` YAML 的字段语义、参数三层覆盖与选用纪律。

风格包本体（01–12）见 `style-pack-library.md`；本文件只管字段语义与覆盖规则。

## YAML 字段清单

| 字段 | 含义 |
|---|---|
| `风格参数` | 根键。选风格 = 加载一个参数块覆盖默认值。 |
| `lens_kit_mm` | 可用焦段（mm）清单；决定空间压缩与人物距离。 |
| `allowed_moves` | 允许的镜头运动白名单（`static` / `slow_push` / `arc_track` 等）。 |
| `forbidden_moves` | 禁止的运动黑名单，显式写出以防"随手加运镜"。 |
| `motion_budget` | 运动预算（`low` / `medium`）：每镜可用的运动量。 |
| `key_light_ratio` | 主光与辅光的光比，写作 `"4:1"`、`"32:1"` 等形式。 |
| `palette` | 色彩 / 材质基调关键词列表。 |
| `avg_shot_length_s` | 单镜平均时长（秒）；均长即节奏，受单镜 ≤5s 硬门约束。 |
| `sound_policy` | 声音策略：同期声、配乐与音效的使用纪律。 |
| `negative_prompt_additions` | 追加到负面提示词的排除项。 |

## 参数三层覆盖

`风格参数` > 场景锚点 > 全局默认，逐层覆盖（外层优先，内层兜底）。
风格包只覆盖默认值，不改变事实锚点，也不改变门禁判定。

## 选用与组合规则

- **一场一风格**：同场戏内禁止混风格包；类型切换直接换包（转场即换包，风格是节奏标点）。
- **参数覆盖**：按上节三层顺序逐层覆盖。
- **类型即节奏**：均长本身是类型信号（喜剧 2s、悬疑 5s、古装 4.5s），仍受单镜 ≤5s 硬门约束。
- **出口双门不放宽**：风格参数只覆盖默认值，不豁免 `references/dramaturgy-gate.md` 的六点检查。
- 12 包的逐包机制、反例与适用范围见 `style-pack-library.md`。

## 反例：这不是什么

- 不是"滤镜预设"：参数约束运动、光比、声音与排除项，不是给画面套一层色调。
- 不是"越慢越高级"：均长只是类型信号，写意靠省略而非拖长每一镜。
- 不是"门禁豁免"：放宽的只是默认值，`gate_directing` 与出口双门照常校验。
- 每个风格包各自的"反例 / 这不是什么"随包写在 `style-pack-library.md` 对应小节。

## 与本项目集成

- 风格包 YAML 直接写入创作循环 `options.style_pack`；`_build_directing` 将
  `style/tone/pacing` 落入 `DirectingPlan`。
- `gate_directing`（D001–D004）校验风格/基调/节奏/阐述完整性。
