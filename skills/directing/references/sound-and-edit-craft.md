# 声音与剪辑手艺

> `directing` 按需加载参考。补充 `directing-craft.md` 的 Mode H（声音）与 Mode I（剪辑）细节：
> **声音是情绪的第二个镜头，剪辑是节奏的最后一道门**。

## 一、声音三层

| 层 | 内容 | 作用 |
|---|---|---|
| 对白 | 台词/旁白 | 信息与性格（见 `dialogue-examples.md`） |
| 音效（Foley/环境） | 脚步、门响、雨、键盘 | 空间可信度与节奏标点 |
| 音乐 | 主题/氛围/情绪推进 | 情绪引导（慎用，易滥） |

**配比原则**：信息戏靠对白；情绪戏靠音效留白；转折处音乐进入或骤然停止。

## 二、声音的节奏作用

- **音效即标点**：门响=句号、脚步逼近=逗号、静默=破折号（对应 F7 音画分离、F10 转场）。
- **留白**：情绪峰值前 1–2 秒抽掉音乐 → 观众屏息（比加音乐更有效）。
- **声音先入/后出**：下场景的声音提前进入（J-cut），或上场景声音延续到下场景（L-cut）→ 无缝转场。

## 三、剪辑节奏四参数

| 参数 | 说明 | 参考 |
|---|---|---|
| 平均镜头时长（ASL） | 类型信号：喜剧 2s / 悬疑 5s | 见 `style-pack-library.md` |
| 切点动机 | 每次切必须有动机（新信息/情绪变化/动作完成） | 无动机=跳切 |
| 景别递进 | 建置→推进→强调 | 见 `shot-patterns.md` |
| 轴线/方向一致 | 越轴需过路费（中性镜/过渡） | 见 `failure-casebook.md` F3 |

## 四、转场工程（五种）

| 转场 | 做法 | 适用 |
|---|---|---|
| 硬切 | 直接切 | 同场连续动作 |
| Match cut | 相似物/相似动作衔接 | 时空跳跃且需顺滑 |
| 声音桥（J/L-cut） | 声音先入/后出 | 场景过渡 |
| 空镜过渡 | 1.5–2s 中性空镜 | 情绪缓冲 |
| 匹配转场 | 前后段光色/运动方向一致 | 大跨度时空 |

## 五、声音与剪辑的自检

- [ ] 每个切点有明确动机（新信息/情绪变化/动作完成）
- [ ] ASL 与类型匹配（喜剧短、悬疑长）
- [ ] 情绪峰值前有留白或音乐骤停
- [ ] 转场两侧运动方向/光色一致，或付了"过路费"
- [ ] 对白与画面**音画分离**（声音走独立轨，不塞进画面提示词）
- [ ] 声音三层齐备（对白/音效/音乐），无一层缺席

## 六、与本项目集成

- 声音方案落 `DirectingPlan`（tone/pacing/notes）与分镜 `Shot.sound`；
- 剪辑节奏与 `Shot.duration_seconds`（2–5s 硬门）、段长（≤15s）联动；
- 转场设计对应 `failure-casebook.md` F10 的修复路径。
