# 一致性锚点实例库

> `storyboarding` 按需加载参考。canonical description 写法、光色锚点、逐字识别符的正反例，解决 AI 生成"角色漂移/光影跳变"。

## 一、canonical description（角色身份串）写法

**公式**：`身份词 + 3 个不变特征 + 1 个专属识别符`，控制在 40–60 字，**逐镜逐字复用**。

### 正例

```
李默：28岁外卖骑手，蓝色骑手服袖口磨白，左手腕黑色电子表，右侧眉尾一道短疤。
```

- 为什么成立：职业/年代（28岁+骑手）、3 个可画特征（袖口磨白/电子表/眉尾疤）、
  疤是**别人画不走的识别符**。
- 使用规则：每条视频/分镜提示词**原样粘贴**这一句，禁止改写措辞。

### 反例（逐条指出病灶）

| 反例 | 病灶 |
|---|---|
| "年轻帅气的外卖小哥" | 无可画特征，100 个人 100 个样 |
| "穿蓝色衣服的李默，戴着表，脸上有疤" | 识别符模糊（什么表/哪道疤），改写后失去逐字一致性 |
| 每镜换形容词（"英气逼人/眉目俊朗"） | 形容词堆砌，模型自由发挥度最大 |

## 二、光色锚点（场景级）

**公式**：`光源方向 + 色温 + 一个实用光源清单`，一场戏一份，逐镜复用。

### 正例

```
出租屋夜戏：单光源右侧窗月光（冷 6500K），台灯暖光 2700K 为唯一实用光；
阴影压至 8:1，全程禁止顶光。
```

### 反例

- "暖色调氛围感灯光"（无方向/无色温/无清单 → 每镜灯光自由漂移）
- 中途新增"夕阳金光"却未改锚点声明（跳变）

### 光色锚点表（建议随分镜交付）

| 场次 | 方向 | 主色温 | 实用光 | 对比度 |
|---|---|---|---|---|
| 出租屋·夜 | 右侧窗 | 6500K | 台灯 2700K | 8:1 |
| 办公室·日 | 顶前偏左 | 5600K | 百叶窗反射 | 4:1 |

## 三、逐字识别符（关键道具/服装）

- 识别符必须**唯一 + 可画 + 逐字复用**：
  - 正例："杯沿有一道缺口的白瓷杯"、"缠着黑色胶带的右拳"
  - 反例："旧杯子"、"受伤的手"
- 识别符是伏笔的前置资产：`gate_foreshadowing_lifecycle` 的 `keyword` 直接引用识别符，
  实现"分镜提示词 ↔ 状态卡伏笔"同词对账。

## 四、锚点包（交付物模板）

```yaml
# scene_anchors.yaml —— 每场一份，随分镜交付
characters:
  李默: "28岁外卖骑手，蓝色骑手服袖口磨白，左手腕黑色电子表，右侧眉尾一道短疤。"
locations:
  出租屋: "8平米隔断，右侧一扇窗，窗下折叠桌，墙上贴满便利贴。"
props:
  白瓷杯: "杯沿一道缺口的白瓷杯。"
lighting:
  出租屋·夜: "单侧窗月光6500K+台灯2700K，对比8:1，禁止顶光。"
palette: ["冷蓝", "钨丝暖橙"]
negative: ["顶光", "第二主光源", "角色换装"]
```

## 五、自检（机器可验证）

- [ ] 每个 recurring 角色都有 canonical description（40–60 字，含识别符）
- [ ] 提示词中的身份串与锚点包**逐字节相同**（可用脚本 diff）
- [ ] 每场一份光色锚点，逐镜未新增未声明光源
- [ ] `palette` 与 `negative` 未被单镜覆盖

## 与本项目集成

- 锚点包写入创作循环 `options`，供 `storyboarding`/`directing` builder 引用；
- 识别符词表同步进 `StoryState.foreshadowing`（`keyword` 字段），实现跨阶段一致性对账。
