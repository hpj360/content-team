# AI 静态图出图配方（场景/角色/道具三类）

> `storyboarding` 按需加载参考。分工边界：动态镜头提示词推导见 `ai-video-storyboard-prompting.md`；风格参数上游见 `style-pack-library.md`；竖屏取景规则见 `vertical-shot-grammar.md`。本篇只管**静态图**三类图的字段配方。
> 蒸馏自项目实战 AIGC 出图配方段落（2026-11-15 校准）：只蒸馏方法，不搬运任何项目专名；所有示例均为自造。
> 红线：提示词只描述**虚构世界**；真实机构徽记、真实品牌、真实人物肖像一律不进配方。

## 一、三配方总览

| 配方 | 用途 | 核心字段 | 质量判据 |
|---|---|---|---|
| 场景图 | 定场空镜、氛围底图，供分镜与视频复用 | 环境五要素＋光色锚＋构图 | 五要素齐备；光色与锚点包一致；可无人复用 |
| 角色立绘 | 定稿参考图、表情/动作素材 | 身份串＋识别符＋服装锁定 | 身份串逐字可 diff；识别符可画且唯一 |
| 道具图 | 伏笔登记的视觉资产 | 三态＋识别符＋使用痕迹 | 三态同源；识别符与 story-state 伏笔同词 |

## 二、字段七件套

三类配方共用同一套字段骨架，顺序固定，逐项填空即成一条提示词：

1. **主体**：谁/什么＋动作状态。静态图忌纯名词：给"正在做什么/处于什么状态"（半蹲记录/雨水未干），动词决定画面的时间感。
2. **场景（环境五要素）**：材质、光源、天气、时代、密度。五项各给一个可画的具体词（"锈蚀铁皮＋顶棚漏光＋阴天＋当代＋杂乱堆叠"），缺一项，模型就替你自由补一项。
3. **构图**：景别＋机位高度＋视线方向。竖屏 9:16 时景别语义按 `vertical-shot-grammar.md` 迁移表上移一级；机位高度（仰/平/俯）单独写出，不留给模型默认平拍。
4. **风格**：从风格包 YAML 逐字抄 `lens_kit`、`palette`、`key_light_ratio` 三项成一句固定后缀（如"35mm 焦段，冷蓝＋钨丝暖橙，光比 8:1"）；一场一包、禁止跨包混用（见 `style-pack-library.md`）。
5. **一致性锚点**：角色用"身份词＋3 个不变特征＋1 个专属识别符"（40–60 字），**逐字复用**、禁止改写措辞；公式与正反例见 `continuity-anchor-examples.md`。
6. **负面词**：每类配方带一组默认负面词（见三/四/五节），另加公共兜底：文字乱码、多余手指、水印、真实品牌标识。
7. **出图参数**：比例（横屏 16:9／竖屏 9:16，与用途对应）、数量（同配方一次出 4 张挑 1）、种子策略（同一实体跨图固定种子，换构图才换种子）。

七件套的"差集"用法：场景图以第 2/3/4/6/7 项为主体；角色立绘以第 1/3/4/5/6/7 项为主体；道具图以第 1/2（限光源）/5/6/7 项为主体——骨架不变，按图类做加减。

## 三、场景图配方

模板句式：

```
[景别＋机位] ＋ [五要素：材质/光源/天气/时代/密度] ＋ [一个瑕疵细节（破绽位）] ＋ [一个入画物证] ＋ [风格后缀] ＋ [负面词]
```

要点：场景图必须留一个"瑕疵/破绽位"——一处与整场不符或未收拾的细节，它是后续叙事的登记口；入画物证即伏笔候选，识别符当场定词。

微例一（废料场，竖屏环境条带）：

```
[景别] 9:16 纵向条带，透过门缝看废料场纵深，机位平高。
[五要素] 锈蚀铁皮棚顶，顶棚漏洞漏下一束顶光，阴天浮尘，当代，杂物堆叠至画外。
[瑕疵] 堆顶一块崭新反光板与全场锈色不符。
[物证] 地面半掩的褪色工牌一枚。
[风格] 35mm 焦段，冷绿＋脏黄，光比 32:1。
[负面] 人物, 文字乱码, 多余手指, 水印, 阳光直射
```

微例二（雪夜站台，竖屏无人空镜）：

```
[景别] 9:16 中景，站台长椅居中，机位略低仰角。
[五要素] 湿滑水泥地，双侧灯箱冷光，小雪，当代，空旷。
[瑕疵] 长椅下压着一张未捡的车票。
[物证] 灯箱玻璃上停一只飞蛾。
[风格] 28mm 焦段，霓虹青＋品红＋沥青黑，光比 16:1。
[负面] 人物, 新增光源, 文字乱码, 水印
```

横屏用途（16:9 定场底图）同一模板，仅两处改动：景别写横屏语义、构图改用"前景遮挡＋门框纵深"交代层次；五要素、瑕疵位、物证、风格后缀、负面词全部不变。

## 四、角色立绘配方

同一角色先各出一次三种单，作为该角色后续全部出图的参考底图：

| 单 | 内容 | 关键字段 |
|---|---|---|
| 三视图 | 正/侧/背全身，同光照同服装 | 身份串逐字复用＋"三视图，同一光照"；负面加"服装不一致" |
| 表情包 | 6–8 个表情格，同构图同光 | 身份串＋"表情表"；负面加"表情间换装、构图漂移" |
| 动作态 | 3–5 个典型动作（坐/持物/警戒） | 身份串＋动作句独立成句；负面加"第二人物入画" |

服装与识别符锁定：立绘定稿后，服装描述与识别符写入锚点包 YAML，此后**不再手写外观**——每次出图原样粘贴锚点包串；确需换装（剧情节点），先改锚点包再出图（见六）。

身份串微例（自造角色，示范七件套第 5 项的写法）：

```
29 岁夜班仓库管理员，藏青工装裤膝部磨白，右手缠米色胶布，左耳骨钉为黑绳。
```

成立理由：职业/年代（29 岁＋管理员）定身份词；膝部磨白、胶布、黑绳是 3 个可画不变特征；黑绳骨钉是别人画不走的专属识别符——此后任何图中该角色，此句原样出现。

与 character-bible 四维联动：角色档案的物理记忆点（遗物、习惯动作、身体记号）是识别符的**唯一来源**——档案即提示词清单，不另行发明；四维状态（能力/心理/关系/目标）的卷内变化，通过遗物与识别符的状态**泄漏入提示词**（如"左耳旧耳钉换成黑绳""手套磨痕加深"），画面细节成为状态卡的外显，不靠表情去说明。

## 五、道具图配方

有叙事功能的道具一律出三态，三态共用同一种子与同一识别符：

| 态 | 内容 | 要点 |
|---|---|---|
| 正交态 | 正/侧/背三面，无背景 | 识别符居中清晰；负面加"使用痕迹" |
| 使用态 | 在场景中被手持/放置 | 与所属场景图共用同一光色锚；出"使用磨损" |
| 损坏态 | 断裂/烧灼/洇痕 | 损坏位置固定在识别符所在处，方便跨图对账 |

道具＝伏笔的视觉登记：每个道具的识别符同步登记进 story-state 伏笔总账（`keyword` 字段直接引用识别符），实现"道具图 ↔ 状态卡"同词对账；损坏态首次出现即伏笔引爆帧，登记状态同步改为"已回收"。

识别符正例："提手缠三圈黑胶带的铝饭盒"；反例："旧饭盒"——前者可画、可对账，后者每图一个样。

## 六、一致性纪律

1. **同一实体跨图锚点逐字一致**：角色串、光色锚串、识别符在任何一张图里逐字节相同；锚点包 YAML 可 diff，两图串不同即判失败（同 `continuity-anchor-examples.md` 格式）。
2. **参考图锁定**：每角色先出定稿立绘，后续所有出图挂同一张为参考图，不再手写外观描述，防止跨图崩坏。
3. **改版规则**：改锚点＝改档案＝登记——任何措辞改动必须同步回锚点包 YAML 与角色档案，写明改动原因与生效集数；禁止"只改提示词、不改档案"的暗改。

静态图锚点包与视频锚点包**同源同格式**，出图前先落包、出图时逐字引用：

```yaml
# image_anchors.yaml —— 静态图锚点包（自造示例）
characters:
  夜班管理员: "29岁夜班仓库管理员，藏青工装裤膝部磨白，右手缠米色胶布，左耳骨钉为黑绳。"
locations:
  废料场: "锈蚀铁皮棚顶废料场，顶光自棚顶漏洞漏下，阴天浮尘。"
props:
  工牌: "半掩于杂物的褪色工牌。"
lighting:
  废料场·阴天: "顶光单束6500K，无第二光源，对比32:1。"
palette: ["冷绿", "脏黄"]
negative: ["新增光源", "文字乱码", "多余手指", "水印"]
```

校验方式：把已出图所用提示词中的身份串/识别符从 YAML 原样导出做逐字节 diff，任何一处不同即该图回炉。

## 七、常见失败与修复

| 症状 | 病因 | 修法 |
|---|---|---|
| 多指/手部崩坏 | 手部动作描述含糊或堆细节 | 手部词减到一句；负面加"多余手指"；关键手戏改局部重绘 |
| 图内文字乱码 | 提示词要求画面自带文字 | 画面文字一律后期贴字；负面加"文字、字幕、乱码" |
| 风格漂移 | 风格后缀缺失或跨包混用 | 后缀逐字粘贴、一场一包；漂移图整批回炉不挑补 |
| 光源矛盾 | 未声明光源被模型自行补光 | 光色锚写"唯一主光＋禁顶光"；负面加"新增光源" |
| 比例失调 | 景别按横屏语义直用竖屏 | 景别按迁移表上移一级；全身图改半身＋头顶留白 |
| 锚点丢失 | 提示词改写了锚点措辞 | 锚点串从 YAML 原样粘贴，脚本 diff 校验后再生图 |

## 八、与工作流集成

接力关系：**分镜镜头表 → 逐镜出图 → 视频生成**。

1. `shot-patterns.md` 产镜头表，定每镜景别/机位/功能——本配方按镜表逐镜填七件套，一镜一图：定场镜用场景图，人物镜用立绘动作态，道具镜用道具图对应态。
2. 逐镜出图后过六/七节纪律（锚点 diff＋失败修复回路），合格图登记为该镜定稿，文件名记录配方与种子号。
3. 交棒 `ai-video-storyboard-prompting.md`：静态图的主体串、光色锚、风格后缀**原样**进入视频提示词对应槽位；静态图即视频的首帧基准与一致性底账。

## 九、自检 6 条

- [ ] 每条提示词七件套字段齐全、槽位顺序一致
- [ ] 身份串/识别符与锚点包逐字节相同（diff 通过）
- [ ] 风格后缀与所属风格包三项（lens_kit/palette/key_light_ratio）一致
- [ ] 场景图五要素齐备且含一个瑕疵位
- [ ] 道具三态齐全且识别符已登记 story-state
- [ ] 种子策略符合"同实体固定、换构图才换"

## 十、局限

- 模型迭代快：本配方按 2026-11-15 口径校准，字段方法稳定、参数方言需按 `content_freshness` 口径复审。
- 本篇不含任何项目专名；接入具体项目时，从该项目的角色档案与锚点包取词，不在本篇内发明。
- 提示词存在各模型方言差异（负面词语法、种子字段名、比例写法），落地时以目标模型文档为准，本篇只约定字段语义。
