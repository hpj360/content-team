# 剪辑节奏与切点方法

> `storyboarding` 按需加载参考。切点类型、每镜时长的情绪函数、J/L cut 的镜头表写法、转场四类，以及与"单镜 2–5s／段 ≤15s"硬门的对账方法。方法论蒸馏，非逐字引用。

## 一、切点三种类型（每个切点必须归入一类）

| 类型 | 定义 | 典型位置 | 判据 |
|---|---|---|---|
| 信息切 | 画面交足信息后即切 | 建置镜、道具镜 | 道具/关系已被观众读到的时刻 |
| 情绪切 | 情绪升满但尚未溢出时切 | 反应镜、特写 | 观众"已经开始下一拍预感"的瞬间 |
| 动势切 | 动作的"止"帧上切 | 打斗、追逐、起身 | 动作终点帧＝下一镜起点帧 |

- 一个切点只能有一个主要类型；写镜头表时在 `notes` 或 description 末尾标注（如 `切点:动势`）。
- **同时是三种切点的镜 = 没有切点**：先删信息再归类。

## 二、每镜时长的情绪函数

时长不是匀速分配，而是情绪曲线的采样：

```
时长(S) ≈ 基准(2s) + 信息补价(0–2s) + 情绪浓度加成(0–1s) − 动势扣减(0–1.5s)
结果钳制在 [2.0, 5.0]（硬门 B004）——公式自然值跌破 2s 时取 2s，不得低于下限
```

| 状态 | 时长倾向 | 例子 |
|---|---|---|
| 高密动势（追/打/争） | 2–3s | 逐镜扣减，多切 |
| 建置/关系交代 | 3.5–5s | 信息补价付满 |
| 情绪峰值前摇 | 4–5s | 克制不切，蓄力 |
| 情绪爆发瞬间 | 2–2.5s | 快切释放 |
| 收尾留白 | 4–5s + 拉远 | 让空间接管情绪 |

- **均质化是节奏病**：全部 3.0s 的镜头表 = 没有情绪函数（见 failure-casebook SB3/SB7）。
- 同一类情绪内允许 ±1s 抖动，跨情绪段必须出现时长差 ≥ 1.5s 的对比。

## 三、音效先入与声画错位

- **音效先入（sound advance）**：下一镜的关键音效在上一镜最后 0.5–1 s 进入（门声先台风声），切点被声音"钉"住，观众不觉得跳。
- **声画错位**：反应声（笑/惊呼/喘）错后 2–3 帧，比同帧更真实；重大一声（雷/门砰）与画面同帧。
- 镜头表约定：`sound` 字段前缀 `PRE:` 表示先入（如 `PRE: 关门声(先入0.8s)`）。

## 四、J/L cut 的镜头表写法

- **J-cut**：下镜的声音先入 → 在**上一镜**的 dialogue/sound 标注（声跨桌面）。
- **L-cut**：上镜的声音延续到下镜 → 在**下一镜**标注（话音拖进空镜）。

写法模板（只改 sound/dialogue 字段，不加新列）：

```json
{"shot_number": 3, "duration_seconds": 4.0, "dialogue": "", "sound": "A 方台词尾，L-cut 拖入镜 4 前 1s"}
{"shot_number": 4, "duration_seconds": 3.5, "dialogue": "", "sound": "PRE: B 方台词先入（J-cut），画面先到"}
```

## 五、转场四类与误用

| 类型 | 做法 | 误用案例 | 修正 |
|---|---|---|---|
| 硬切 | 无处理直切 | 情绪段之间硬切，观众"断片" | 情绪跨段加 1 镜中性空镜（参照 directing F10） |
| 遮罩跳 | 人物/物体扫过镜头瞬间切换时空 | 每场都用遮罩跳，节奏疲劳 | 全片 ≤ 2 次，且两侧运动方向一致 |
| 匹配切 | 前后两镜构图/动作形状相吸 | 相似形状但情绪不匹配，变成滑稽 | 只在"同一决定/同一意象"上用 |
| 动作切 | 上一镜动作"止"接下一镜动作"起" | 动作没做完就切，观众看丢 | 切点必须绑定动作终点帧（跨镜状态交接） |

- 转场是**标点**：不是每两镜都要转场，句号之间本来就是硬切。

## 六、与硬门的对账方法

`creative/gates.py` 硬门：单镜 ∈ [2,5] s（B004）、段合计 ≤ 15 s（B004）、相邻景别不重复（B005，warn）。节奏设计必须**在表格上先对账**再落库：

### 对账表模板

| 镜 | 时长 | 切点类型 | 情绪采样 | J/L | 段累计 | 硬门判 |
|---|---|---|---|---|---|---|
| 1 | 4.0 | 信息切 | 建置 | — | 4.0 | ✓ |
| 2 | 3.0 | 动势切 | 推进 | J | 7.0 | ✓ |
| 3 | 2.5 | 情绪切 | 峰值释放 | — | 9.5 | ✓ |
| 4 | 5.0 | 信息切 | 收尾留白 | L | 14.5 | ✓ ≤15 |

对账规则：

1. **先过 B004**：任一镜 <2 或 >5 → 回到第二节情绪函数重估，禁止"先写满再压时长"。
2. **段接近 15s 必须有人为落差**：最后 1.5s 从最重情绪镜上减（峰值镜总是最先被砍的）。
3. **三种切点至少齐全两类**，且无连续 3 镜同一时长值（均匀即惩罚）。
4. 累计超 15s → 拆成两段，并在段界用一次转场（优先硬切或动作切）。
5. 对账表与镜头表同批交付，`total_duration_seconds` 必须等于"段累计"末值。

## 七、自检（机器可验证）

- [ ] 每个切点标注了类型（信息/情绪/动势三选一）
- [ ] 无连续 3 镜等时长；全表时长至少出现 3 个不同值
- [ ] 音效先入/声画错位已在 sound 字段标注（PRE: / L-cut）
- [ ] 全片遮罩跳 ≤ 2，且两侧运动方向一致
- [ ] 对账表段累计 ≤ 15s，单镜均在 [2,5] s（对应 B004）
- [ ] 相邻景别不连续重复（对应 B005）

## 与本项目集成

- 切点标注写入 `Shot.description` 或 `notes`，供 `CreativeReviewer.gate_storyboard` 复核；
- `validate_shot_durations` 在落库前重放本表的"段累计"列，任何改动后重跑对账；
- J/L cut 的声音设计由 downstream 剪辑层执行，本表只写约定。
