# AI 视频分镜提示词推导（镜头表 → 每镜提示词）

> `storyboarding` 按需加载参考。把镜头表字段（景别/运镜/描述/台词/音效/时长）映射为每镜生成提示词的推导规则；主体与风格一致性逐字复用；含两个完整推导示例。提示词一律用 `[中文描述]` 风格，不照抄任何专有工具语法。**纪律：不复制任何受版权美术资产**（角色形象、机甲/服饰设计、实体影片画面），只写原创的、可拍摄的描述。

## 一、字段 → 提示词的映射规则

镜头表的 6 个字段对应提示词固定槽位，顺序约定如下：

```
[镜头序号与时长] → [景别+运镜] → [场景与光色锚点] → [主体: canonical description 逐字复用]
→ [镜头内运动] → [环境运动] → [风格包后缀] → [台词/声音约定] → [负面词]
```

| 镜头表字段 | 提示词槽位 | 映射要领 |
|---|---|---|
| shot_size | 景别槽 | 用语义词（"胸部以上半身""纵向条带远景"），竖屏按迁移表语义 |
| camera_movement | 运镜槽 | 只写一个主运动方向；"缓推到底"优于"推进" |
| description | 场景槽＋运动槽 | 拆成"静态构图"与"镜头内运动+环境运动"两段（S1 运动 ≥ 2 处） |
| dialogue | 声音约定槽 | 不进画面描述；写"说话中"标记或走独立音轨（对照 directing F7） |
| sound | 声音约定槽 | `PRE:` 先入、切点绑动作终点（对应 storyboard-method 时长对账） |
| duration_seconds | 时长槽 | `[X.0–Y.0s]`，切点绑定可听见/可见的动作终点（directing F4） |

## 二、主体一致性：canonical description 逐字复用

- 来源：`continuity-anchor-examples.md` 第一节的公式（身份词 + 3 个不变特征 + 1 个专属识别符，40–60 字）。
- 规则：**逐字节复制**，禁止改写措辞、增删形容词；每镜
  `[主体] 28岁外卖骑手，蓝色骑手服袖口磨白，左手腕黑色电子表，右侧眉尾一道短疤。`
  原样出现，场景动作写在其后的独立句。
- 校验：锚点包 YAML 转脚本 diff，两镜身份串不同即失败（SB5）。

## 三、风格锚定：风格包 → 提示词后缀

风格包（`palette / lens_kit / motion_budget`，见 directing 技能）化为固定后缀，每镜追加同一句：

```
[风格] 电影感颗粒质感，镜头组 35mm 焦段，主色冷蓝＋钨丝暖橙，浅景深，写实棚拍光比。
[负面] 新增光源, 角色换装, 第二主体复制, 手指异常, 大字满屏字幕
```

- 后缀**不是可选项**：漏一句 = SB5/F8 风格漂移。风格切换只允许发生在明确转场处。
- 负面词三件套兜底：`新增光源 / 主体复制 / 满屏字幕`；版权纪律词：`不复制既有影视画面/美术资产`。

## 四、逐镜校验回路

生成不是终点，每镜过一遍：

1. **身份 diff**：提示词身份串 == 锚点包串（逐字节）。
2. **运动预算**：镜头内运动 ≥ 2 处 + 环境运动 ≥ 1 处（防 PPT 感，F1）。
3. **光光一致**：本镜光色描述 == 光锚串，未出现未声明光源。
4. **时长对账**：成片实际时长回到对账表 ±0.5s 内，越界回炉（B004）。
5. **景别复核**：成片实际景别与镜头表一致；相邻两镜不重景别（B005）。
6. 不合格镜最多重摇 2 次即回改提示词，禁止原地打转。

## 五、推导示例一：对话戏（两人谈判破裂，竖屏，11s）

镜头表（对账后）：

| 镜 | 景别 | 运镜 | 时长 | 描述 | 声音 |
|---|---|---|---|---|---|
| 1 | MEDIUM | STATIC | 4.0 | 隔桌对坐，桌上一份文件 | 环境雨声；PRE: 文件拍桌声先入 0.8s |
| 2 | MEDIUM_CLOSE | DOLLY(缓推) | 3.5 | 一方起身要走，袖口磨白入画 | 台词一句（≤12 字），L-cut 拖 0.5s |
| 3 | CLOSE | STATIC | 3.5 | 另一方手指收紧，捏皱纸角 | 纸张窸窣，雨声延续 |

镜 1 推导提示词：

```
[0.0–4.0s 点击文件拍桌声即切]
[景别] 9:16 竖幅，胸部以上中景，两人隔折叠桌对坐，各占画面半侧。
[主体] 28岁外卖骑手，蓝色骑手服袖口磨白，左手腕黑色电子表，右侧眉尾一道短疤。
[主体·对坐方] 对坐者穿灰色立领外套，右手无名指一枚素圈戒指。
[镜头内运动] 骑手把一份文件推过桌面又抽回一半；灰外套者视线从窗侧移回文件。
[环境运动] 右侧窗雨丝斜落，台灯暖光在桌面晃出第二层影。
[光色锚点] 出租屋夜戏：右侧窗月光 6500K＋台灯 2700K，对比 8:1，禁止顶光。
[风格] 电影感颗粒，35mm 焦段，冷蓝＋钨丝暖橙，浅景深。
[声音] 雨声打底；0.8s 处文件拍桌声先入（为镜 2 钉切点）；人物"说话中"口部动作，不逐字对口型。
[负面] 新增光源, 第二主光源, 主体复制, 满屏字幕, 换装, 不复制既有影视画面
```

镜 2（要点版）：身份串逐字复用＋"起身，动作止＝跨过门槛半步"给镜 3 绑定切点；DOLLY 推速与台词收点同步。镜 3：切碎点绑"纸张捏皱定型"终点帧，EXTREME 与 CLOSE 之间以"手指"替换"面部"避免与镜 2 景别连读雷同——镜 3 实取 CLOSE，与镜 2 的 MEDIUM_CLOSE 已不同，通过 B005。

## 六、推导示例二：追逐镜头（城中巷道，竖屏，13s）

镜头表（对账后）：

| 镜 | 景别 | 运镜 | 时长 | 描述 | 切点类型 |
|---|---|---|---|---|---|
| 1 | WIDE(纵向条带) | TRACKING(侧跟) | 4.0 | 巷道纵深，两人一前一后 | 信息切 |
| 2 | CLOSE | HANDHELD | 3.0 | 主角回头/脚步溅水 | 动势切 |
| 3 | MEDIUM | TRACKING(反打) | 3.0 | 追方视角，目标渐近 | 动势切 |
| 4 | EXTREME_CLOSE | STATIC | 3.0 | 拐角前 0.5s 静帧→急转出画 | 卡点切（音乐重拍） |

镜 2 推导提示词：

```
[4.0–7.0s 切点绑"脚步双落并步"终点帧]
[景别] 9:16 竖幅近景：小腿至肩，面部占上 1/3。
[主体] 28岁外卖骑手，蓝色骑手服袖口磨白，左手腕黑色电子表，右侧眉尾一道短疤。
[镜头内运动] 主角回头一瞥又猛转回，右手撑墙借力蹬出一步；头盔带在颊边甩动。
[环境运动] 地面水洼被蹬碎溅起，巷道尽头摩托车灯闪两下。
[运镜] 手持轻微晃动，前景砖墙扫过（前景遮挡制造纵深）。
[风格] 同镜 1 后缀逐字复用。
[声音] 喘息声错后 2 帧； PRE: 下一镜脚步声先入 0.6s。
[负面] 新增光源, 主体复制, 手指异常, 满屏字幕, 不复制既有影视画面
```

要点：镜 4 的 0.5s 静帧写进时长槽（"[3.0] 帧停→重拍即出"），承担卡点；三镜运动方向保持"向下纵深冲"，无 reverse。

## 七、自检（机器可验证）

- [ ] 每镜提示词含全部槽位，槽位顺序一致（可脚本切分校验）
- [ ] 身份串与锚点包逐字节相同（diff 通过）
- [ ] 风格后缀全段逐字一致；风格词未在镜内被改写
- [ ] 镜头内运动 ≥ 2 处，环境运动 ≥ 1 处
- [ ] 负面词含版权纪律项；台词走声音槽而非画面槽
- [ ] 逐镜实际时长在 B004 硬门内；相邻景别不重复（B005）
