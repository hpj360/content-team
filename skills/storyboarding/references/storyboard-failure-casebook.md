# 分镜失败案例手册（SB 编号 × 完整案例）

> `storyboarding` 按需加载参考。条目结构对齐 `directing/references/failure-casebook.md`：症状 → 机制 → 修复（前后对照）→ 关联断言。每个案例的"关联断言"指向 `creative/gates.py` 分镜门真实检查维度或 SKILL.md 机器可验证清单。方法论蒸馏，非逐字引用。

## 案例一：SB1 越轴（左右关系翻转）

- **症状**：对话中段观众说不清谁在屏幕左谁在右，两人像"互换了位置"。
- **机制**：机位跨过两人连线（180° 轴线）且无过渡；视频模型无跨镜空间记忆，生成时方位自由漂移。
- **修复前**：镜 4 从 A 的左侧拍，镜 5 直接切到 B（跨过两人连线），方位凭空翻转。
- **修复后**：镜 4 → 插入 2.5s 中性镜（正面对称机位，两人各占画面半侧）→ 镜 5 以门框为前景锚定新方位。
- **修复**：越轴必付"过路费"——插入中性镜或摇移过渡，或在锚点包声明"全场不越轴"；越轴后的首镜用门框/灯等前景物锚定新方位。
- **关联断言**：SKILL 清单「相邻镜头机位变化 ≥ 30°，不越 180° 轴线」；`gate_storyboard` B005（相邻景别重复，warn）常与越轴伴发——越轴修复时同步重查景别递进。

## 案例二：SB2 跳切（景别直撞）

- **症状**：镜 3 与镜 4 同为 MEDIUM，人像"跳了一下"，观感像丢帧。
- **机制**：相邻镜头景别重复且机位变化 < 30°，违反 30° 规则；AI 生成首尾帧过于相似时观感等同于同一镜头被掐断。
- **修复前**：`[3] MEDIUM STATIC 3.5s 开口 ｜ [4] MEDIUM STATIC 3.5s 继续说`。
- **修复后**：镜 4 改 MEDIUM_CLOSE + DOLLY(缓推)，或将镜 3 拉远一级；刻意强调需在 notes 声明。
- **关联断言**：`gate_storyboard` B005「相邻镜头景别重复」（warn，伴随位 consistency）。

## 案例三：SB3 时长均质化（全是 3.0s）

- **症状**：整张镜头表每镜都是 3.0s，成片像"节拍器"，无高潮无呼吸。
- **机制**：先写画面后补时长，逐镜取安全中值；情绪函数缺席（对照 edit-rhythm-and-transition 第二节）。
- **修复**：按情绪曲线重新采样——动势段压到 2–2.5s、建置段给到 4–5s、峰值前摇 5s；重跑硬门确认仍在 [2,5] 内。
- **关联断言**：`gate_storyboard` B004（`validate_shot_durations` 硬门）；SKILL 清单「每镜时长 ∈ [2, 5] 秒」——均质化不出界但必须靠对账表的人工检查项兜住。

## 案例四：SB4 字幕满屏（台词淹没画面）

- **症状**：长台词被整段铺满屏，人物只剩头顶，信息靠"读"不靠"看"。
- **机制**：台词以文字形式塞进画面层且按最大宽度排布；分镜阶段未先划字幕安全区。
- **修复前**：镜 2 拍 5s、屏幕下半被 40 字台词整段覆盖，人物只剩额头以上。
- **修复后**：拆成 2 镜各 3s，每镜 1 句 ≤ 2 行、行宽 ≤ 70%，人物双眼线抬出字幕带。
- **修复**：一人一屏一条一句拆行（≤ 2 行，行宽 ≤ 70%）；长台词拆多镜，每镜只承载一个语义拍；台词超额部分转独立音轨（对照 directing F7 音画分离）。
- **关联断言**：SKILL 清单「每镜都有非空 description」——字幕挤掉画面的镜，其 description 仍是空壳台词，应由 B002 的"描述为空/非可拍摄画面"口径拦截。

## 案例五：SB5 AI 生成一致性崩坏（角色换了脸）

- **症状**：镜 5 起角色眉尾疤消失、袖口颜色换了，第 8 镜几乎认不出。
- **机制**：提示词在不同镜里**改写**了角色描述措辞（"送外卖的小哥"≈"28 岁骑手"≠ 逐字一致）；风格/光色未进入逐镜复用的锚点。
- **修复前**：每镜重写"李默出现在门口"。
- **修复后**：canonical description 逐字粘贴（衔接 `continuity-anchor-examples.md`），光色锚点逐镜追加同一句，negative 加 `character Drift / costume_change`。
- **关联断言**：SKILL 清单「角色 canonical description 与光色锚点逐镜逐字一致」；锚点漂移可在落库前用脚本 diff 两镜描述串，交由独立审查器复核。

## 案例六：SB6 竖屏挤字幕（底部安全区被吞）

- **症状**：竖屏投喂后字幕被平台进度条/互动按钮压住，下半行不可读。
- **机制**：分镜按无安全区满幅设计，人物/台词占满底部；竖屏未按迁移表取景（对照 `vertical-shot-grammar.md` 第三节）。
- **修复前**：EXTREME_CLOSE 拍满全幅，下巴贴底边，字幕与人物耳朵重叠。
- **修复后**：面部压到上 2/3，视线前侧留白；底部 15% 只留给字幕，台词 ≤ 2 行。
- **修复**：底部 15% 定为字幕带，行宽 ≤ 70%；人物双眼线抬到 30–40% 高度；关键道具一律不落底部 15%。
- **关联断言**：SKILL 清单「`total_duration_seconds` = 各镜之和，且符合平台时长预期」的姊妹项——**平台画面预期**（竖屏安全区）在设计阶段判定，不进入 `gate_storyboard` 代码门，须写入 notes 供审查器复核。

## 案例七：SB7 节奏无切点变化（全是"说完就切"）

- **症状**：每个镜都是"台词讲完 → 直切"，观众能数切点，悬念全失。
- **机制**：所有切点都是信息切，缺席情绪切/动势切；J-cut/L-cut 完全未启用（对照 edit-rhythm-and-transition 第一/四节）。
- **修复前**：7 镜全部"台词尾帧 → 直切"，时长 3.0s 均质排列。
- **修复后**：镜 5 改动势切（起身转身终点帧接切）、镜 6 音效先入 0.8s 钉住转折，时长呈现 2.0/2.5/4.0/5.0 的落差。
- **修复**：给每个切点归型并在镜表标注；每段至少引入一次动势切或情绪切；关键转折用音效先入 0.5–1s 钉住切点。
- **关联断言**：SKILL 清单「相邻镜头景别不连续重复（除非刻意强调）」＋ B005；切点类型属于设计期人工判定项，写入 `notes` 由 `CreativeReviewer` 复核。

## 案例八：SB8 铺垫镜头冗长（建置吞掉时长预算）

- **症状**：前两镜环境例行公事拍满 10s，高潮只能硬塞进最后 5s，情绪没跑起来就到段界。
- **机制**：按"开场要有气氛"的数量直觉拆镜，未按"信息切"判据提前切；缺少对账表（段累计列）。
- **修复前**：镜 1 EXTREME_WIDE 5s＋镜 2 WIDE 5s，全是环境例行公事，段只剩 5s 给冲突。
- **修复后**：两镜合并为 1 镜 4.5s（DOLLY 进：环境与主角一手抓细节同框完成），腾出的 5.5s 让给峰值前摇镜。
- **修复**：建置合并为 1 镜 4–5s（信息交足即切）；腾出的时长让给峰值前摇镜；重跑对账表确认段累计 ≤ 15s 且时长出现 ≥ 3 个不同值。
- **关联断言**：`gate_storyboard` B004（段时长 > 15s 为 error）＋ B001（若删镜导致镜号断档则为「镜头号未从 1 连续递增」error）。

## 处置流程（对照三振规则）

1. 先按症状**编码**（SB1–SB8），禁止跳过诊断直接重生成。
2. 沿成本阶梯取最便宜修复：改时长/景别 → 改运镜 → 增删镜 → 重写段。
3. 同一编码三次未愈 → 回退到重新读场（storyboard-method 核心流程第 1 步），并回写本案例簿。
4. 修复后必须重跑：`gate_storyboard`（B001–B005）＋ SKILL 机器可验证清单全项。
